# pytest rootdir 與 import 來源

pytest 以命令列引數（測試檔）的共同祖先為起點決定 rootdir 與 inifile，inifile 的 `pythonpath` 相對 rootdir 展開；cwd 不參與這個決定。測試檔放在哪棵目錄樹，被 import 的套件就優先取自哪棵樹。

## PYT-1 在舊版目錄以絕對路徑跑新版測試檔，全綠被讀成正向對照結果

| 欄位 | 內容 |
|------|------|
| 症狀 | 為驗證新測試的鑑別力，在舊版套件目錄下以絕對路徑執行新版目錄樹的測試檔，預期轉紅卻全綠 |
| 常見誤判 | cwd 在舊版目錄，所以跑到的是舊版程式碼；全綠代表舊版也通過，或測試沒有鑑別力 |
| 實際機制 | rootdir 與 inifile 取自測試檔所在的新版目錄樹，`pythonpath` 讓新版套件排在 `sys.path` 前端；細節見來源 pattern |
| 檢查方法 | `(cd <舊版目錄> && python -m pytest -s <新版測試檔絕對路徑> 2>&1 \| grep -E "rootdir\|configfile")`，並在測試內暫時加 `print(<被測模組>.__file__)` 以 `-s` 執行，看實際 import 的檔案位置 |
| 正向對照 | 同一 cwd 改跑舊版目錄樹內的測試檔，`rootdir:` 與 `__file__` 必須換成舊版路徑；兩次輸出相同代表檢查沒有區分力 |
| 判讀標準 | `rootdir:` 與 `__file__` 都指向舊版被測檔所在的樹，對照才有效；任一指向新版 → 對照無效，改在「被測程式碼與測試檔同屬一棵樹」的環境（如複製套件後只換回舊版被測檔）重跑。對照的紅須落在行為斷言上，收集錯誤或 import 錯誤不算 |
