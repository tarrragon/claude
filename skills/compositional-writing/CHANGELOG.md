**Version**: 1.3.2 — teaching-article-context 的承重術語當場定義：第三支柱講的那個東西原本在同一節裡有三個名字（變數 / 旋鈕 / 可動項）而一個都沒定義，三份理解探針有一份回報「文章沒說」。統一成「可動項」並在首次出現處定義。另修四處指涉無先行詞（「兩者」「那一篇」「接一篇」「後一次」），全部是探針指出、回原文查證屬實的。

**Version**: 1.3.1 — teaching-article-context 卡補三項多輪審查抓出的缺陷：加上論述基礎與限制段（兩批同源、無對照組，同庫每張卡都有這一段而它漏了）、第一與第二支柱各補一個檢查（前者原本借用了 `description` 那個動作而通過條件相反、後者原本沒有檢查）、第三支柱補適用範圍（模型只有一個可動項的判斷標準篇與定義卡，第二種就是完整形態）並把兩個檢查拆開。另修支柱名的泛用詞與「掛在」的物理化錯配。

**Version**: 1.3.0 — 新增 principle 卡 teaching-article-context：教材的脈絡由三件事決定（這一篇在序列裡的位置、論證用得到的材料有沒有就地寫進去、往外的連結綁在什麼上面），從兩次全分類改寫抽出。第三項有三種強度而只有一種完整——綁在本篇模型的一個可動項上（「把其中一項換掉會變成什麼」），比列舉相鄰主題強、比「遇到 X 去讀 Y」強兩級；做不到最強的那一種代表本篇還沒建立帶可動項的模型。另記偏移的成因固定是規則錯配，而射程限制放在原則自己身上沒有效力。writing-articles.md 加對應的動筆前檢查節

**Version**: 1.2.0 — 術語探針的回答改成分四類讀。收斂度只分得出前三類，第四類是少數份有把握而它們一致指向另一個所指——這個詞在同一個領域裡已經是別的概念的名字，它在收斂度上與非通用詞落在同一區。處置比另外幾類嚴格（非通用可以就地定義後留用，同域佔用只能換掉，而且要換成描述不是同義詞），證據全在定義的內容裡，所以 prompt 要多一句「有把握的那些，寫出它指的東西」。principle 卡 term-probe-measures-register-not-invention 同步

**Version**: 1.1.0 — `managing-article-collections` 新增一節：按功能組織的模組要另給選擇一層路由。每個功能都有一節而「我這個問題該用哪一個」沒有，這是組織方式的直接結果——章節照被解釋的對象切、選擇發生在對象之間。修法是模組入口加一張問題到落點的表（很便宜、不必重寫任何一章），兩個判準：問題用讀者的語言寫不用功能的語言、承擔選擇的章節從業務事實開場不從功能比對開場（功能型章節維持原樣）。辨識訊號是章節名全部是被解釋的對象、以及使用者問「我這樣寫犯了什麼錯」而非「這個功能怎麼用」。

**Version**: 1.0.0 — 新增 principle 卡 `basics-anchor-the-advanced` 與核心原則一段：深度的分配不看主題的表面複雜度。熟悉度決定作者覺得一件事要不要解釋、要不要當推導起點，而基本功能的熟悉度最高、因此同時失去這兩個待遇；讀者的處境相反。量測：一批十篇教材裡兩個最基礎的題目產出全批最危險的兩個缺陷而兩者都不報錯。同批修兩張既有卡——`audience-is-professional-not-layperson` 補一節擋掉「讀者不是外行人所以基本可以帶過」這個誤讀（那張卡管姿態不管份量），`teaching-module-needs-derivation-anchor` 補源頭的品質測試（必須是基本機制、一句話說得完）。

**Version**: 0.99.0 — principle 卡 `cross-links-eat-the-article-they-live-in` 的修正，來自第二批異形態內容的預先登記驗證。**五種關係裡的「組成」補上方向這一維**——它原本寫成「本篇的哪一步用到它」，而十八條路由裡有兩條方向相反（目的地拿本篇的產物去用），在五種關係裡歸不進去，硬歸會讓承諾寫反。兩個方向各有自己的承諾形態。同批證實這個清單換題材仍然涵蓋：第二批替換零條（第一批的主導形態），其餘四種各自都用上了。

**Version**: 0.98.0 — 三輪十二個 frame 的審查之後的修正。**條件分支降級成五種關係型別裡的一種**（替換），另外四種各給形態——個案實跑逐條檢查二十二個連結只有一個是替換型，把它寫成通用解會逼出硬塞。**判準補上射程**：測的是以論證為交付的單篇，術語卡、目錄頁、歸納層與孤立單篇落在射程外，判準之前先過定位這一關。principle 卡另補「每一條判定都要附它的輸入」（十六條規則裡十三條的最省力遵循是腦中判一次、報告寫一句通過，而認真做過與沒做產物相同）。

**Version**: 0.97.0 — 修正 0.96.0 引入的判定條件。路由承諾原本寫成句法規則（要寫成關於目的地的謂語），多輪審查找出假陰性——「這一類的完整成員與兩地要求差在哪，在[某某]」照句法規則判成沒承諾而它已經說了交付的兩件事。判斷標準改成內容測試：遮住目的地，讀者預測不預測得出那一篇會給什麼；句型只影響命中率。這一條被改過三次而三次都是同一種失效（把形式當判準），該形態記在 principle 卡上。承重術語掃描同步修正——工具的精確度沒有量過，卡上原本寫的四取三是人挑的那四個的命中率。

**Version**: 0.94.0 — 新增「動手之前先定這一份的定位」節，放在 Core Pillars 之前。本檔的規則來自好幾個定位（agent 指令、人類教材、程式碼註解），共用之後累積成一個不記得自己來歷的池子，而沒有先過定位這一關的話，一條為 A 定位設計的規則會把 A 的體例搬到 B 上、每一步都合規。判別的軸不是「內容裡有沒有可執行的東西」——教材也給辨識訊號與可以改的東西——而是**那個動作落在哪裡：在世界上動手，還是在腦中重新歸類**。新節帶一張定位對體例對 reference 的表，以及一次五份獨立探針量出的七種裝置（表徵對映清單、檢查順序指示、配比數字、順序關鍵加顛倒的後果、可執行的操作判準、具體器具作法、序列連接詞），掃裝置比掃語氣可靠。序列連接詞那一項最容易漏：把步驟編號換成先、之後、最後只改掉一半，量測顯示「會不會放手邊」翻到教材側而「會不會照著做」仍在手冊側。處置不刪資訊，改的是框架。附 principle 卡 positioning-decides-form-before-any-rule-applies
