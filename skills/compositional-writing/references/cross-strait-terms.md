# 兩岸用語對照：先翻成英文確定意思，再選台灣用語

> **本檔位置**：`compositional-writing` 的地區用語詞庫 reference，用在讀者是台灣讀者的中文稿件。
>
> **何時讀**：給台灣讀者的稿件出現中國大陸慣用詞時、keyword bank 的地區用語 grep 命中詞時，或寫的人要確認手上的詞是否為中國大陸的慣用詞時。
>
> **不適用**：慣用語直譯（拍腦袋、靠譜、接地氣）是開放集合，詞庫列不完，要靠在地讀者冷讀，見 [regional-idioms-evade-keyword-bank](principles/regional-idioms-evade-keyword-bank.md)。稿件的讀者不只台灣時，這份的詞庫與 rg 不適用，寫的人照同樣的欄位另建詞庫。

---

## 換詞之前先翻成英文的理由

一個中國用語可能對到幾個英文概念，這幾個概念在台灣各有各的詞。「優化」在原句裡可能指 optimize（調整到某個指標的最佳值，台灣寫「最佳化」）、enhance（加強既有的功能或效果，寫「強化」）或 improve（讓對象比現在好，寫「改善」或「改進」）。寫的人把「優化」一律換成「最佳化」時，原本指 improve 的句子意思就變成達到了最佳值。所以換詞時，寫的人先把自己在這一句要說的事翻成英文、選定英文概念，再取那個概念的台灣用語。

寫的人用中文的「優化」時不必區分最佳化與強化，翻成英文時要選一個，選的依據是這一句的對象與結果。英文的 optimize 也常泛指改善，所以寫的人說不出被調到最佳值的指標時，寫「改善」（compiler optimization 這類領域固定名稱除外）。寫的人不熟那個領域、判斷不出是哪一種時，也寫「改善」或「改進」：這兩個詞只表示比現在好，不含達到最佳值或加強某項功能的意思。

「待優化」照同一個做法處理。英文的表格欄位常見 to be improved，句子常用 needs improvement（需要改進）或 room for improvement（有改進空間）。所以表格的狀態欄寫「待改善」，句子裡寫「需要改進」或「有改進空間」，並寫出要改進的是哪一項。

同一個英文詞在台灣也可能分成兩個詞，這時翻成英文還選不出台灣用語。function 在台灣分成「函式」與「函數」，中國大陸兩者都寫「函數」。寫的人依這個 function 是什麼選詞：程式裡定義與呼叫的 function 寫函式（回呼函式、使用者定義函式、純函式、高階函式、建構函式），SQL 與查詢語言內建、不是視窗也不是聚合的 function 也寫函式（`lower()`、`date()`、PostGIS 的 `ST_Distance()`、Cypher 的 `labels()`），數學與計算關係寫函數（數學的函數、SQL 與查詢語言的視窗函數與聚合函數、損失函數、神經網路的 activation function）。選詞不看句子在談它的哪一面，所以「呼叫聚合函數 SUM」仍寫聚合函數，「純函式對相同輸入回傳相同結果」仍寫純函式。

## 判斷步驟

對每一處命中各判斷一次，同一個詞在不同句子可以有不同處置。

1. **掃描**：對稿件跑 [keyword-bank](keyword-bank.md)〈地區用語 grep〉的兩條 rg。「台灣少見」那一條的命中通常要換；「台灣也常用」那一條的命中可能要留著。
2. **翻成英文**：取含命中的完整術語（配置文件、頭文件、電信運營商），把寫的人在這一句要說的事翻成英文，選定英文概念。命中的字面不是這個詞時（「直接口頭」的接口、「品質量測」的質量），這一處留著。
3. **決定是否換詞**：
   - **換**：台灣用另一個詞寫這個英文概念。人臉識別的「識別」指 recognition，換成「辨識」；通知渠道的「渠道」指 notification channel，換成「管道」。
   - **留著**：詞庫寫明台灣也這樣用的意思（identifier 的「識別碼」、same-store sales 的「同店銷售」、音響 gain 的「增益」）。字面要跟別處對得上的也照原文：引文、書名、論文題名、產品名、介面標籤、專有名詞、可執行的程式碼、指令、log、檔名、URL 與 tag。句子討論這個詞本身時同樣留著。作者自己寫的程式碼註解照一般句子判斷。
   - **判斷不出意思**：自己寫的句子，先決定要說哪個意思；轉述別人的內容，回原文、來源或作者查。查不到時，有一個台灣用語涵蓋這幾個意思就寫它（「優化」寫「改善」）；沒有時保留原詞，並寫出來源沒有說明是哪一種（公告寫「接口」，沒有說明指軟體介面還是硬體連接埠）。
4. **取台灣用語**：查下面的詞庫。完整術語不在表裡時不逐字換（頭文件是「標頭檔」，配置文件是「設定檔」，電信運營商是「電信業者」）：台灣有慣用詞就用那個詞，拿不準時查台灣官方或台灣廠商的文件；中國原廠的繁中文件可能沿用對岸用詞，不當依據。台灣沒有固定短詞時，寫出這個詞指的動作或對象，第一次出現附英文。這個詞只在特定業界通行時，第一次出現同樣寫出動作或對象並附英文，之後可以用原詞（買量第一次寫成「投放廣告取得新玩家（paid user acquisition）」，之後可以寫買量）。
5. **全篇對齊**：同一個英文概念在同一種位置（表格欄位或句子）全篇用同一個台灣用語；function 依它是程式單位還是數學與計算關係選詞，同一篇可以函式與函數都出現；兩個英文概念不寫成同一個詞（camera 與 monitor 都寫成監視器時，camera 改寫監視攝影機）。

## 把新詞補進詞庫

遇到新詞時，照〈判斷步驟〉判過之後加進對應的那一張表，再把詞加進 keyword-bank〈地區用語 grep〉，pattern 只維護那一份：台灣少有相同用法的詞加進「台灣少見」那一條，有相同用法的加進「台灣也常用」那一條。新詞的字面出現在別的常見詞裡時（「頁遊」在「網頁遊戲」裡），在 pattern 加排除條件，拿那個常見詞跑一次確認它不再命中，並確認新詞本身仍然命中。
