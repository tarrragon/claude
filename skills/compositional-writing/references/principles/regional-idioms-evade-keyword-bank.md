# 地區慣用語直譯：keyword grep 抓不到、同源讀得懂會放行

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被字句層 keyword bank 的「地區用語」grep 引用、是 [`regional-terminology-alignment`](regional-terminology-alignment.md) 的偵測維度延伸。
>
> **何時讀**：擴充地區用語掃描時、review 回報「地區用語 clean」卻被在地讀者抓到用語時、判斷漏抓的用語補進清單之後修不修得掉時。

---

## 結論

地區用語的偵測分兩層，難度不同。**單詞漂移**（同一概念在不同地區各有常用詞）的每個詞字面固定，keyword grep 掃得到清單已收的詞，清單外的詞要靠目標地區讀者指出；命中之後換不換、換成哪個詞見 [`regional-terminology-alignment`](regional-terminology-alignment.md)。**慣用語直譯**（把一個抽象動作用生動比喻包裝的口語片語）是開放集合、無法用一份短清單列舉，且每一句「語意讀得懂」，所以列舉式 grep 結構性抓不到、同源審查者也會合理化放行。慣用語直譯的真防線是目標地區讀者的冷讀，不是把 grep 的 keyword 清單加長。

---

## 為什麼慣用語比單詞難抓

### 單詞與慣用語補進清單之後的差別

單詞漂移的每個詞字面固定，能列成對照表，keyword bank 的 grep pattern 由這張對照表組成，掃到就是候選。清單不是窮舉，清單外的單詞要靠目標地區讀者指出。這種漏抓屬於 design gap（定義見 [multi-pass-review-frame-granularity](multi-pass-review-frame-granularity.md)〈補機制之前：先分 design gap 與 execution gap〉），把單詞收進清單就修得掉：之後這個詞的繁體寫法都掃得到，只有 pattern 為了避開字面相同的台灣用語而略過的組合（例如「視頻寬度」，見 [keyword-bank](../keyword-bank.md)〈地區用語 grep〉）掃不到。對照表與換詞步驟在 [cross-strait-terms](../cross-strait-terms.md)。

慣用語是開放集合：「憑感覺做決定」「可靠」「務實」各可以直譯成好幾個不同地區的生動片語。慣用語的產生是組合性的（動詞 + 比喻 + 語氣），列舉不完。單詞的清單同樣不是窮舉，差別在一個概念的寫法數得出來（default 是默認與缺省），補進這幾個詞就涵蓋這個概念；慣用語同一個意思的說法數不完，把 grep 清單加長只會追著個案跑、永遠漏掉下一個沒列到的片語，所以這種 design gap 補 keyword 修不掉，要換偵測方法。

### 同源盲區：讀得懂就放行

慣用語直譯的第二層難處是它「可讀」。跨地區訓練語料下，作者跟 LLM 審查者對這類片語都有語感、一讀就懂意思，於是同源審查者把它合理化成「雖然是那邊的說法、但讀者看得懂、可接受」——偵測即使命中，判定也放水。這跟 register 違規（否定起手、喊話、誇飾）的同源自審上限同構（見 [`multi-pass-review-frame-granularity`](multi-pass-review-frame-granularity.md)）：同源審查者跟作者共享文體 / 語料直覺、對這層有結構上限、加再多輪同源 review 都跨不過。

---

## 識別訊號

1. **成語式 / 比喻式的決策與評價詞**：把一個抽象動作用畫面感很強的口語片語包裝、且該片語偏向某個地區的高頻用法。命中訊號是「這句在描述決策 / 評價 / 程度、用了一個很生動的口語片語」。
2. **表面讀得懂、但在地不這樣說**：判斷標準不是「看不看得懂」（都看得懂），是「這個地區的人會不會這樣說」。要判定得問在地語感、不是問語意。
3. **review 回報字句層 clean、卻被在地讀者一眼抓到**：這個落差本身是訊號——clean 是「grep 清單沒中」、不是「在地讀者讀起來對」。同源 reviewer 的 clean 對慣用語層不可當真、要標「未經在地抽查」。

---

## 修法：偵測靠在地冷讀、不是加長清單

1. **詞表只收已知個案**：把已踩過的慣用語加進 keyword bank、讓存量 debt 持續可見、不再依賴記憶。但明確標「本清單是已知個案、不是窮舉」——它抓存量、不保證抓新個案。
2. **判定層交在地讀者冷讀**：新個案的真防線是作者以外、且是目標地區的眼睛。這跟 register 違規的異源複核是同一套操作——同源負責曝光候選、在地異源負責定奪。同源 review 對慣用語層的產出是「給在地人複核的清單」、不是「已複核乾淨」。

---

## 何時不算違規

- 引用對方地區的原文 / quote：保留準確性比對齊重要。
- 描述對方地區的具體社會現象本身：不是拿它當一般形容詞。
- 已滲透到在地主流語料的詞：判定要跟著讀者群更新。
- 個人風格 / 訪談保留：narrative 選擇。

判斷標準跟 [`regional-terminology-alignment`](regional-terminology-alignment.md) 一致：問「讀者地區是否單一、這個片語是不是讓在地讀者覺得出戲」、而不是「看不看得懂」。

## 判讀徵兆

| 訊號                                      | 該做的行動                                                     |
| ----------------------------------------- | -------------------------------------------------------------- |
| 出現成語式 / 比喻式的地區口語決策評價片語 | 換成在地說法                                                   |
| 想靠「加長 grep 清單」把慣用語掃乾淨      | 停——這是開放集合、清單追不完；已知個案入清單、新個案交在地冷讀 |
| 同源 reviewer 回報「地區用語 clean」      | 標「未經在地抽查」：這個回報在單詞層只代表 pattern 列的繁體寫法沒有出現；清單外的詞、pattern 略過的用法與慣用語要目標地區讀者抽查 |
| 分不清漏抓的用語補進清單之後修不修得掉    | 單詞：把這個概念的寫法收進清單後，繁體寫法掃得到；慣用語：同一個意思的說法收不完，收進清單只涵蓋那一個片語，要異源 |

**核心原則**：地區用語的偵測，單詞層的定位寫得成腳本（grep 找出已知詞的位置，換成哪個詞逐處判斷）、慣用語層不可。把慣用語當成「加長清單就能解」，是把補 keyword 修不掉的 design gap 當成修得掉的那一種；慣用語的真防線是在地讀者的異源冷讀。
