# Sentence Self-Sufficiency By Consumption Unit

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被 [reference-authoring-standards](../reference-authoring-standards.md) 引用、支撐可查詢性支柱的「行自足」義務。
>
> **何時讀**：寫或審查 checklist 項、表格格、判斷標準句這類會被單獨抽離消費的句子時；或給 LLM 讀的規範文字要新增規則句時；或讀者反映「段落簡潔到看不出議題」時。

## 核心命題

一個語句的自包含義務由它的**消費單位**決定：設計上會被單獨抽離消費的句子（checklist 項、表格格、判斷標準句、grep 命中的行、章節首句）——本卡稱**單句消費位**——必須在句內資訊自足；嵌在段落敘事裡的句子——**敘事位**——可以依賴鄰句、壓縮合法。

**資訊充足**是可檢查的正向規格、四個條件：

1. **命題完整**：主詞在場（誰）、謂語完整（做什麼 / 是什麼）、作用對象與範圍明確（對什麼）、成立條件顯式（什麼時候）、量化範圍與情態顯式（全稱或存在、強制或建議、不留給讀者推定）。省略只在成分可從句內回收時合法。
2. **指涉閉合**：句中每個代詞、縮略形、殘片名詞、在句內找得到先行詞或完整形；跨句指涉要帶復原提示——完整名詞頭先出現、殘片形後用。在單句消費位、閉合的標準是**判讀時不需先解壓**：先行詞雖在單位內、但讀者要把殘片解壓回完整概念才判得動論證的、視為未閉合。
3. **實詞可反推**：每個承載內容的詞能反推到具體機制、條件、契約；高度壓縮的謂語（「強到失實」）展開所需的內容要在句內或緊鄰處存在。
4. **一句一命題**：對仗與排比裡的每個半句能獨立判真；把多個命題壓進一個節奏單位時、每個命題各自通過前三條。複合條件句（若 A 且 B 則 C）與合連詞定義是單一命題、不觸發本條。

驗收測試是**抽離重讀**：把一個消費單位（checklist 的一項、表格的一列含鍵欄、獨立的判斷標準句）單獨交給沒讀過上下文的讀者（人或模型）、命題能不能無歧義復原——抽離的單位是消費單位、不是裸句。執行協議：執行者要**輸出復原出的命題本身**、不是回報通過與否（模型填補歧義用的正是文體先驗、會生成看似合理的復原後回報「沒有歧義」）、由作者比對復原是否等於原意；人與模型判定不同時、以不足計。第三類位置是**檢索鍵位**（title、description、表格鍵欄、卡名、anchor）：義務是識別充足（讀者能指認它索引哪個命題）、命題完整不適用、跟 metadata 精簡規範衝突時精簡優先。

正向規格是刻意的設計選擇：「避免為了美感犧牲資訊」這類負向禁令以模糊審美概念為軸、執行者（尤其是 LLM）要先自行定義「什麼算美感導向的簡潔」、而那個定義只能來自造成問題的同一個文體先驗（寫作者——人或模型——從語料學來的文風預設、機制見下段）。四條件把違規變成可指認的偏差：「缺主詞」「指涉懸空」比「太簡潔了」可執行。

## 為什麼會寫出資訊不足的句子

壓縮把解歧負擔外移：每省一個成分（主詞、名詞頭、修飾語）、句子變短、節奏變好、而解讀所需的資訊轉嫁給讀者手上的 context。線性閱讀的人類有 discourse memory、多數時候付得起；抽離消費的讀者付不起——負擔轉嫁直接變成歧義。推力是文體先驗：中文技術寫作常見四字節奏、對仗、殘句收尾的文風、寫的人（人或模型）往典型滑、且滑的當下句子讀起來「更好」——寫作者自己看不到失資訊、因為他腦中有完整 context、每個殘片對他都可回收。

中文在這裡是放大器：單字是多義語素、壓縮砍掉名詞頭、修飾語、主詞時、砍掉的正是解歧成分。放大器之上、不同消費者付不起解歧轉嫁的原因各不相同：

| 消費者 | 消費情境        | 為什麼付不起解歧轉嫁                                              |
| ------ | --------------- | ----------------------------------------------------------------- |
| LLM    | 單行檢索        | grep-friendly 設計預期句子被單獨命中、句子的指涉成分沒跟著句子走  |
| LLM    | 長 context 生成 | 模型對幾句之前定義的取用可靠度隨距離下降                          |
| LLM    | 風格繼承        | 被讀進 context 的規範文字是生成的直接素材、文風連同缺陷被輸出延續 |
| 人     | 跳讀與搜尋落地  | 掃描式閱讀直達段落中間、手上沒有順讀累積的上下文記憶              |

## Case：一條 checklist 項的兩版對照

一條 audit checklist 項的初版括號後半寫「反比結構無法用文體先驗的無意滑動解釋、所以警惕等級最高」——「反比結構」「無意滑動」是同項前分句已定義概念的**壓縮重述**、先行詞在項內、但讀者每次執行都要先把殘片解壓回完整概念才判得動論證、「解釋不成無意」這個六字謂語把一個完整命題壓縮到單獨閱讀無法復原的程度。篇章層的冷讀 reviewer 未見（順讀時殘片可回收、篇章層方法對句內壓縮結構性看不見）、由審查流程之外的另一位讀者以抽離重讀指出。修正版把後半寫成「「話最滿的段落恰好最難查證」這種全篇分布比單點升格更難歸因於無意的文風滑動」——每個指涉句內閉合、而兩版括號的總長相當：**自足的成本落在成分安排、不必然落在字數**、換掉殘片重述省下的正是讀者的解壓步驟。初版通過條件一與三、卡在條件二的解壓標準——正向規格的判決由那條標準產生。

## 自查清單

- [ ] checklist 項、表格格、判斷標準句逐句跑過抽離重讀（單獨讀、指涉能回收）
- [ ] 殘片名詞的完整形在同句、或在該術語全篇首次出現處存在
- [ ] 對仗與排比的每個半句能獨立判真
- [ ] 給 LLM 讀的規範新增規則句時、寫完先抽離重讀再入庫
- [ ] 收短句子前先判消費單位：敘事位可收；單句消費位的自足為抽離消費而存在、成本落在成分安排、字數增減都可能

## 跟鄰近原則的分工

- **名詞頭**（[compressed-chinese-terms-need-head-noun](compressed-chinese-terms-need-head-noun.md)）：那卡管單一術語壓縮後要能回答「這是什麼」；本卡把同一義務推廣到整句——句子壓縮後要能回答「誰、對什麼、什麼條件」。
- **口語精度**（[colloquial-rhetoric-erodes-technical-precision](colloquial-rhetoric-erodes-technical-precision.md)）：本卡第三條件直接沿用那卡的精度判斷標準（用詞能反推到機制 / 條件 / 契約）；那卡管詞的選擇、本卡管句的成分完整度。
- **轉換保真**（[rewrite-preserves-claim-intensity](rewrite-preserves-claim-intensity.md)）：遞迴關係——那卡的文體先驗接管描述轉換時的漂移、本卡指出壓縮到產生歧義的規範文字會讓同一機制在生成下游重演。

**核心**：句子的美感由讀過上下文的人評、句子的資訊由沒讀過上下文的消費者取——單句消費位為後者寫、四條件是它的規格、抽離重讀是它的驗收。
