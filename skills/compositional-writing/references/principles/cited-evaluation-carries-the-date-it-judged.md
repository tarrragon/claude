# 引用一份評價時，留意它評的是對象在什麼時候的狀態

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被 `references/source-to-teaching-analysis.md`〈引用評價時留意它評的時間點〉引用。
>
> **何時讀**：文章引用樂評、評測、使用心得或量測結果，或引用同時帶著評語的來源，而這份評價評的是幾年前的狀態、或被評的對象之後還在改變時；引用的是考證或鑑定的結論，或排名這類相對比較，而之後可能出現了新的證據或新的比較對象時；近期的評價找不到、把搜尋範圍擴大到更早的年份而找回一批舊來源時。

---

## 論述基礎與限制

這張卡處理的寫法：文章為了說明某個對象（一位演出者、一項產品、一套系統）在某個時間點的樣子（多半是現在），引用一份對它的評價，而那份評價評的是多年前的狀態。**評價**指評價者針對對象在某一刻的表現所做的判斷或量到的結果：樂評、產品評測、使用心得的評語，以及效能量測的數值都是；考證或鑑定的結論（一句話出自誰、一份錄音的演奏者是誰）是依證據下的判斷，也算評價。**紀錄**指同一份來源裡不帶判斷的事實：那一場演了哪幾首、那一版有哪些功能、量測用的設定。**評的時間點**指評價所評的那一刻：一場演出的日期、一個產品的版本、一次量測的日期與設定，評一張錄音時是那張錄音的版本（原始發行或某一次重製）；評的是一段期間（年度回顧、用了三年的心得）時取期間的終點；考證或鑑定取下判斷的日期，不取被考證的對象的日期。它跟評價刊登的日期可能不同。**評價所評的面向**指評語談的那一項屬性：評測談的還原速度、樂評談的音準；同一個對象在這一項上變化大，在另一項上可能沒有變。**評語依據的事物**指評語成立所依賴的事物：被評的對象，相對比較時還有比較的對象、範圍與標準，考證或鑑定時還有下判斷時拿得到的證據（完整的定義在〈修法〉連到的那一節）。

個案是一篇教讀者從演出者的背景讀音樂會選曲的文章，下面的年數都從那篇文章寫作時起算。文章逐場列出演出之後找得到的文字（署名樂評、媒體報導、主辦新聞稿）；寫到一位鋼琴家時，近兩年的場次找不到媒體樂評，委託寫作的人指示再找更早的場次。查證找回三筆：三十四年前一場獨奏會的署名樂評、八年前一場的署名樂評、三年前一場的專欄文章。初稿把三筆都寫進正文，並在彙整演後文字的表格裡把三十四年前那篇跟八年前、三年前的兩篇並列，連樂評的評語一起寫出。委託的人指出：三十四年前的感想放到現在幾乎沒有參考價值。修改後，那一場只留曲目，用來佐證這位鋼琴家把古典與當代作品排在同一場是一貫的做法；評語刪掉，表格拿掉那一列。

初稿把三十四年前的評語寫進正文，成因是查證的指令與那篇樂評的組成。查證的指令是「找有樂評的場次」，找到的每一筆都符合指令，於是都被當成收穫寫進去；指令沒有寫年限，寫文章的人也沒有在收進來之前比對評的時間點。那篇樂評又同時帶著紀錄與評價，寫文章的人需要的是紀錄（曲目），引用時把評價一起帶了進來。

委託的人之後補充了這條原則的性質：不同的東西，有效的年份不一樣。演奏家在生涯晚期成長的幅度，跟早年的演出成長的幅度不一樣；有些東西三四十年裡進步的空間並不大。所以這是一種要注意的事，不是硬性檢查的條件。

限制如下。證據只有這一個個案：「隔多久算太久」沒有量過，也沒有通用的年數；〈核心原則〉裡軟體版本、硬體、錄音與音樂廳的例子是這張卡從個案往外推的，個案裡沒有出現。各類對象變化得多快由寫文章的人依對那個領域的了解判斷，這張卡沒有提供量測，也沒有量過讀者讀到舊評價時實際怎麼理解。這張卡的推導從被評的對象在這段時間裡的變化出發；評語依據的另外兩種事物（相對比較的比較對象與標準、依證據下的判斷所用的證據）變了、評價可以重做，以及論斷寫的是評價本身時不判斷對象的變化，這幾項是從個案往外推的，個案裡沒有出現。同一篇文章留下了八年前的那篇樂評：這位鋼琴家這八年間的演奏狀態改變了多少，寫文章時沒有找到可以對照的樂評，照這張卡屬於「判斷不出來」：文章照用，寫出評的時間點與缺的那一項資訊（這八年間可以對照的演奏評價或錄音），沒有找到樂評這件事寫進交稿時附的紀錄。

## 核心原則

**引用評價之前，寫文章的人先確認這份評價評的時間點，以及讀者要判斷的時間點。** 讀者讀一篇教他挑音樂會的文章，要判斷的是這位演出者現在的演奏；三十四年前的樂評評的是當年那一晚的演奏。這兩個時間點之間，演出者的技術與身體狀態可能都已經不同，那份評語描述的就不一定是讀者要判斷的對象。評語寫得再具體、評價者再知名，都不改變它評的是什麼時候。

**判斷之前先看這份評價支撐的論斷寫的是什麼，判別看讀者拿那一句做什麼。** 讀者拿它了解評價本身的歷史（這位樂評人當年的立場、一部作品當年被怎麼接受）時，評價就是當年的事實，對象後來怎麼變不影響它；讀者拿它判斷被評的對象時，即使句子寫的是「樂評寫了什麼」（一篇教讀者挑場次的文章逐場列出樂評的評語），也要判斷評語依據的事物改變了多少。少了這一步，寫文章的人會把一份交代接受史需要的引文當成過期的評價刪掉；判別改看句子的主詞，則任何評語都能改寫成「樂評寫了什麼」而跳過判斷。

**同一份來源裡的紀錄與評價分開處理。** 那篇舊樂評寫了當晚的曲目，這是紀錄：那一晚確實演了那幾首，當成那一晚的事實引用時，三十四年後一樣為真。同一篇寫的「聲部清晰」「希望更放得開」是評價，描述的是那一晚。引用時把紀錄與評價拆開：紀錄可以用，並寫明只取紀錄；評價用不用，照下面評語依據的事物改變了多少的判斷。紀錄也有它的時間點：拿舊紀錄說明對象現在的樣子時（把舊版的功能清單當成現在的功能），同樣要判斷一次。

**一份評價有效多久，隨對象與對象所處的階段而不同，沒有通用的年數。** 同樣是演奏家，早年成長的幅度大，幾年前的評價就可能不符合現況；生涯晚期變化的幅度與方向跟早年不同，成長放慢，技術這類面向也可能退步，所以看的是評語談的那一項。哪個年齡算早年、哪個算晚期沒有界線，由寫文章的人依那一位演奏者的情形判斷。一項軟體出了新的主要版本、一台機器換了硬體之後，之前的評價評的那個版本、那一套硬體，可能已經不是讀者會遇到的；換了版本不等於每一個面向都變了，要查評語談的那一項。也有些東西三四十年裡變化不大：一張已經發行的錄音、一個已經凍結的版本、一棟沒有改建的音樂廳本身不再改變，只描述它本身、也不是考證或鑑定這類依證據下的判斷的評語多年後仍然適用。凍結只說明被評的對象沒有變；拿它跟別的對象比較的評語（「同類裡最快」）與依證據下的判斷，照下面評語依據的其他事物那一段處理。

**這是引用時要留意並判斷的事，不是一條硬性檢查的條件。** 寫文章的人問的是：從評的時間點到讀者要判斷的時間點，評語依據的事物（定義在〈論述基礎與限制〉）改變了多少。這項判斷每一次引用評價都做；沒有機械條件的是它的答案，要靠寫文章的人對那個領域的了解，所以不訂「超過幾年就不用」的門檻，也不是每一份舊評價都要拿掉。判斷之後的處置分成變化大、變化不大與判斷不出來：

- **變化大**：不把評語當成現況寫，拿掉評語，需要的紀錄照樣引用。文章另有一段交代對象過去的樣子、讀者在那一段不拿它判斷現在時，那一處讀者要判斷的是當年，可以寫成「當年的評價是……」並寫出評的時間點。
- **變化不大**：評語可以當成現況引用，並寫出評的時間點。判成這一種要說得出依據的事實（評語依據的事物在這段期間沒有改變），說不出來的歸判斷不出來；依據要哪些事實、寫在哪裡，照〈修法〉連到的那一節。
- **判斷不出來**：評語照樣引用，但寫成評的時間點當時的狀態，並寫出缺的是哪一項資訊，讓讀者拿它跟對象現在的狀態比對；缺的資訊要寫到什麼程度，照〈修法〉連到的那一節。查證的經過不寫進正文，因為它不是這篇文章要交付的內容。這一種不拿掉評語，理由是這條原則是留意項：寫文章的人拿不出對象已經改變的依據時，把評的時間點與缺的那一項資訊交給讀者，比替讀者刪掉一份可能仍然適用的評價來得保守。只寫出評的時間點而沒有寫缺什麼的，讀者拿到的仍然只是評語。

**為了滿足一個收錄條件去找證據時，找到的來源要再做一次這項判斷。** 「只收有樂評的場次」這類條件讓寫文章的人把每一篇找到的樂評都當成達標的證據。條件只確認評價存在，沒有確認它評的是什麼時候；而讀者拿這份證據去判斷的是現在。近期的評價找不到、把搜尋範圍擴大到更早的年份時，找回來的正是評的時間點比較早的那些。即使正文只寫出「這一場有樂評」而沒有引用評語，讀者也是拿「有樂評」判斷要不要去，所以這一類引用的論斷寫的是被評的對象。

**被評的對象以外，評語依據的事物還有兩種，它們變了，評語也會失效。** 評語是相對比較（「最快」、排名、「A 比 B 快」）時，比較的對象、範圍或標準變了而推翻了比較的結論，評語跟著失效，即使被評的那一個沒有變。評語是依證據下的判斷（一句話出自誰、一份錄音的演奏者是誰這類考證與鑑定）時，被考證的對象早已凍結，之後出現的文獻與檢驗結果仍然會改變證據。這兩種照同一組問句判斷，判斷的對象從被評的對象擴大到評語依據的這些事物。評價可以重做時（量測可以重跑、找得到評的時間點較近的另一份評價），先重做或換成較近的那一份，做不到才照上面的問句判斷，重跑得到的是一份新的評價；那一晚的演出這類評價無法重做，只能判斷。

## 反模式

- **把多年前的評語當成對象現在的評價**：三十四年前的樂評評語放在一篇教讀者挑今年音樂會的文章裡。
- **判斷結果不同的評價並列在同一張表、同一個清單**：表格的同一欄列出相隔三十年的評價，同一欄裡的評價在版面上沒有新舊之分，讀者要自己從年份推出哪一筆不能當成現在的評價。
- **對象已經明顯改變，卻只寫出評的時間點就當成處理過**：年份要讀者自己折算；沒有折算的讀者拿到的仍是評語（這一句是推論，沒有量過）。
- **說不出依據就判成變化不大**：三種判斷裡，變化不大的處置成本最低，只要加上評的時間點；寫文章的人拿不出評語依據的事物沒有改變的事實時，該歸判斷不出來。
- **把年數當成門檻**：訂「超過十年的評價一律不用」這類規則。對象變化的速度各不相同，同一個年數對一位年輕演奏家太長，對一張錄音沒有意義。
- **因為舊評價不能用，把整份來源丟掉**：來源裡的紀錄可能正是寫文章的人需要的佐證。
- **拿評價者的名聲抵銷時間差**：評價出自知名的樂評人、權威的評測媒體，不改變它評的是什麼時候的對象。

## 修法

照著做的問句與處置寫在 [source-to-teaching-analysis](../source-to-teaching-analysis.md)〈引用評價時留意它評的時間點〉：依序問論斷的對象、評的時間點、讀者要判斷的時間點，以及評語依據的事物改變了多少，再照處置表處置；彙整成表、擴大搜尋範圍與審查時各自怎麼做，也寫在那一節。這張卡不另寫一份步驟，因為同一套步驟寫在兩處時，修改的人只改其中一份，兩份就會給出不同的處置。〈核心原則〉主張每一份引用的評價都先判斷再決定怎麼用、同一份來源裡的紀錄與評語拆開而紀錄可以留下、判斷不出來時評語連同評的時間點與缺的那一項資訊一起交給讀者，那一節的問句與處置都從這幾項主張推出。

改寫的例子：

- 改前：「三十四年前她在音樂廳的獨奏會把舒曼、巴赫、荀貝格與普羅高菲夫排在同一場；當年的樂評寫她彈賦格時聲部的進行清晰而自然，也寫到希望她的音樂更放得開。」
- 改後（變化大，只取紀錄）：「三十四年前她在音樂廳的獨奏會就把舒曼、巴赫、荀貝格與普羅高菲夫排在同一場（曲目取自當年對這一場的樂評；三十多年前的評語不能當成她現在演奏的評價，本篇只引用曲目）。」
- 判斷不出來時的寫法：「2018 年她獨奏了這部作品的前十一段，樂評寫她把架構梳理得清晰（評的是 2018 年的演出；要有她 2018 年之後彈巴赫的錄音或樂評，才判斷得出她現在彈巴赫是不是還把架構梳理得這麼清晰）。」

| 評的時間點之後，對象換了版本、換了硬體，或處在成長快的階段 | 先查那個變動有沒有動到評語談的那一項；變化大的拿掉評語 |
| 評語是「最快」、排名這類相對比較                           | 比較的對象、範圍與標準也是評語依據的事物；判的是比較的結論還成不成立 |

| 選場次、選購的文章寫的是「某某樂評寫了什麼」「這一場有樂評」 | 讀者拿它判斷對象，論斷寫的是被評的對象；句子的主詞是評價者不改變這一點 |

| 收錄條件寫的是「有評價」「有量測」，沒有寫評的時間點       | 條件只確認評價存在；寫文章的人自己補上這項判斷                       |
| 文件訂了「超過 N 年不引用」的門檻                          | 年數不是判斷標準；改成逐份判斷評語依據的事物的變化 |
| 因為舊評價不能用，整份來源都沒有引用                       | 來源裡的紀錄可能還用得上；拆開紀錄與評價再決定                       |

## 跟其他抽象層原則的關係

- [AI 生成的內容不虛構經驗與出處](no-fabricated-experience-or-attribution.md)：那張卡要求出處只寫到驗證過的層級，管的是出處是否為真；這張卡管的是出處為真、引文也沒錯，而它佐證的對象可能已經不是讀者要判斷的那一個。兩張都把引用當成論證的一環來驗，驗的環節不同。
- [寫出特定實例的值，就取代了讀者本來要做的查證](written-value-replaces-the-readers-check.md)：同一類後果，處置不完全相同。那張卡處理文章寫出只對作者的環境適用的值、讀者照抄，修法是把值換成該去哪裡查，並指出只加「未驗證」的標註不夠。這張卡處理文章寫出只描述多年前狀態的評語、讀者當成現在的評價記住；對象變化大時同樣拿掉，判斷不出來時則留下評語並寫出評的時間點與缺的那一項資訊，靠的正是標註。這張卡接受這個差別，理由是特定實例的值讀者會直接照抄去用，而一句帶著年份與缺的那一項資訊的評語是讀者拿來參考的材料。
