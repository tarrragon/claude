# 寫作除了表達意義，還要設計閱讀的節奏、壓力與引導

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被 SKILL.md 原則 3（意圖顯性與層級貼合）與原則 6（多輪 re-read 的冷讀 frame 擴充）引用。
>
> **何時讀**：文章意義正確、審查也回報看得懂，讀者仍反應讀起來累或跟不上時；或設計冷讀審查的檢查問題時。

---

## 核心原則

**文章同時有兩個設計對象：意義（說什麼）與閱讀過程（讀者怎麼讀過去）。** 意義正確而閱讀過程沒有被設計的文章，每一行都讀得懂、整篇讀下來卻累——負擔不出現在任何一句上，出現在句與句的累積裡。閱讀過程有三個設計面。

### 節奏：字數是節奏資源，不是壓縮目標

中文是單音節語言，同樣的語意用的音節比多音節拼音文字少，朗讀與閱讀的節奏更快。需要讀者停下來思考的位置，刻意加字延長閱讀時間是合法且必要的手段——「不僅是」寫成「不僅僅是」、「差別是有無」寫成「差別是有或無而非程度上的高低」，多出來的字不承載新資訊，承載的是思考時間。精簡的義務只在檢索鍵位（title / description / 表格鍵欄，見 [sentence-self-sufficiency-by-consumption-unit](./sentence-self-sufficiency-by-consumption-unit.md) 的消費單位分工）；敘事位的字數服務節奏，該慢的位置就加字。

### 壓力：密度與指涉是相乘的負擔

高資訊密度的句子要求高理解力；不指稱人事物（位置指涉、轉喻、長代詞鏈）要求高記憶力——讀者要一路攜帶未解決的指涉往下讀。兩者疊加時每一行同時收兩種稅，閱讀負擔以壓迫力的形式出現。逐句的解碼測試（見 [decodable-from-text-already-read](./decodable-from-text-already-read.md)）管單句；本卡補總量視角——每一句都過得了解碼測試的文章，仍可能因為高密度句連續出現而整篇壓迫。診斷問句：讀到這一行時，讀者手上有幾個還沒解決的指涉、上一次可以喘口氣的句子在幾行之前。

### 引導：主動提醒與分層切入點，不要求讀者自我檢討

文章不可能要求讀者時時自我檢討。用到前置概念的位置，正形是**主動提醒**：說出這一段會用到什麼、告訴讀者可以去哪裡回顧或補充、還不熟就先去建立概念再回來——檢查的工作由文章做完、不派給讀者（考核框架的修法見 [verify-by-recognition-not-recitation](./verify-by-recognition-not-recitation.md)）。

專業識讀的落差用**一層一層的切入點**承接：術語分級（行內展開 / 連卡 / 裸用）、概念卡、讀者路線，每一層都給下一層的入口。可及性的底線：即使是高專業內容，也不寫成只有同領域小範圍頂尖讀者才能讀——語句與段落的容易理解跟銜接是最基本的要求，不是對深度的妥協；經驗差距用案例與分層補、技術深度不降。

---

## 對審查的含義

冷讀 frame 問「看不看得懂」，量的是理解的可能性；本卡加兩問，量閱讀的成本與斷點：

1. **讀起來累不累**（節奏與壓力）：這一段要讀者同時記住幾個未具名的指涉；連續幾行是高密度句、思考時間有沒有被襯出來。
2. **卡住的讀者有沒有被接住**（引導）：用到前置概念的位置有沒有主動提醒與路由；識讀落差有沒有分層的切入點。

「看得懂」通過而讀者仍反應累或跟不上時，缺的通常是這兩問。

## 判讀徵兆

| 訊號                                                 | 該做的事                                                               |
| ---------------------------------------------------- | ---------------------------------------------------------------------- |
| 連續多行高密度句、沒有襯字與停頓                     | 節奏過快——在要讀者思考的位置刻意加字延長閱讀時間                       |
| 讀到某一行要同時記住兩個以上未具名的指涉             | 壓迫力——具名、拆段、或把指涉就地解決                                   |
| 段落用到前置概念而沒有回顧提醒與路由                 | 補主動提醒：這裡會用到什麼、可以去哪裡建立概念、再回來讀               |
| 檢核段要求讀者自我檢討或自我評估                     | 換成主動提醒——文章自己把提醒與路由做完，檢查的工作不派給讀者           |
| 文章只有同領域資深讀者讀得動、理由是「內容本來就難」 | 難的是內容不是語句——語句與銜接先修到容易理解，識讀落差用分層切入點承接 |
| 審查回報「看得懂」而讀者反應「讀起來累」             | 冷讀只量了理解——補「累不累」與「有沒有被接住」兩問                     |
