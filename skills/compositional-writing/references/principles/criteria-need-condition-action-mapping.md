# 判斷標準要寫到條件層：維度清單是它的空殼

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被 SKILL.md 原則 3 的「判斷標準寫到條件層」段引用。
>
> **何時讀**：寫教學文章的判斷標準段時；或審查發現某段「列了要考慮什麼、卻判斷不出自己落在哪裡」時。

## 核心原則

教學文章的判斷標準要寫到條件層：讀者判斷得出自己落在哪一個條件、各條件的後果與理由，加上條件失效的情境。判斷標準有三個成熟度：

| 成熟度   | 形態                                     | 讀者拿到什麼                   |
| -------- | ---------------------------------------- | ------------------------------ |
| 口訣     | 無推導的結論（「不超過某個比例」）       | 一條要背的規則、換情境即失效   |
| 維度清單 | 「判斷看 A、B、C」 | 知道要考慮什麼、判斷不出自己落在哪裡 |
| 條件層 | 「A 成立時後果是 X，因為……；A 不成立時後果是 Y」＋失效情境 | 帶自己的參數判斷得出落在哪個條件、後果與理由是什麼 |

維度清單最有欺騙性：它有判斷的動詞（「判斷」「取決於」）、每個維度都有機制支撐、通過字句層與機制層的審查——卻在讀者要做決定的那一刻斷線。它是空殼，而且機制重建完成之後仍會殘留（機制正確與判斷標準到位是兩個獨立的檢查）。

驗收用**重算測試**：讀者帶自己的參數走進這一段，能不能判斷出自己落在哪一個條件，以及那個條件的後果與理由。讀完只知道「這幾項都要考慮」，這段還停在第二層。

## 條件到行動的對應屬於執行者的 surface

「A 成立 → 做 X」這種逐項對應，是寫的人在寫的當下把判斷做完、讀者照著執行的形態，適合照著執行的 agent 指令、skill 與 runbook。寫進教學文章時它是手冊的裝置（表徵對映清單、可執行的操作判斷標準）：讀者讀完會在世界上照做，而不是在腦中重新歸類，條件組合換一個就沒有路可走。教學文章交付條件、後果與理由，行動由讀者自己做出；要讓 agent 照著執行的行動對應寫在 skill。定位怎麼決定體例見 [positioning-decides-form-before-any-rule-applies](positioning-decides-form-before-any-rule-applies.md)。

## 條件不可窮舉時的合法變體

自查問句組：把決策變數轉成讀者答得出來的問題，加一條排序規則，讀者答完就判斷得出自己落在哪一種情形。它跟維度清單的差別在可答性——維度清單給名詞（「訂單信用」）、自查問句給可自答的問題（「過去幾季的承諾兌現率多高」）。

## 判讀徵兆

- 判斷標準句的動詞停在「看 / 考慮 / 取決於」、沒有寫出各條件的後果——補各條件的後果與理由。
- 讀者問「我落在哪一種情形、會怎樣」而這段沒有給出材料——重算測試失敗。
- 判斷標準段沒有失效情境——補「條件不成立時落到哪一種情形」。
- 教學段落寫成「看到 A → 做 X」的逐項對應——手冊裝置，改寫成條件、後果與理由，行動對應移到 skill。
- 批次稿件的判斷標準段句式雷同（「判斷看 A、B、C」連發）——空殼正被當模板複製，逐段跑重算測試。

## 邊界

背景與機制段不承擔判斷標準、不適用本卡；runbook 與 skill 的分支點寫給照著執行的人，寫成條件到行動的對應，不套本卡的條件層；維度清單作為條件層的前導（先列維度、再寫各條件的後果）合規，違規的是列完就收尾；探索型筆記記錄未收斂的思考、不強制到第三層，但要標明知識類型。
