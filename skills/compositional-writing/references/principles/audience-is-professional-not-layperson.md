# 讀者是缺經驗的專業人士、不是外行人

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被原則 3（意圖顯性與層級貼合）引用。
>
> **何時讀**：寫技術教材時決定讀者定位、選擇進入方式與語氣。

## 原則

技術教材的讀者是在特定領域缺乏經驗的專業人士，不是完全不懂的外行人。他們有系統思考能力、理解風險與成本、能處理抽象概念，只是沒有經歷過這個領域的具體情境。

寫法的差別在於進入方式：

| 寫法     | 預設                       | 效果                                        |
| -------- | -------------------------- | ------------------------------------------- |
| 科普宣導 | 讀者不懂、需要被說服       | 降低可信度 — 專業人士感到被低估             |
| 經驗補足 | 讀者有能力判斷、缺的是情境 | 建立信任 — 讀者在熟悉的認知框架裡接收新資訊 |

## 判讀訊號

寫教材時如果發現自己在用以下句型，代表可能掉進了宣導式框架：

- 「你可能沒注意到…」「你可能不知道…」— 預設讀者無知
- 「想像一下…」「把 X 想成 Y…」— 用比喻替代直接說明
- 「跑得好好的」「聽起來很複雜」— 用語氣管理讀者情緒
- 「其實很簡單」「說穿了就是」— 降低複雜度的假象

替代方式：直接描述情境、列出操作需求、說明不做的後果。讀者有能力從事實中得出判斷。

## 這張卡管姿態，不管份量

**最常見的誤用是把「讀者不是外行人」讀成「所以基本的可以帶過」。** 兩者無關：本卡反對的是科普姿態（故事線導入、比喻堆疊、「你可能不知道」），不是反對把基本定義寫足。讀者缺的正是這個領域的基本結構，所以基本處要寫得比進階處更完整——用中性的敘述寫足，而不是用科普的方式寫多。

判斷深度時的訊號不是主題的表面複雜度，是「讀者讀到這裡手上有什麼」。基本處讀者手上的既有結構最少、能自行補完的最少，而作者在那裡的熟悉度最高、最容易覺得不必解釋——兩邊的需求剛好反向。一次量測裡，一批教材中兩個最基礎的題目產出了全批最危險的兩個缺陷，而兩者都不報錯。

**機制：這個定位是能力宣稱，而它被當成知識宣稱在用。**「讀者是專業人士」說的是他有能力理解（了解研究方法、理解開發原則、知道如何邏輯推導、有開發經驗）；寫作當下它被讀成他已經知道（這個領域的名詞、原理與縮寫）。能力與知識是兩個不同的量，而同一句話對兩種讀法都通順，於是選哪一種由當下的方便決定，而方便固定指向第二種——省略比展開便宜。

**方向由讀者的需求決定，不由他的存量決定。** 專業讀者要的是每個流程的原因、成本與代價（這個取捨的理由是什麼、少做一層防護的風險是什麼、為什麼這裡可以忽略部分成本），以及用詞的精準（`2*4` 與 `1*8` 在執行中是兩回事，「先查看右邊再查看左邊」與「先看右邊再看左邊」得到不同結果，所以動詞與名詞不任意縮寫，每一句要讓讀者知道是什麼東西跟什麼東西產生反應、是誰做了什麼動作、對誰產生影響）。這些要求全部是更多的文字，所以這條原則按它描述的需求生效時推向展開。

**判別問句：這一處省略，省下的是讀者不需要的字，還是讀者要自己補回來的脈絡。** 答案落在第二邊就展開。

**這一節與本卡同檔是刻意的。** 本卡的失效模式正是有人只讀到半條規則——擋住「把讀者當外行人」的那句話，同時是「讀者不需要這個解釋」最有力的依據，而兩種違規在稿件上長得相反，掃其中一種的那一輪不會順便抓到另一種。把限定拆成另一個檔案會在載入時重演同一個風險。

**偵測要靠會產生輸出的動作，不能靠讀稿**：省略在產物上沒有痕跡（沒補的卡不存在、沒展開的原理不佔行數），以稿件為輸入的檢查對它全盲。兩個有輸出的做法是術語分級逐個詞跑出一張表（缺卡的格子在表上是空的而不是隱形的），以及理解取樣（讓沒有作者脈絡的讀者回報每個動作誰做的、指涉詞各指誰）。
