# 入口由違規形態寫不寫得成 pattern 決定，佔比只決定能不能原樣進清單

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被字句層的 keyword bank（一組用來曝光候選違規的 grep pattern）的用詞錯配段引用。
>
> **何時讀**：某條用詞規則已經有 grep 清單、而漏抓的實例持續從外部指正進來時；或想把一個新詞加進既有 grep 清單之前。

## 核心原則

**入口由兩件事決定：違規義項佔它全部用法多少，以及那個違規形態寫不寫得成 pattern。** 佔比只決定「原樣進清單」這一個選項可不可行，其餘的入口由形態決定；兩者都不決定這個詞要不要被涵蓋。清單是判準的一次抽樣，不是判準本身——抽到的是那些「幾乎只在違規時才出現」的詞；違規義項只佔少數的詞違規可以同樣嚴重，差別在原樣加進清單會用噪音蓋掉訊號。

入口至少有這幾種，前三種成本遞增：**原樣進清單**（違規義項佔多數）、**收窄 pattern 或加豁免子句**（違規義項少、而違規形態穩定到寫得成 pattern）、**改用探針**（形態描述得出來卻寫不成 pattern）。另外兩種不在這條成本線上：**排一輪限定 scope 的 review**（例如「這批新寫的、從外語文獻讀來的概念詞」），它是探針缺的那個偵測入口；以及**承認沒有可行的入口**，寫下「這一類目前只能靠讀的人自己注意」，比擺一個抓不到的 pattern 誠實。這份清單本身也是抽樣。三種常常同時在用：一份物理化錯配清單可以收下「撐」這類違規佔比極低的詞，靠一句豁免處理（主詞是實體或系統負載時不觸發）；形態穩定的直譯詞收窄 pattern 就抓得到；只有連穩定形態都沒有的才輪到探針。

因此漏抓一個詞之後的動作既不是「加進 regex」也不是「一律改探針」，是先算比例再選入口。兩類詞各自示範原樣加進去為什麼行不通：

- **既有義項合法的直譯**：那個詞在本語言已經有自己的義項（本義與固有的引申義都算），違規的只有從外語搭配借來的那一個。實例（中文）：「滑坡」的本義是山崩、固有引申義是衰退（經濟滑坡、成績滑坡），而「下滑」「滑落」「滑向某個狀態」都是正常用法；違規的只有 slippery slope 借來的那個義項——把一個失敗當成可以滑進去的地方、當成可數的路徑。一次全站掃描裡這個字出現兩百多處，違規集中在少數幾種寫法上。
- **詞頻過高的泛用動詞**：實例（中文）：「拿」在技術寫作裡到處都是（拿到的需求、拿去用、拿它對照自己的處境），這些全部合規；違規的只有拿一個物理取得動詞去承接認知關係那一種（「拿到的是理解」——讀書得到的是理解，不是可以拿走的物件，該說學到 / 讀出來 / 得到的教訓）。這一個的佔比沒有量測過——本卡修法 2 要求算，而寫卡當下沒有算。

原樣加進清單之後，噪音會蓋掉訊號，而下一步多半是有人把它們整條拿掉——那時被拿掉的不只是噪音，還有那條規則對這兩類的涵蓋；刪的人看的是命中率，而涵蓋範圍寫在規則正文、不在清單旁邊。收窄 pattern 與豁免子句存在的理由就是避開這個結局。

入選判準跟下面兩個探針的可信度不在同一級。前者由「噪音蓋掉訊號、蓋掉之後維護者會把整條拿掉」這個機制支持；後者各自綁在中文的句構與詞義上，換語言要重新設計，而且只有一個量測過。

## 反模式

這一類問題出現在規則由少數人維護、而執行入口是一條 grep 的體系：規則正文寫的是判準，pre-commit 或 CI 跑的是清單，兩者的涵蓋範圍不同而沒有人比對過——判準寫得越好，落差越大。執行入口若是人工或 agent review，判準可以直接被執行，「清單 vs 探針」這個分工就不是問題。

**把清單的涵蓋當成規則的涵蓋。** 「這一類唯一有穩定關鍵詞可掃」這種標註在被讀的時候會變成「掃完清單就掃完這一類」。一次實測是掃完清單、修完六十幾處、全站驗證乾淨之後，同一批內容裡仍有兩類完整的違規在。零命中是「清單沒抓到」，不是「沒有違規」。

**用清單的命中數判斷這一類清乾淨了。** 那個數字量的是清單的產能，不是這一類違規的總量。

**依賴外部指正當唯一的補漏機制。** 語言的容錯讓作者自己讀不出來——不精準的謂語通順、意思也到得了。外部眼睛有效，但它排不進行程表，把它當唯一機制等於把偵測交給運氣。反向的實例也有：既有義項探針寫進規則之後，同類的第三個實例是那條探針自己抓到的，不必再等人指出。

## 修法

1. **判準與清單分開寫，並標明清單是抽樣。** 規則正文寫可執行的判準（例如「問這個動詞照字面成立需要什麼物理條件」），清單另起一段標成「目前抽到的高密度詞」。兩者混在一起時，讀規則的人會停在清單。
2. **新詞進清單前先算違規比例、再看形態，然後選入口。** 全站掃一次那個詞，數違規佔多少。比例高就原樣進清單；比例低而違規形態寫得成 pattern，收窄 pattern 或加一句豁免；形態描述得出來卻寫不成 pattern，才輪到探針；連形態都不穩定的，剩下的是排一輪限定 scope 的 review 或明說沒有入口。第三個實例是「承載 / 載體」——它照物理化錯配的判準成立（承載要有重量與支承面，而「即時反應」「功能」都沒有），佔比低而形態穩定，屬於收窄 pattern 那一格，而清單抓不到它。跳過計數直接選入口是這一步最常被省掉的部分。
3. **補語型態探針**（抓泛用動詞頂替具體關係）。**這一條綁在中文的分裂句構上，換語言要另找對應的位置。** 中文的「⋯⋯的是」後面接一個完整斷言時，前面那個動詞值得回頭看——精準的認知動詞（學到 / 看出 / 意識到）容得下子句，而物理取得動詞（拿到 / 抓到）接上去會讀不順。與語言無關的那一層是：**不精準的謂語在需要接子句時會接不下去，接不下去的那個位置就是探針的落點**；各語言要自己找出哪個句構會讓它現形。目前是候選訊號而不是已驗證的探針：只有一個實例，沒有掃過全站的真陽性率，也沒有跨批驗證——照上一條的要求，它自己還沒過那一關。
4. **既有義項探針**（抓外語隱喻直譯）：把那個詞在本語言的**全部**既有義項列出來（本義與固有的引申義都算），再問句子用的是哪一個。滑坡的本義是山崩這個地質事件、固有引申義是衰退（經濟滑坡、成績滑坡），兩者都不容許「另一條滑坡」這種把它當成可數路徑的用法——那個用法只在英文 slippery slope 裡成立。只列本義會誤判：漏掉衰退這個引申義的話，「成績滑坡」會被判成違規。詞典查得到不等於這個用法成立，這個探針要抓的正是那個落差。它沒有偵測入口——這是判定程序，要先有人懷疑某個詞才跑得起來。懷疑有兩個排得進行程的來源：讀的時候卡了一下卻說不出哪裡怪，以及某個概念本來從外語文獻讀來、這是第一次用本語言寫它。
5. **換詞時同義詞要分散。** 一個泛用動詞換掉之後，替代詞按語境各自選（拿到 → 學到 / 讀出來 / 掌握 / 得到的教訓），不要一律換成同一個——一律替換會用新模具換掉舊模具。

## 判讀徵兆

| 訊號                                                 | 該做的事                                                             |
| ---------------------------------------------------- | -------------------------------------------------------------------- |
| 某條用詞規則的漏抓實例持續從外部指正進來             | 不要先擴充清單；先算那些詞的違規比例，低的改做探針                   |
| 一個詞有既有義項、而句子用的是外語搭配裡的那個       | 既有義項探針命中；本義與固有引申義都列出來，再問句子用的是哪一個     |
| 「⋯⋯的是」後面接的是完整斷言而不是名詞組             | 前面那個動詞多半選錯；換成容得下子句的認知動詞                       |
| 掃完清單、全站零命中，而規則涵蓋的範圍描述得比清單廣 | 零命中只證明清單沒抓到；規則正文與清單要分開寫，並標明清單是抽樣     |
| 想把一個高頻常用詞加進 grep 清單                     | 先掃一次數違規佔比；佔比低就會用噪音蓋掉訊號，下一個維護者會把它拿掉 |
| 換掉一個泛用動詞時所有位置都換成同一個替代詞         | 那是用新模具換舊模具；替代詞按語境各自選                             |

## 跟其他原則的關係

- [word-choice-fits-concept-attributes](word-choice-fits-concept-attributes.md)：直接的上游，本卡只動它的偵測層。用詞錯配的**判準**沒有問題（「滑進去的失敗」「拿到的是理解」照它的判準都成立），被推翻的是操作化時加上的「這一類唯一有穩定關鍵詞可掃」。
- [avoid-overused-generic-words](avoid-overused-generic-words.md)：軸不同的姊妹——那張的訊號是**密度**（同一個泛用詞反覆出現，它的清單同時含名詞與動詞），本卡的訊號是**單次出現時謂語與賓語的關係對不上**。也解釋了為什麼「拿」這種高頻詞不該原樣加進那張卡的 grep 清單。
- [regional-idioms-evade-keyword-bank](regional-idioms-evade-keyword-bank.md)：同一個結構在地區用語軸上的實例——grep 抓不到、同源讀得懂會放行。本卡給出那一類抓不到的入選判準（違規義項佔該詞用法的比例太低），並把「只能靠在地讀者」補上探針；目前兩個探針裡只有一個有偵測入口。
- 字句層另有一條對稱的規則：**keyword bank 的命中是候選不是判決**——命中之後要一個語意判定步驟（引號內的反例引用、主詞本來就是實體的用法都合規），否則偵測成功而判定失敗。那條處理偽陽性，本卡處理偽陰性（沒命中不表示沒有）。兩者合起來說明關鍵詞只適合當入口的一部分，兩端都要有別的機制接。
- 另一條同型的是 **register 違規的偵測可機械化、判定要靠文體異源的眼睛**：作者讀不出自己的語域，共同機制跟本卡一樣是語言容得下、通順度不下降，因此同源自審回報的「clean」不可當真。差別在那條的最後一關是異源的人（由作者以外、文體不同的眼睛複核；同一位作者自己回頭掃讀不出這一類），本卡想把其中一部分換成可排程的探針、目前只換掉一半。
- [cadence-homogenization](cadence-homogenization.md)：換詞時同義詞要分散那一條的理由住在那裡。
