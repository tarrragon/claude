# 文章的連貫靠鞏固形狀、不靠讀者的記憶：每一節攜帶它與其他節的內容關係

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被 SKILL.md 原則 3（意圖顯性與層級貼合）的形狀鞏固段與字句層 keyword bank 的「脈絡懸置」類引用。
>
> **何時讀**：文章每一節單獨讀都對、整篇卻讀起來割裂時；讀者中斷後回不到脈絡時；或稿件出現「等下再討論」「前面兩個小節」「用一句話總結」「分成兩組、第一組……」這類指涉時。

---

## 核心原則

**文章的連貫是形狀問題，承載它的是文本、不是讀者的記憶。**讀者的工作記憶要當成隨時會清空的——脈絡必須能從讀者當下所在的任一節點就地重建。

做法是讓每個結構單位（節、段、清單項）攜帶它與其他單位的**內容關係**：誰給出定義、誰在同一個問題上走不同的邏輯、誰承接誰留下的問題、誰要先分開前面幾個都沒有分開的東西。當每一節都攜帶關係，讀者從任一切面都推得出其他切面——忘記細節的讀者用不著回頭重讀，讀到哪裡都能把情境找回來。跨屏的位置關係（前面、後面、等下）承載不了這件事：位置是排列的 derivation，讀者中斷後不持有那張排列地圖。指涉與目的地在同一屏時不受此限，那時工作記憶不參與。

設計條件取自 ADHD 讀者的認知現實：注意力隨時中斷、工作記憶不可依賴、任何「記住前面講過的 X」都是不可靠的指令。而 ADHD 讀者只是這種脈絡隨時清空的狀態的常駐版本——任何讀者被打斷、隔天續讀、或從搜尋直接落在中段，回到文章時同樣不持有前文的脈絡。能力強的讀者會自動補完文章的形狀，所以割裂對作者與同源 reviewer 都不可見；驗收要用不會補完的讀者（低階模型探針從中段讀起）才量得到。

## 四種把脈絡寄存在讀者記憶裡的形態

| 形態     | 例句                           | 失效機制                                                   |
| -------- | ------------------------------ | ---------------------------------------------------------- |
| 前向懸置 | 「等下再討論」「後面會提到」   | 給讀者一張沒有內容的欠條；讀到目的地時懸置早已被忘記       |
| 位置回指 | 「前面兩個小節就是講這個狀況」 | 解碼需要位置地圖，而讀者（尤其中斷後）不持有它             |
| 壓縮總結 | 「用一句話總結」「一言以蔽之」 | 把形狀的交付推遲到文末一次補交；沒跟上的讀者一句話也救不回 |
| 列舉鳥瞰 | 「分成兩組，第一組四本講……」   | 從上方描述地圖，要求讀者 hold 住整張清單才能繼續讀         |

前三種是句式，掃得到；第四種是結構，要用判斷標準看。列舉鳥瞰的失效在於它的消費方式：讀者必須把「兩組、四本、各講什麼」整批裝進工作記憶，後面的分節內容才對得上號。注意力在列舉途中斷掉的讀者，帶走的是零——他既沒拿到成員、也沒拿到關係，而列舉句讀起來資訊密度很高，作者會以為交付過了。

前向懸置有一個合法的近親：**帶內容名的前向路由**。「這個批評成不成立，取決於單元怎麼定義——那正是 C 那本要處理的問題」同樣指向未讀的內容，差別在它把目的地用內容具名（誰、處理什麼問題），讀者當場拿到一條關係，忘了也能靠名字找回去。違規的判定看指涉攜帶什麼：只有位置或時間（等下、前面、下一節）是違規，攜帶內容名（最好再帶連結）是路由。

## 修法：關係鏈與錨點路由

列舉鳥瞰的替代是**關係鏈**：成員逐個進場，每一個由它與前一個成員的內容關係引入——A 給出原始定義；B 在同一個問題上跟 A 走了不同的邏輯；無論選擇哪一種做法，做完之後要評估產出時用 C；產出的執行交給機器時，D 要先分開的是前面三個都沒有分開的兩種活動。每一環都接在讀者剛讀完的那一環上，工作記憶的負擔恆為一；而從任何一環讀起的讀者，光憑那一環的文字就知道自己在整篇的什麼位置。

錨點路由是機械面：關係詞旁掛連結（篇內 `#` 錨點或站內路徑），讓「找回情境」的成本是一次點擊、不是一次重讀。多分支結構（一個情境分出 A / B / C / D 四種應對）尤其如此：各分支錨到自己的段標、分支之間提到彼此時用內容名加錨點互指，讀者從任一分支都回得到分流點。篇內錨點會不會因為段標改字而靜默失效，取決於工具鏈驗不驗它——這一項要先查證再決定要不要人工維護：有些連結檢查工具把篇內錨點納入 error 層，有些完全不驗，後者才需要在改段標時 grep 一次指向它的錨。

## 鞏固形狀動的是指涉的載體

重複已講過的概念是把同一資訊再放一次：文章變長、形狀沒有變清楚，還會養出重述型總結段那種補丁（總結段是正文發散的訊號、該重組正文不該補丁）。鞏固形狀動的是指涉的載體——用關係語言取代位置語言、用內容名取代時間詞——多數情況是代換不加字。判別方式：一段修改若只是把某節的內容在別處再講一次，是重複；若是讓某節說出它與其他節的關係，是鞏固。**節首用一句重述定義或關係，屬於鞏固**——它服務的是從任意節點進入的讀者；同一句話寫在段與段之間、把線性讀者剛讀完的再摘一次，就是回收、要刪。分界在服務對象，不在句子長什麼樣。

## 連不進關係網的段落是拆分訊號

觀點彼此獨立與彼此對立的內容，都接得進關係網：對立是關係（「B 在同一個問題上不同意 A」），獨立也是關係（「立場選定之後仍然要回答的問題由 C 承接」）。一段內容對其他各節說不出任何內容關係時，正確的處置是把它視為拆分候選——它可能屬於另一篇，把它獨立出去、在本篇留一條帶內容名的路由；硬寫轉場句把它黏在原地，產出的正是位置語言（「另外值得一提的是」「回到正題」），黏合的痕跡比缺口更難修。

## 這一組三張卡的粒度與順序

連貫的檢查分三層，粒度由粗到細，順序不可顛倒——粗的層沒收斂就往下走，會被大量細層 finding 淹沒，而那些 finding 多數在粗層修完之後自動消失：

| 層         | 卡                                                                                 | 管什麼                                     |
| ---------- | ---------------------------------------------------------------------------------- | ------------------------------------------ |
| 命題層     | 低階模型讀者探針（多份獨立理解之間的分歧）                                          | 讀者實際帶走的命題對不對                   |
| 節層       | 本卡                                                                                 | 節與節有沒有攜帶內容關係（形狀）           |
| 句層       | [coherence-by-advancing-not-recapping](coherence-by-advancing-not-recapping.md)      | 句與句的方向（推進還是要求讀者回頭）       |
| 詞與語法層 | [translation-forces-disambiguation](translation-forces-disambiguation.md)            | 一個詞、一個語法項有沒有兩種以上的落地方式 |

## 判斷標準

任選一節、遮住其他節，問：**只憑這一節自己的文字，說得出這一節在整篇的什麼位置、跟哪些節是什麼關係嗎。**說不出的節就是割裂點。全篇層級的對應問題是：讀者從任一節進入、中斷、再回來，能不能不重讀就把「這篇在回答什麼、我讀到推導的哪一步」重建出來。

驗收可以用理解探針執行（低階模型讀者探針：派多個低階模型、用逐字相同的指令、不給審查框架、只問理解不問評價）：讓探針從中段某一節開始讀，回報「這一節在講什麼、它跟前後各節是什麼關係、讀完這一節之後該去哪」。回報裡出現「文章沒說」的位置就是形狀缺口。

## 判讀徵兆

- 掃句式層候選：`rg "等下再|稍後再|之後會(講|談|提到)|後面會(提到|講|說明)|下面會(提到|講)|如前所述|前面(提過|說過|講過|幾個小節|兩個小節)|上[一面](提到|說過)|用一句話(總結|概括)|一言以蔽之"`。命中是候選——緊鄰的近距指涉（「見下表」而表在下一行）、「」內引用、已具名對象的向後回指合規；判定看指涉攜不攜帶內容名。
- 掃列舉鳥瞰候選：`rg "分成[兩三四五]組|第[一二三四]組"`。緊鄰表格或清單、且各成員隨即具名展開的合規；宣告分組後成員以「第 N 組」身分在後文登場的違規。
- 審查全部通過、冷讀者仍回報「讀起來散」——能力強的審查者補完了形狀，換不會補完的讀者再量一次。

## 什麼時候不成立

- 查表型內容（規格表、判讀徵兆表、checklist）：消費單位是逐列查詢或逐項執行，本來就不依賴線性脈絡，各列的自足義務由 [sentence-self-sufficiency-by-consumption-unit](sentence-self-sufficiency-by-consumption-unit.md) 承接。
- 刻意的多入口 hub 頁（目錄、MOC）：每個條目本身就是路由，條目之間互相獨立是設計。
- 緊鄰的近距前向指涉：「做法如下」後面緊接清單，指涉與目的地在同一屏，工作記憶不參與。
