# 先佔位、冒號或括號之後才補出內容：同一個對象在一句裡講兩次，佔位指的內容只有一句話時刪掉佔位

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被字句層 keyword bank 的〈先佔位、冒號或括號之後才補出內容〉引用；判讀問句、合規邊界與嚴重度以 bank 那一條為準，本卡的〈核心原則〉與〈判讀徵兆〉是它的推導；修法與例子以本卡為準。
>
> **何時讀**：讀到或寫出「差別落在沒達到的那一項（A、B 或 C）」「判斷標準落在這裡：……」「理由就在這裡：……」這類句子，要判斷它是不是把同一個對象講了兩次、該怎麼改成對象只出現一次時。

## 論述基礎與限制

這張卡處理的句子形態：一句話的動詞（落在、在、出在、在於、是）後面先寫一個佔位，冒號或括號之後才寫出佔位指的內容。佔位是指示詞片語或泛稱，例如「那一項」「這裡」「這個語言的性質」「四件事」，它指的對象要讀到冒號或括號之後才知道。

這張卡來自一篇音響教學文章裡一段的修改。原句是「有一方沒達到時，聽得出的差別落在沒達到的那一項（頻率響應的傾斜、失真或底噪）」。審稿的人指出，「落在」這種寫法可以直接寫成「頻率響應的傾斜、失真或底噪，某一項的偏差就是聽得出的差別」；動詞換成「在」，句子一樣冗餘，要的是同一個對象只講一次、句子乾淨、重點清楚。中間有一版保留了佔位與冒號，把動詞換成「就在」，同時在冒號之後補了三項門檻的數值（「可能聽得出的差別就在那一項：」），就是審稿的人說的「換成在一樣冗餘」。

寫這張卡的 agent 在一個教學內容集合上做了一次偵測量測：排除歸納卡與自動產生的副本之後共 3749 個 Markdown 檔，依路徑排序。下面的「抽象名詞清單」指代價、理由、差別等 18 個抽象名詞，regex 是 `(代價|理由|差別|差異|問題|教訓|標準|原因|根因|重心|重點|關鍵|決定|成本|風險|責任|好處|來源)`：

- 只看詞彙，抽象名詞清單緊接 `(落在|出在)`：157 處，沒有逐處判。這條 pattern 也命中內容緊接在動詞後面的句子，例如「問題出在測試隔離」，所以只看詞彙分不出這張卡的形態。
- 窄版（這次加進 bank 的 pattern）：抽象名詞清單 `[^。，；：（]{0,6}(落在|出在|在於)[^。，；（]{0,12}(那|這|其中|某)[^。，；]{0,10}[（：]`，13 處，逐處判定：
  - 3 處是這張卡的形態：「問題正好落在最需要它的那個情形上：」、「判斷標準落在這裡：」、「理由落在這個語言的性質上：」。
  - 1 處判不定：「教訓落在這：」，冒號之後寫的是事故經過，教訓寫在下一句，「這」也可能指前一句。
  - 3 處佔位指的內容不只一句話：兩處接段標，一處接六個各自成段的粗體項。
  - 5 處佔位指的是冒號之後的內容以外的對象：承擔的一方（「代價落在使用者這一端：」、「代價落在寫入那一側：」）、範圍（「『拿前一筆比較』那一族問題」）、前文（「這兩段」、「那件處理本身」指同一句前半的執行者）。
  - 1 處的內容寫在動詞後面。
- 寬版：把窄版的動詞換成 `(在|是)`，67 處；「在」也命中落在、出在、在於，窄版的 13 處都在裡面。依路徑排序取第 1、5、9……處，共 17 處，逐處判定：3 處是這張卡的形態（「關鍵就在這：」、「……的理由就在這裡：」、「根本差異在這裡：」）；1 處判不定（「判斷標準還是那句『跟誰走』：」，內容已經接在動詞後面，「那句」又回指前文）；5 處佔位指的內容不只一句話（程式碼、條列、段標，以及「代價的形狀具體是這樣：」接的好幾句段落）；8 處佔位指的是別的對象或內容寫在動詞後面。

限制：證據只有一個個案與一次量測；命中的判定由寫這張卡的 agent 做，它手上有寫作時的脈絡，沒有用沒讀過這次討論的讀者或探針量過讀者的實際負擔。窄版與寬版兩條 pattern 都只收抽象名詞清單裡的主詞，主詞不在清單裡的同一個形態（「瓶頸出在那一段（資料庫的連線池）」）掃不到。佔位寫在主詞位置的同一種冗餘（「那一章的判斷標準在這裡同樣適用：」，冒號之後解開的是主詞）不在這張卡的定義裡。

## 核心原則

**佔位指的就是冒號或括號之後的內容時，同一個對象在一句裡講了兩次，佔位是冗餘。** 判讀的方法是問佔位指的是什麼：「沒達到的那一項」是哪幾項？答案是括號裡的頻率響應的傾斜、失真或底噪；「理由落在這個語言的性質上：引擎執行的是計畫」裡，「這個語言的性質」是什麼？答案是冒號之後的「引擎執行的是計畫」。答案就在冒號或括號之後時，句子先給讀者一個還沒有內容的指涉，讀到冒號或括號才解開（這是寫這張卡的 agent 的閱讀判斷，沒有用探針量過），句子要交付的內容被推到句尾。

**佔位指的是別的對象時，這張卡不處理。** 「代價落在寫入那一側：每插進一列，資料庫要去父表確認那個值在不在」裡，問「寫入那一側」是什麼，答案是承擔代價的一方，冒號之後說的是代價怎麼發生，兩者不同。範圍（「那一族問題」）、前文（「這兩段」）也一樣。括號只是舉例時（「延遲來自那幾個外部呼叫（例如付款閘道）」），佔位指的範圍比括號裡的內容寬，也不是同一個對象，佔位保留。標明後文文類的標記（「具體是這樣：」「舉一個例子：」）指的是「後面是示範」，也不是冒號之後的內容，保留。這類句子的動詞是「落在」這類空間譬喻時，另照 [結構譬喻頂替主詞與動詞](structural-metaphor-replaces-actor-and-verb.md) 的判讀問法判。

**冗餘來自句子的結構。** 審稿的人判斷動詞換成「在」仍然冗餘；換成「出在」「在於」是依同一個結構推論的，佔位與冒號或括號之後的內容都還在。寬版裡同一個形態也用「在」寫得出來（「理由就在這裡：」）。所以只換動詞不算改好，要動的是句子的結構。

**一種可能的成因是寫作者思考的順序。** 寫的人先想到類別（「差別在哪一項」），再去找成員，句子照思考的順序寫下來，類別與佔位就留在成品裡。這是推論，沒有草稿歷史可以佐證。

**佔位指的內容不只一句話時，冒號引出合規。** 判的是冒號或括號之後現在寫成的樣子：到第一個句號為止是一句話，分號串起的幾項仍在一句裡；不先把好幾句併成一句再判。佔位指的是好幾句的段落、一份條列、幾個段標或一段程式碼時（「根因多半是下面三類：」接三個段標），句子沒有地方放下它，冒號引出的是一段結構，佔位是必要的引出。

**帶數字的佔位，數字一律拿掉。** 「長期要守住的是四件事：配額不被打爆、髒資料不污染統計……」的「四件事」也是佔位，而且多帶了一個寫死的數字：內容增減一項，數字就過期，跟程式不把變數的值寫死是同一個理由（審稿的人的判定）。冒號之後只有一句話時，刪掉佔位，把成員寫進句子；冒號之後是清單時，引出句保留、不寫數字（「長期要守住的事：」接清單）。介紹另一份內容時的計數另見 [摘要另一份內容時寫出成員](counted-summary-delivers-only-the-length.md)。

## 反模式

- **只換動詞**：「差別落在那一項（A、B、C）」改成「差別在那一項（A、B、C）」，佔位與括號裡的內容都還在。
- **刪掉括號、留下佔位**：「差別落在沒達到的那一項」讀者不知道是哪幾項。
- **把成員改寫成另一個抽象名詞**：「差別落在量測的偏差上」，成員不見了。

## 修法

1. 問佔位指的是什麼，確認答案就是冒號或括號之後的內容。
2. 那段內容只有一句話時，刪掉佔位，把內容寫進句子：接在動詞後面，或寫到主詞的位置；原本的抽象名詞可以留下，動詞寫出實際的關係（是、來自、造成、取決於）。不只一句話時（好幾句的段落、條列、段標、程式碼），不改。
3. 檢查：原句的條件、範圍、門檻、情態（可能、多半）、主詞的所屬，以及佔位本身帶的限定、分類與評價（「失敗的那一個」「這個語言的性質」「最需要它的」），改寫之後都還在，寫在同一句或緊接的下一句；刪掉的只有佔位裡的指示詞。改寫後的句子再照字句層 bank 掃一次，換上的寫法可能落進另一類。

修法的例子：

- 「有一方沒達到時，聽得出的差別落在沒達到的那一項（頻率響應的傾斜、失真或底噪）」→「有一方沒達到時，頻率響應的傾斜、失真或底噪，哪一項沒達到門檻，聽得出的差別就來自那一項」。
- 「判斷標準落在這裡：讀到用它的那一行時，方向自己說得出來。」→「判斷標準是讀到用它的那一行時，方向自己說得出來。」
- 「production write 要有 idempotency 設計的理由就在這裡：因 busy 失敗的寫入可以用同一個 key 安全重送，已經成功的不會被寫第二次。」→「production write 要有 idempotency 設計，理由是因 busy 失敗的寫入可以用同一個 key 安全重送，已經成功的不會被寫第二次。」

| 徵兆                                                                                          | 判讀                                                           |
| --------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |

| 答案是好幾句的段落、一份條列、幾個段標或一段程式碼                                            | 冒號引出的是一段結構，合規                                     |

| 改寫時只換了動詞，佔位與冒號或括號還在                                                        | 句子的結構沒有改，冗餘還在                                     |

## 跟其他抽象層原則的關係

- 重點優先陳述（bank 的〈正向陳述優先〉）是最接近的原則。那條原則處理的是核心概念被擠到否定句「而是」之後；這張卡處理的句子先用佔位指向核心內容，再從冒號或括號之後補出來，同樣把重點推到句尾。
- [結構譬喻頂替主詞與動詞](structural-metaphor-replaces-actor-and-verb.md)：兩張卡都談到「落在」。「落在」後面的佔位指的就是冒號之後的內容時，歸這張卡，換掉動詞仍然冗餘；佔位指的是別的對象（承擔的一方、範圍）時，這張卡不處理，照那張卡的判讀問法判。
- [名詞要求的「誰的、什麼的」也是槽位](noun-without-its-owner-passes-the-slot-check.md)：這種句子的抽象主詞（差別、原因、代價）正是那張卡列的、要寫出所屬的名詞。修法把內容接在它後面，名詞的所屬由內容交代。
- [切開一個集合之前先寫切分的依據，再替每一塊命名](unnamed-halves-are-unextracted-variables.md)：那張卡的「一部分」「另一半」是還沒命名的指涉；這種句子的佔位也是還沒解開的指涉，差別在它的內容就寫在同一句的後半，修法是把內容搬到前面，不必另外命名。
- [一組並列的括號各裝不同東西時，讀者會先找一條統一規則](parallel-parentheses-imply-a-uniform-relation.md)：那張卡處理一組括號之間的關係；這張卡處理一個括號跟它前面的佔位指同一組成員的情形。
- [摘要另一份內容時寫出成員，計數只告訴讀者清單有多長](counted-summary-delivers-only-the-length.md)：那張卡處理介紹另一份內容時只寫計數；這張卡處理同一句裡先用「四件事」佔位、冒號之後才列成員。兩張卡都要求拿掉數字。
- 「修法是新違規的來源、且常引入同類變體」這條原則：這張卡的來源個案裡，只把「落在」換成「就在」的那一版修法留下了同一個結構，正是這條原則說的同類變體。
