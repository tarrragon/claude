# 結構譬喻頂替主詞與動詞：分類寫成「線」、書「承接」一個「面」、讀者「走」到某篇、判定「住在」某篇，新稿與集合裡的舊文章用的是同一組詞

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle），被字句層 keyword bank 的「結構譬喻頂替主詞與動詞」類別與「批量 sibling 寫作的生成端輪替」那一段引用。
>
> **何時讀**：一個內容集合用「這條線」「各接一個面」「由 X 承接」「走 [某篇]」「判定住在某篇」「X 的決定落在 Y 上」這類詞組織自己，或要以集合裡的舊文章為範本寫新文章時。

## 論述基礎與限制

一個書單集合早期寫成三條「書線」，各篇用「這條線處理的是…」「另外兩條線」「三本各接一個面」「由 X 承接」「走 [某篇]」「判定住在某篇」「這條線的決定落在錢上」這組詞組織內容。寫新書單的 agent 以這批舊文章為範本，七個新檔的初稿每一個都用了同一組詞。審稿的人指出三類缺陷：「這條線」當主詞（單位名應該是「書單」）、「X 的決定落在 Y」把讀者做的決定寫成書單的屬性（應寫「X 書單討論的主題放在 Y 上」）、「四本各接一個面」（新稿初稿裡的一句）是廢話，而且省略了主詞、用錯了動詞（應寫「這四本各自討論不同的面向」再逐本寫出）。

量測有三組，都用同一組關鍵詞計命中行數（「線」：`這條線|那條線|兩條線|三條線|四條線|條線的|書線|一條線`；「接與面」：`承接|接得住|接住|各接|接一個|一個面|那一面|這一面`；「決定」：`決定落在|決定的對象`）：

- **舊文章**（47 個檔，含目錄頁）：104／97／6 行。
- **新稿初稿**（七個檔第一次寫入的內容）：每個檔都有命中；新稿出現了舊文章沒有的形態，例如「走《X》」在舊文章是 0 處、在新稿初稿有 7 處，「承擔的角色」舊文章 7 處、新稿初稿 13 處。
- **同一個網站的其他集合**：用本 skill bank 的 pattern 掃到 713 行、454 個檔，等距抽 12 處，約 8 處是同一族的譬喻（「先承接…議題」「該章同時承接」「主體這條線」「內容住在文章裡」「走 [某篇]」）。

所以這組詞不是那一個集合獨有的；新稿與舊文章用同一組詞，有兩個成因說得通：新稿以舊文章為範本照抄，以及寫新稿的同一個生成端自己就有這組用詞習慣。這次的資料分不開兩者。修完之後，那個集合用同一組關鍵詞剩 3／23／0 行，逐處判定為合規（指職涯路徑的「技術路線」、引號內示範對話裡指工作流的「那條線」、改寫後的「一個面向」）。

規則類文件（規則檔與 skill）也大量用住在、落在、住址、承接說內容寫在哪裡，這張卡建立時沒有判定那些用法。後來用兩組探針量過讀者讀出的意思跟本意是否一致。兩組的做法相同：作者在派發之前寫下每一句的本意，派出三份低階模型探針，指令逐字相同，要每一份把每一句改寫成不含譬喻的白話，寫出實際做事或被描述的是什麼、還缺什麼資訊，並標出不確定的詞。

- **規則檔原句那一組**：16 句取自規則檔與 skill（四個詞各 4 句），另加一句對照句。16 句 × 3 份共 48 次解讀，最後讀法都跟本意一致，其中一份對一句的「住在」標了不確定（寫在，還是負責決定）。這一組的證據力弱：探針在那個專案底下派出，系統提示載入了全部規則檔，四個詞在其中各出現 11 到 35 行（用專案的詞頻工具量），17 句裡有 7 句逐字或近逐字就在系統提示裡，其中一句連意思都寫在括號裡；題目也沒有反例，分不出讀對的原因是句子本身還是系統提示。
- **補上反例那一組**：補上逐字出現與反例兩個缺口。12 句取自 skill 的 reference 與 principle 卡（這些檔不載入系統提示；其中 2 句作者改寫過主詞），6 句是那個書單集合已判為違規的句型（「這條線處理的是…」「這三本各接一個面」「另外兩條線…」「財務書單的決定落在錢上」「這個議題由課程承接」「這個判定住在另一篇」），另加一句對照句。主詞是線、面的 3 句與轉化句「決定落在錢上」，三份都標不確定，說不出實際做事的是什麼。「承接」的 3 句：「Given 須承接前序狀態」三份都讀成延續；「由課程承接」三份都讀出兩種以上的意思（涵蓋或負責教、接續、移交）；「三類 case 適合不同承接深度」三份都讀不出深度量的是什麼。住在、落在、住址而主詞是實際對象的 11 句（含書單集合那一句「判定住在另一篇」），9 句三份都把這個詞讀成寫在、位於、屬於其中一個，其中兩句標的不確定在別的詞上；「優雅住在作者的審美裡」被讀成「來源」，三個詞都換不了；「那是問 3，住在本檔」一份分不出指答案寫在本檔，還是問題屬於本檔的範圍。位置沒寫名字的句子，缺的是「哪一篇」這類指涉。

補上反例那一組仍有一項限制沒有排除：探針還是在那個專案底下派出，系統提示裡那時的規則把住在、落在解釋成內容寫在哪裡（「推導住在 report 卡」就是那裡的例句），所以住在、落在讀對的結果只是上限。有鑑別力的是另外兩類：書單句型在同一份系統提示下仍然讀不出實際做事的是什麼；「承接」在那份規則裡得到同樣的解釋，仍然被讀出兩種意思。

兩組合起來，分界在兩件事：主詞是結構譬喻還是實際的對象，以及這個詞換成寫在、屬於、位於之後剩一個意思還是兩個；位置是否寫出名字不影響分界。探針的任務本身就是把每一句改寫成不含譬喻的白話，所以判定的換詞那一步照它們做的事寫成換詞測試：讀對的句子換出來只有一個意思；讀錯或讀出兩種意思的句子，三個詞都換不了，或換出兩個意思。判定寫在〈修法〉的「判讀分兩種問法」那一段之後。補上反例那一組裡，書單集合那一句「判定住在另一篇」也讀得對，所以內容集合裡同一型的用法（〈修法〉第 3 步把「判定住在某篇」改成「判定寫在某篇」）可能不必列為違規。之後審稿的人在回答「規則類文件裡既有的承接與內容集合裡的住在要不要整組重判」時下了判定：「承接是一個合理的用法，住在不是」。本卡把它讀成：既有的「承接」不整組重判，改到那一行時仍照本卡判（量測裡「由課程承接」讀出兩種以上的意思，「Given 須承接前序狀態」讀對；承接描述內容集合的結構時仍是本卡的形態）；「住在」改成一律換掉（〈修法〉的「住在」那一段），內容集合與規則類文件裡的同型用法隨即改寫。

## 核心原則

**集合的組織者替自己的結構取了空間與搬運的名字，這組名字寫進正文之後，佔住了主詞與動詞的位置。** 寫第一批文章的人在腦中把分類想成幾條平行的「線」，每一篇「承接」一個題目，讀者沿著連結「走」到下一篇，判定「住在」某一篇。這組詞對組織者是一張方便的結構地圖；寫進正文之後，每一句的主詞與動詞換成了那張地圖上的元素：「這條線處理的是資本與現金流怎麼配置」的主詞是一條線，而做「處理」的是這個書單收的書；「三本各接一個面」的動詞是「接」，而每一本實際做的是討論、分析、記錄、量測某一件事；「走 [某篇]」的動作者是讀者，而讀者實際做的是讀那一篇。讀者讀這些句子時，要先把譬喻換回實際的主詞與動作，換不回來時就只剩一句聽起來在交代分工、實際沒說出誰做了什麼的話。

**新稿與舊文章用同一組詞，範本與生成端的習慣都可能是成因。** 以集合裡的舊文章為範本時，抄走的除了結構與段落順序還有句型；同一個生成端在沒有範本的集合裡也寫出同一組詞（上面那 713 行）。兩個成因的處置不同：範本傳遞要靠先掃範本、修範本擋，生成端的習慣要靠掃自己的初稿擋。這次分不開兩者，所以修法兩邊都做。

**三種形態各自藏掉不同的槽位**：譬喻當單位名藏掉主詞，搬運與居住動詞藏掉動作，轉化句藏掉動作者。

- **譬喻當單位名**（線、面）：佔住主詞或受詞，讀者不知道句子在講哪一個實體。修法是換成集合裡實際的單位名（書單、主題篇、面向）。「一側」另有 bank〈部分與一側當名字〉的判讀與豁免。
- **搬運與居住動詞**（接、承接、接得住、走、住在、落在、承擔的角色）：佔住動詞，讀者不知道實際的動作是什麼，或者句子的主詞做不了這個動作（書不承擔角色）。修法是寫出那個動作（討論、涵蓋、收在、讀、寫在、在這一篇的用途是）與它的動作者。
- **轉化句**（「把 X 從印象變成數字」「X 的決定落在 Y 上」）：把動作者藏在一個抽象的轉化或歸屬後面。「某本書的價值是把團隊做得好不好從印象變成數字」裡，做事的是讀者，動作是用四項量測取代印象；「某書單的決定落在錢上」把讀者做的決定寫成書單的屬性，書單做的是把討論的主題放在錢上。修法是寫出誰用什麼取代什麼、誰討論什麼。

## 反模式

- **用分類的組織譬喻寫正文**：「這條線」「另外兩條線」「管理線」寫進讀者看得到的文章，讀者要先知道作者心中的那張地圖。
- **「各接一個面」當分工句**：這一句交付的只有「每本書不一樣」，每一本做了什麼要讀者自己去讀各節；寫出來的時候，句子本身就是分工。
- **以舊文章為範本而不先掃它的句型**：範本裡的同一組詞跟著進新稿。
- **只掃範本、不掃自己的初稿**：生成端自己的習慣在沒有範本的地方照樣寫出同一組詞。
- **只修新稿**：舊文章裡的同一組詞留著，下一次以舊文章為範本時又會被抄走（這一條是推論，這次沒有觀察到「下一次」）。

## 修法

1. **寫新稿之前掃範本，寫完之後掃自己的初稿**：用本 skill bank〈結構譬喻頂替主詞與動詞〉那一條 pattern 掃，再補這個集合特有的組織名詞與動詞（這一次是「書線」「決定的對象」；找法是讀集合的目錄頁、範本的段標與分工句）；命中密集時先修範本。
2. **單位名用集合裡實際的名字**：每一個「線」「面」換成它在文章裡給讀者看的名字（書單、主題篇、面向），比較時寫「其他書單」「另外兩個書單」。
3. **每一個搬運與居住動詞換成實際的動作**：「三本各接一個面」→「這三本各自討論不同的面向：《A》討論…，《B》分析…」；「由課程承接」→「這門課涵蓋…」；「走 [某篇]」→「讀 [某篇]」或「…收在 [某篇]」；「判定住在某篇」→「判定寫在某篇」；「這本書承擔的角色是」→「這本書在這一篇的用途是」。
4. **轉化句寫出動作者與動作**：「把 X 從 A 變成 B」→「用 B 取代對 X 的 A」，並寫出 B 是什麼；「X 的決定落在 Y」→「X 討論的主題放在 Y 上」。
5. **新稿與舊文章一起修**。
6. **替換詞再掃一次**：換上的詞照同一條 pattern 與判讀再過一次，依語境選實際的動作，不全篇換成同一個詞（「承接」一律換「涵蓋」是新的模具）；換成「銜接」「串起」「扮演…角色」只是換一個譬喻。

判讀分兩種問法。空間與搬運譬喻（線、面、接、承接、走、落在；「住在」不問這一題，照下面「住在」一律換那一段）先問這個詞描述的是不是內容集合的結構（分類、篇章、目錄頁、讀者的閱讀路徑、判定寫在哪裡），描述系統、市場或領域對象的多半合規：一次在基礎設施類集合的實掃裡，18 處「承接」有 15 處是系統元件承接流量或連線；另一次在財務類集合，54 處「承接」有 29 行是「承接量」；同一次在記錄類集合，命中幾乎全是「，走 [」的違規。轉化句與「承擔的角色」不是空間譬喻，套這一問會把「把團隊做得好不好從印象變成數字」放行（它描述的是一本書的價值，不是集合的結構），所以改問動作者是誰、主詞做不做得了這個動作。合規的形態、以及要轉去其他條目判的情形（「承接」當文章或模組的自指、「接得住」當足夠性斷言、主詞是物的「承擔」、「這條線」指分界或判斷標準），以本 skill bank〈結構譬喻頂替主詞與動詞〉那一條為準。

「住在」不再走上面的判斷問句：審稿的人判定它描述內容、規則、資料或元件在哪裡時一律換成實際的動詞，主詞是系統元件也一樣。依據是這個判定；〈論述基礎與限制〉的量測提供的是兩類例子，不是讀對率：換詞測試失敗的（「優雅住在作者的審美裡」三份探針都讀成來源，寫在、位於、屬於都換不了），以及讀出兩種意思的（「那是問 3，住在本檔」一份分不出指答案還是問題的範圍）。量測過的主詞是規則與內容，系統元件當主詞的沒有量過。量測沒有把住在、落在、住址的讀對率分開，落在與住址仍照下一段判，理由是落在有大量「屬於某個條件或選項」的平實用法，住址是使用本 skill 的專案常有定義的術語。處置以本 skill bank〈結構譬喻頂替主詞與動詞〉的「住在」那一句為準。

規則類文件（規則檔與 skill，包括本 skill）裡的落在、住址，依〈論述基礎與限制〉的兩組探針量測，判定在兩步都成立時不屬於本卡的形態（這個判定原本也涵蓋「住在」，被上一段取代）。一、主詞不是結構譬喻（「這條線」「一個面」），也不是讀者或作者做的決定（「X 的決定落在 Y」這類轉化句）；推導、規則、判定、錯誤這類寫下來的內容或發生的事件當主詞，不算轉化句。二、只換這個詞，句子其餘部分不動：落在逐一換成「寫在」「屬於」「位於」，住址只換成「寫的位置」；至少一種換法保持原意，而且換得通的幾種說的是同一件事；主詞省略、要補出主詞才換得通時不成立：「只寫在那個唯一的住址」換成寫的位置；「錯誤落在別人的檔案時」換成位於或屬於，說的都是錯誤出現在別人的檔案。兩步都成立時，這個詞只剩一個平實的意思，讀者不必先知道作者的分類地圖。三個詞都換不了，或換得通的兩種說的是兩件事時，照本卡判。「承接」換不成這三個詞，不在這個範圍，照本卡判。位置沒有寫出名字（「寫在另一篇」）不影響這兩步；「哪一篇」沒寫出來是指涉的問題，照指涉與命名的規則判。審查時的處置以本 skill bank 那一條為準。

補集合特有的組織詞時，補進的詞要先抽樣：一次在財務類集合照目錄頁補了「這一層」「第二層」「兩條路」「承擔的…責任」，補出的 pattern 掃到 137 行，抽樣 8 處沒有一處屬於本卡，多數是文章自己分析模型的序數分層，其餘是領域用法（「由母公司承擔成本」）。違規義項不佔多數的詞加進 pattern，只會把別的類別混進這一條。

| 分工句寫「各接一個面」「由 X 承接」「接得住」 | 動詞是搬運譬喻，每一本實際做了什麼沒寫出來                 |
| 「走 [某篇]」「住在某篇」「落在 Y 上」        | 讀者的動作（讀）與判定的位置（寫在）被換成移動與居住       |
| 新稿與集合裡的舊文章用同一組少見的詞          | 範本傳遞與生成端的習慣都可能是成因，範本與自己的初稿都要掃 |
| 改寫時要補出原文沒寫的主詞或對象              | 回到被介紹的對象與稿件前文核對，譬喻底下原本沒有寫出所指   |

## 跟其他原則的關係

- [物理動詞佔住的內容](physical-verbs-stand-in-for-content.md)：最接近的一張。那張卡處理承重與支撐類的物理動詞佔住需求、失效形態、關係與可信度；本卡處理同一個機制的另一組詞：空間、路線與居住的譬喻（線、面、接、走、住在、落在），它們佔住的是主詞、單位名與動作。
- [以對象起手的句子：缺少的動作者、時機與觸發原因](topic-first-sentence-drops-actor-and-timing.md)：那張卡處理動作者缺席的句子；本卡的形態是動作者被一個譬喻名詞頂替（「這條線處理的是」），格子看起來是滿的，所以照那張卡的問句「誰做」逐字找，找到的是「線」，要再問一次這個名詞能不能做這個動作。
- [先佔位、冒號或括號之後才補出內容](placeholder-then-content-says-it-twice.md)：「落在」後面的佔位指的就是冒號或括號之後的內容時（「判斷標準落在這裡：……」），換掉動詞仍然冗餘，那一種歸那張卡判；佔位指的是別的對象時（「代價落在寫入那一側：」指的是承擔的一方），那張卡不處理，照本卡的判讀問法判。
- [Cadence 同質化](cadence-homogenization.md)：那張卡處理批量寫作時開場、段標、敘事骨架被模板帶成同一個樣子；本卡補上句子層的形態：新稿與範本共用一組句型缺陷，而範本只是成因之一。
- [連貫靠句句推進](coherence-by-advancing-not-recapping.md)：那張卡把「《X》承接的就是這一段」歸成文章自指；本卡把同一個「承接」歸成搬運動詞。兩張卡判的是同一個字的兩種用法：描述文章怎麼編排自己時是文章自指，描述一本書或一篇文章做了什麼時是本卡的形態，兩者的修法都是寫出實際的對象與動作。
- [名詞要求的「誰的、什麼的」也是槽位](noun-without-its-owner-passes-the-slot-check.md)：「一個面」「那一面」是要求所屬的名詞（什麼的面向），本卡的修法之一（「面」改「面向」並寫出是哪個面向）就是那張卡的修法套在這組詞上。
