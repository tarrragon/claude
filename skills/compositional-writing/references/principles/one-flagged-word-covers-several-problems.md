# 被點名的一個詞所在的句子可能同時有幾種寫法缺陷：把主詞擬人的動詞、用替代品的缺點界定價值與文宣式的獨一性斷言，要分開找、分開修

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle），被 keyword-bank〈用詞搭配錯位〉的擬人那一項與〈正向陳述優先〉的「只寫對照方缺什麼的句子」引用。
>
> **何時讀**：使用者或審查者點名一個詞要拿掉，改寫之後同一句又被點名；或文章拿現場、原作、親手做這類對象跟替代品（錄音、線上、複製品）並列，寫出「X 給不了的」「只發生一次」「跟著一路走」這類句子時。

## 論述基礎與限制

本卡來自一篇音樂鑑賞教學文章的四次修改。原稿談現場與錄音的那一節開頭寫「一場現場演出是一首作品在一個晚上只發生一次的版本」，接著是「錄音給不了、而下面的例子裡都聽得到看得到的，還有：」。

- **委託人第一次點名**：第一句是廢話，教學文章不必像宣傳文宣那樣強調一期一會；「給不了」是 LLM 常用的句型，要直接寫在現場可以注意什麼。
- **第一次修改**：刪掉「給不了」，把一句改成「錄音常把這段落差縮小，家裡的音響通常也不會開到那個音量」。
- **同一句被再點名**：這時「給不了」已經不在句子裡，主詞仍然是錄音。
- **之後的點名**：「結尾往哪裡走、跟著一路走到最後」把動作擬人了；標題的「跟台上一起經歷」也是同一類。
- **委託人的補充**：「給不了」本身就是把主詞擬人；LLM 一直有把主詞擬人的習慣，寫的時候要注意，檢討時要查。

量測：

- 字句層 bank 的否定 pattern 不涵蓋「不了」，原稿的六處一處都沒掃到。
- 同一個內容集合裡另外 11 處「給不了」，主詞全是物。其中 6 處寫在讀者要在幾個選項之間選的位置（事件與 Port、兩種佇列、兩種一致性等級），對照是選擇的依據，動詞仍然藏起了實際的屬性。
- 四次修改改到的 28 處，在原文裡的相對位置從 1% 到 97%，前 20% 有 12 處；擬人與文宣句沒有集中在長文章的後段。
- 短 context 的對照：三個新派的 agent 拿同一份事實摘要各寫同一組三段，判成擬人的，原稿每千字 7.9 處，新稿 3.1、3.5、1.2 處；三份新稿都照樣寫出「錄音裡沒有的東西」這個對照框架。干擾因素包括新稿的系統提示裡多了一行要求不擬人的備忘、摘要本身已去掉擬人、原稿是審查前的初稿、只有三份，所以分不開 context 長度與其他因素。對照框架比較像是新稿的作者照著摘要的節名與清單結構寫出來的。

把擬人寫成檢查規則的過程也是材料。第一版用「主詞是哪一類 × 動詞是哪一類」判，再列出做得了的情形（主詞代指一個人、領域標準用語、物理字面）與排除條款。審查兩次觸發設計稽核：每補一條邊界，冷讀與探針就在邊上找到一個能讀出兩種處置的句子（佇列算程式還是物品、書單算不算代指作者、評論文章的慣用說法算不算標準用語）。委託人要求先反省寫法、再反省對規則的理解。第一次反省的結論是：一個要靠判斷的事項被寫成了條件清單，而且被點名的句子共同的缺陷是實際發生的事被藏起來了，所以改成「改寫之後多出讀者需要的資訊就改」的改寫測試。這一版的審查又觸發第三次設計稽核：三份探針都把「HDD 給不了 SSD 的隨機讀取速度」判成可以留（改寫之後資訊相同），「讀者從主詞讀得回的動作者」也跟「判定者不代填槽位」互撞。第二次反省的結論是：委託人在意的是借來的動詞本身，而「主詞要能執行這個動作」本來就是槽位規則的一項，不該另立一套判法。規則因此歸回槽位規則，判法先改成動詞比對（改寫成實際的動作者之後，動詞有沒有換）。動詞比對的 Round 1 又有一半的個案得到兩種處置：改寫句怎麼選、主詞代指誰、句子沒有動作者、因果動詞與受事主語，都是分支的邊界。最後的寫法是委託人選的「只問一句的留意項」：主詞是物時檢查「這個主詞本身，或它在這個領域裡慣用來指的人，能不能執行這個動作」，不能執行就改寫，附正反例與痕跡，不寫分支。

限制：證據只有一位作者（LLM 生成端）的一批文章；「LLM 常把主詞擬人」是委託人的觀察，生成端的頻率沒有量過。

## 核心原則

**讀者點名的是最顯眼的那個詞，那一句可能同時有幾種寫法缺陷，每一種的偵測方法與修法都不同。**

- **把主詞擬人的動詞**：主詞是物（錄音、結尾、眼睛、音樂），動詞是它不能執行的動作（給、幫、經歷、走）。動詞是借來的，實際發生的事也常常沒寫出來：錄音的動態範圍比現場窄、合唱團開始唱、音量一層層加大。判斷照 SKILL.md〈每一句先填槽位再成句（生成端規格）〉那一項檢查：這個主詞本身，或它在這個領域裡慣用來指的人，能不能執行這個動作。「法國號在舞台外演奏」能執行（法國號慣用來指吹法國號的人）；「HDD 給不了 SSD 的隨機讀取速度」不能執行，改成「HDD 的隨機讀取速度比 SSD 慢」。
- **用替代品的缺點界定價值**：句子寫的是被拿來對照的替代品（bank 稱對照方，範圍比替代品寬：拿來對照的任何對象都算）缺什麼，替代品不一定在主詞的位置；讀者讀完只拿到替代品缺什麼，沒有拿到本篇對象的內容。判法、候選與痕跡只寫在 [keyword-bank](../keyword-bank.md)〈正向陳述優先〉底下的「只寫對照方缺什麼的句子」。這一種換動詞修不好：「給不了」換成「縮小」之後，讀者拿到的仍然只有錄音缺什麼。
- **文宣式的獨一性斷言**：「只發生一次的版本」「跟台上一起經歷」。拿話題的定義推得出這一句，所以它沒有交付新的資訊；這類句子的功能是經營期待，教學文章的讀者要的是成因與用處。

**三種缺陷常常出現在同一句裡，所以會被當成同一個缺陷。** 修改的人照著點名的詞修，只修好那個詞；其餘幾種缺陷沒有被改到，修改的人要等點名的人下一次指出才會發現。

**擬人是生成端的習慣，在寫的當下擋。** 「主詞要能執行這個動作」已經是槽位規則的一項，卻沒有被執行：寫與審的步驟裡，沒有一步要求寫的人或審查者逐句做這一項檢查，同源的審查者讀起來也是順的。

## 反模式

- **只換掉被點名的詞**：換成「縮小」「做不到」「缺少」，讀者讀完仍然只拿到替代品缺什麼，或實際的動作者仍然沒寫出來。
- **只補進否定詞的 pattern 就當作處理完**：把「給不了」補進去之後，它也只抓得到這一個詞；擬人的動詞不一定帶否定（走、幫、經歷），替代品的對照改寫之後沒有固定的字詞。
- **讀者要選的段落連對照一起刪掉**：要改的是藏起屬性的動詞，對照留著。
- **把擬人寫成主詞與動詞的分類表，或另立一套判法**：主詞歸哪一類本身就要判斷，每補一條合規情形就多一條讀得出兩種處置的邊界；另立的判法又會跟槽位規則在每一個邊界互撞；把判斷寫成帶分支的比對程序，分支的邊界照樣讀得出兩種處置。用槽位規則的那一項檢查判，並把改寫句或留下的理由寫成痕跡。
- **用另一個宣傳句取代獨一性斷言**：「每一場都是獨一無二的」換的只是措辭。

## 修法

擬人的判斷照 SKILL.md〈每一句先填槽位再成句（生成端規格）〉那一項檢查，偵測、痕跡與嚴重度寫在 [keyword-bank](../keyword-bank.md)〈用詞搭配錯位〉的擬人那一項；替代品的對照照同一份 bank〈正向陳述優先〉底下的「只寫對照方缺什麼的句子」判；獨一性斷言用 [parallel-clause-filled-with-the-topics-definition](parallel-clause-filled-with-the-topics-definition.md) 的定義代換測試，改寫時寫出變因與讀者的用處。本卡另外補上跟修改流程有關的幾件事：

1. **被點名的詞放回整句，三種缺陷逐一判**，不只處理那個詞。
2. **改完拿改後的句子再判一次**，不只搜被點名的那個詞。
3. **同一個集合一起掃**：擬人照 bank 的 pattern 與主謂抽取找候選，替代品的對照用替代品的名字當候選，內容集合的結構譬喻照同一份 bank 的〈結構譬喻頂替主詞與動詞〉。同一批文章互相當範本時，同一種寫法會出現在好幾篇。

## 判讀徵兆

| 徵兆                                                       | 判讀                                                                     |
| ---------------------------------------------------------- | ------------------------------------------------------------------------ |
| 改寫之後同一句又被點名，而被點名的詞已經不在句子裡         | 修好的是那個詞，替代品的對照、獨一性斷言或另一個擬人動詞還在改後的句子裡 |
| 主詞是物（錄音、結尾、眼睛），動詞是給、走、幫、經歷       | 擬人的候選，檢查這個主詞或它慣用來指的人能不能執行這個動作                 |
| 句子寫的是錄音、線上、複製品這類替代品缺什麼               | 問讀者讀完這一段拿到了什麼，只拿到替代品缺什麼就要改                     |
| 「只發生一次」「獨一無二」「一起經歷」寫在教學文章的開段或標題 | 文宣式的獨一性斷言，定義代換測試下沒有新資訊                         |
| 同一種擬人寫法出現在同一批好幾篇裡                         | 同一批文章互相當範本，或生成端的習慣；整個集合一起掃，不只修被點名的那篇 |
| 檢查規則每補一條合規情形，審查就找到一個兩種處置的新句子   | 一個要靠判斷的事項被寫成了條件清單；改成觸發、一問與痕跡                 |
