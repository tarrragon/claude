# 要靠判斷的原則寫成留意項：什麼時候判斷、判斷留下什麼寫成查得到的事實，判斷的答案不寫成條件

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被 `references/reference-authoring-standards.md`〈要靠判斷的條文寫成留意項〉引用。
>
> **何時讀**：寫一條規則、一張原則卡或 reference 的一節，而它要求的判斷沒有可以機械比對的答案（要靠執行者對那個領域的了解）時；要決定哪些內容寫成查得到的條件、哪些留給判斷，以及怎麼讓讀的人不把它讀成可以不做、也不把它讀成硬性門檻時。

---

## 論述基礎與限制

這張卡處理的寫法：一條原則要執行者做一個判斷，而這個判斷的答案依個案而不同、沒有可以機械比對的條件；寫規則的人把它寫成了條件與步驟（「兩個時間點不同就拿掉」「超過 N 年不用」），或反過來只寫「要留意」而沒有寫出任何查得到的東西。**留意項**在這張卡指：每一次遇到觸發的情形都要做、做完要留下痕跡，而判斷的答案留給執行者的那一類規則。

這張卡來自一次改寫：[引用一份評價時，留意它評的是對象在什麼時候的狀態](cited-evaluation-carries-the-date-it-judged.md) 那張卡與它在 `references/source-to-teaching-analysis.md` 對應的一節。那張卡的初版把原則寫成比對兩個時間點、不同就拿掉評語的步驟。委託那次寫作的人指出：不同的東西有效的年份不一樣，演奏家在生涯晚期成長的幅度跟早年不一樣，有些東西三四十年進步的空間並不大；所以這是一種要注意的事，不是硬性檢查的條件。改寫之後跑了四輪審查，這張卡的材料是那四輪的結果：

- **改了定位之後，硬性的寫法還留在別處。** 核心原則改成「依對象改變了多少判斷」之後，第一輪的兩位審查者找到四處最高嚴重度的問題，都是同一件事：卡片的修法步驟、判讀徵兆表、關係段與 reference 那一節各有一句仍然拿時間差當條件（「對不上就拿掉」「時間點差很多的不並列」），其中三處在原則卡本體，本體因此比 reference 裡對應的那一節還嚴。
- **只寫「留意項，不是檢查條件」讀不出強度。** 第二輪三份低階模型的理解探針讀同一節，三份都回報「留意項」與下一句「在引用之前判斷一次」強度不一致，並列出「提醒、不強制執行」這種讀法。補上定義（每一次引用都做這項判斷，沒有機械條件的是判斷的答案）之後，第四輪的三份都讀成每次都要做、沒有通過與否的檢查。
- **成本最低的那個答案會變成預設。** 第三輪的審查者拿誤用的方式實跑：三種判斷結果裡「變化不大」只要加上年份就能照用，不必寫依據，審查者又不查答案，於是把三十四年前的評語判成變化不大、加上年份照用，寫的人與審查的人都會放行，正好是那張卡的起源個案。
- **痕跡補齊之後，處置分得開。** 第四輪三份探針各走六個情境（兩年前的功能清單、可以重跑的基準測試、凍結函式庫的「同類裡最快」、七十五歲鋼琴家四年前的樂評、文中寫了換主廚的餐廳食記、回顧型文章），三份的處置一致，而且各自指出不能只憑換了版本、只憑年數下判斷。
- **把同一條寫進審查流程時，審查端又出了三種缺口。** 同一天把這一條加進多輪審查裡查核事實的那一輪，另跑三輪。審查者要不要指出一處的條件在作者端與審查端各寫了一份，兩份已經不一致（一份寫「不必提」，一份寫「也列在表裡」）；要不要指出全靠「評語寫成當時的狀態，還是寫成對現況的描述」這個區分，而它沒有判別的依據，三份探針在同兩個情境上各自分成兩種讀法；作者端只要求依據「說得出」，審查端卻以稿件看不看得出依據來指出問題，照作者端做完的稿件每一處都會被指出。
- **把這張卡寫成規則撰寫指引的一節時，審查補了兩類這張卡原本沒有的內容。** 一位審查者拿五條性質不同的規則草稿照那一節走：「審查至少三輪」「錯誤率超過門檻就呼叫值班」這類門檻，照字面會被改成留意項，而它們是刻意不讓執行者當場判斷的護欄；痕跡只規定了位置，每一處都寫「已評估，無需調整」就能通過那一節的每一項驗收。另一位審查者指出那一節跟同一份指引裡「每一個結論各有查得到的入口條件」的既有驗收項，對同一條留意項給出相反的處置。

限制：證據只有這一條原則的一次改寫與一次寫進審查流程，各輪審查的讀者是同一個模型家族的審查者與低階模型探針，沒有量過人照這一節執行的結果。「探針讀成每次都要做」是對那一節文字的讀法，不代表執行時真的每次都做。

## 核心原則

**一條要靠判斷的規則有三個部分，各自的寫法不同：什麼時候判斷、判斷留下什麼、判斷的答案。** 什麼時候判斷寫成查得到的事實（文章引用了樂評、評測、使用心得或量測）；判斷留下什麼也寫成查得到的事實（引用的位置寫出評的時間點、寫明只取紀錄、寫出缺什麼）；判斷的答案（這個對象在這段時間改變了多少）留給執行者，並且明講它沒有機械的條件。前兩個部分讓規則查得到有沒有被執行，第三個部分保留判斷。

**寫規則的人把答案也寫成條件，成因在規則的體例。** 修法寫成編號步驟、徵兆寫成對照表、審查要分嚴重度，每一種體例都在要一個可以照著判的條件；「觸發條件寫成查得到的事實」這類寫規則的規則又把人推向條件。寫的人於是伸手拿一個看得到的量（時間差、年數）頂替判斷。規則用數量當門檻時，那個數量有兩種身分：它是判斷的直接證據，或它在代理一個判斷。代理的那一種，被代理的判斷可以直接檢查時，換成直接檢查就好；這張卡處理的是判斷沒辦法直接檢查的情形，能寫成事實的只有觸發與痕跡。

**「留意項」三個字不夠，要寫出它的強度。** 「這是留意項，不是檢查條件」可以讀成可以不做的提醒。寫規則的人在同一處寫出：這項判斷每一次都做；沒有機械條件的是它的答案；做完之後在哪裡留下什麼。也在同一處寫出不要的東西：不訂年數這類門檻，也不要求一律採取某一種處置。

**每一種判斷結果都要有對應的痕跡，否則成本最低的那一種會變成預設。** 判成某一種結果不必寫任何依據時，想省事的執行者會一律選它：要求執行者做判定的規則沒有規定判定留下什麼時，判定會沿著不產生後續動作的那個結論塌陷。「變化不大」要把依據的事實寫在引用的位置或交稿時附的紀錄裡，寫不出來的歸「判斷不出來」；「判斷不出來」要在產物裡寫出缺的是哪一項資訊，只寫「無法確認」不算；查了什麼寫進交付時附的紀錄，不寫進產物，因為查找的經過不是產物要交付的內容時，產物的讀者用不到它（產物本身就是考證或排查的紀錄時另論）。依據要寫在審查者讀得到的位置：只要求「說得出」時，審查者每一輪都得重問一次，照規則做了判斷的稿件與沒做的稿件在審查者眼前相同。痕跡規定的是判斷要留下結果與依據，沒有規定結果該是哪一個。

**處置是把觸發的內容拿掉時，產物裡沒有位置留痕跡。** 判成變化大、拿掉評語之後，稿件裡看不出做過判斷，一律拿掉因此是另一條不留痕跡的省力路徑。寫規則的人要決定這一種留不留痕跡，並把決定寫進規則：留的，規定寫在交付時附的紀錄（拿掉了什麼、依的是哪一項事實）；不留的，寫出理由，並把「一律拿掉」列為反模式。那張卡選的是不留，理由是被考慮過而沒有引用的來源數量多，逐份記錄的成本高於它防的錯。

**痕跡要帶個案專有的事實，否則套話就能通過。** 規則只規定痕跡寫在哪裡時，「已評估，無需調整」「經判斷變化不大」都在審查者讀得到的位置，而它們原樣搬到另一個個案上仍然成立。痕跡的內容要過一道檢查：帶著這一個個案專有、別人回頭查得到的事實。審查者把套話照沒有痕跡指出；這查的是痕跡的形式，不是答案。

**有一類門檻是刻意的護欄，不改成留意項。** 量確實在頂替一個不能直接檢查的判斷，而寫規則的人刻意不讓執行者當場判斷：判錯的後果不可逆；執行者在那一刻的省力選項正好是「不做」（審查至少跑幾輪）；幾個人要對同一個結果有一致的預期（發版的條件、告警的升級門檻）。這一類門檻留著，規則寫出它是哪一種護欄。把它改成留意項，等於把判斷交還給最容易沿省力路徑判的那個人。護欄可以跟留意項並用：達到門檻一律做，沒達到時照留意項判斷。

**審查者查痕跡與事實，不查答案，也不拿代理的量判通過與否。** 審查者指出查得到的事實（評的時間點、稿件自己寫到或稿件給出的來源裡看得到的變動事件、稿件與交稿的紀錄都看不出判成沒有改變的依據），請寫的人重新判斷或說出依據，嚴重度不列最高的那一級；對象改變了多少、評語留不留，審查者不替他決定。審查這一端寫成最高嚴重度加一個門檻時，留意項就在審查端變回了硬性檢查。

**定位改了之後，回頭找還留著舊定位的句子。** 核心原則改成留意項之後，步驟、表格、關係段、副本、別張卡指過來的句子不會自己跟著改；那次四處最高嚴重度的問題都在這些位置。找法是用舊定位的關鍵詞（那次是「對不上」「拿掉」「不並列」）掃卡片與它的每一份副本，逐處問這一句是在要求判斷，還是在替判斷給答案。

## 反模式

- **把判斷的答案寫成條件**：「評的時間點與讀者要判斷的時間點不同時，拿掉評語」。時間點不同是觸發判斷的事實，不是判斷的結果。
- **拿一個看得到的量頂替判斷**：「超過十年的評價不用」「時間點差很多的不並列」。年數看得到，對象改變了多少看不到，前者就被拿來代替後者。
- **只寫「要留意」，沒有觸發與痕跡**：執行過與沒執行過的產物相同，這條規則只約束願意遵守的人。
- **寫了「留意項」而沒有寫強度**：讀的人分不出是每次都要做，還是可以不做。
- **有一種判斷結果不必留痕跡**：它會變成預設的答案。
- **審查端把留意項列成最高嚴重度並附門檻**：寫的人為了通過審查會照門檻做，判斷就不再被做。
- **核心原則改了定位，步驟與表格還是舊的**：同一份文件給出兩種處置，照步驟做的人拿到的是舊的硬性版本。
- **痕跡只規定位置，沒有規定內容**：每一處都寫同一句套話，位置對了，審查者查不出有沒有判斷過。
- **把刻意的護欄改成留意項**：「至少審查三輪」改成「每次判斷審查夠不夠」，執行者在省力選項正好是不做的那一刻拿回了判斷。

## 修法

1. **先分出這條原則的三個部分**：什麼時候判斷、判斷留下什麼、判斷的答案。寫出判斷的問句；問句答不出機械的條件時（答案依對象、階段或領域而不同），這一條就是留意項。規則裡既有的門檻先判是不是刻意的護欄（後果不可逆、省力選項正好是不做、幾個人要有一致的預期）；是的話留著，寫出是哪一種。
2. **觸發寫成查得到的事實**，並且以動作觸發，不以執行者自述的目的觸發（「文章引用了評價」，不是「文章要用評價說明現況」）：自述的目的會讓執行者自認不適用。
3. **寫出判斷的問句，並給兩個方向的例子**：答案是「變了」的例子與答案是「沒變」的例子都給，例子寫出依的是哪一項屬性；只給一個方向的例子，讀的人會把那個方向當成預設。
4. **每一種判斷結果各寫一種處置與它的痕跡**；判斷不出來也是一種結果，同樣有處置與痕跡。痕跡要帶個案專有的事實；處置是拿掉內容的那一種，寫出留不留痕跡的決定與理由。
5. **在開頭寫出強度與不要的東西**：每一次都做；答案沒有機械條件；不訂某一種門檻；不要求一律採取某一種處置。
6. **寫出審查者查什麼**：查觸發的事實與痕跡有沒有寫出來，指出查得到的事實，嚴重度不列最高的那一級；不查答案。審查者要不要指出一處的判別也寫成查得到的事實（那次的「評語寫成當時的狀態」寫成兩件查得到的事），審查端的判別只寫在一個位置，另一處連過去；審查者一處都沒找到觸發的情形時，報告也留一列。
7. **改過定位之後，用舊定位的關鍵詞掃整份文件與每一份副本**，把仍然在替判斷給答案的句子改掉。
8. **拿幾個答案不同的個案走一遍**：規則的修法逐句驗證會通過，套到個案上才看得出兩句互撞。個案之間的處置分不開，或都落到同一種結果時，問句或痕跡還沒寫清楚。

## 判讀徵兆

| 徵兆                                                               | 判讀                                                                                                             |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| 規則的條件是一個看得到的量（年數、次數、行數），理由是「比較好判」 | 先分這個量是判斷的直接證據還是代理；是代理時，被代理的判斷能直接檢查就換成直接檢查，不能就寫成留意項             |
| 規則寫「X 與 Y 不同時就做 Z」，而該不該做 Z 其實依個案而定         | 把觸發判斷的事實寫成了判斷的結果；補上問句與幾種處置                                                             |
| 規則只寫「要留意」「要考慮」，沒有寫做完留下什麼                   | 沒有痕跡，執行過與沒執行過分不出來；補觸發與痕跡                                                                 |
| 讀的人問「這是一定要做，還是可以不做」                             | 沒有寫強度；在開頭寫出每一次都做、沒有機械條件的是答案                                                           |
| 幾種判斷結果裡，有一種不必寫任何依據                               | 它會變成預設；替它規定要寫出的依據與寫的位置                                                                               |
| 個案實跑時，每一個個案都落到同一種結果                             | 問句沒有鑑別力，或某一種結果成本最低                                                                             |
| 審查的條目把這一項列最高嚴重度，或附上年數這類門檻                 | 審查端把留意項變回硬性檢查；改成指出事實、降一級                                                                 |
| 核心原則寫的是判斷，步驟或表格寫的是條件                           | 定位改了而舊句子還在；用舊定位的關鍵詞掃一次                                                                     |

## 跟其他原則的關係

- [引用一份評價時，留意它評的是對象在什麼時候的狀態](cited-evaluation-carries-the-date-it-judged.md)：這張卡的個案來源。那張卡是一條留意項的內容，這張卡記的是把它寫成留意項的過程裡出過的錯與修法。
- [subjective-precondition-never-fires-for-the-misreader](subjective-precondition-never-fires-for-the-misreader.md)：那張卡要求條文的要件寫成查得到的條件、不寫成讀者的主觀狀態。這張卡畫出那條要求的邊界：觸發與痕跡照那張卡寫成查得到的事實，判斷的答案不在那條要求的範圍裡。
