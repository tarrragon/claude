# Rewrite Preserves Claim Intensity

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被 [translation-review](../translation-review.md) 引用。
>
> **何時讀**：翻譯、轉述、摘要或改寫他人材料後，成品讀起來比原文更有力、更像口號，或需要判斷一次量級升格是超譯還是正當的文案設計時。

## 核心命題

轉換他人材料（翻譯、轉述、摘要、改寫）時、成品的每個 claim 要停在原文的強度量級。強度是 claim 的一部分：形容詞的讚美量級（great 對 miraculous）、模態與頻率詞的確定性（可能對必然、有時對總是）都在傳遞作者對這個 claim 的信心與定位。量級被拉高（升格）或壓低（降格）時、即使概念類型沒換、句子通順、reader 拿到的也是另一個 claim。

可操作判準是**鄰詞存在測試**：原文語言存在一個量級更強的專詞、而原文沒有選用它、代表原文停在較低量級。實例：某產品登入成功頁的英文標語「Build something great」、日文在地化「素晴らしいものを作りましょう」量級對位；把日文句再交給 AI 中譯、得到「讓我們製造一點奇蹟吧」——日文有「奇跡」這個常用專詞、日文版沒選用它、中譯選「奇蹟」等於替上游做了一個它明確沒做的選擇。同語言的轉述用同一個測試：原文寫「暗示」（suggests）而轉述寫「證明」、轉述者替原文換上了它明確沒選的強詞。

## 為什麼轉換會把量級拉高

文體先驗接管。轉換孤立短句（slogan、標題、金句）時、轉換者——人或語言模型——同時在做兩件事：對位原文、產出目標文體的典型樣貌。上下文越少、後者的權重越大：中文行銷語裡「創造奇蹟」比「做出很棒的東西」更像一句 slogan、於是成品往文體典型滑、翻譯默默變成文案再創作、而且沒有任何一方宣告過這個轉變。

| 放大條件                   | 作用方式                             |
| -------------------------- | ------------------------------------ |
| 孤立短句、無上下文         | 文體先驗權重上升、保真對照材料減少   |
| 目標文體有慣用的高強度句式 | 成品被慣用句式吸走、量級跟著句式走   |
| 轉換目的未宣告             | 翻譯與再創作的界線消失、升格無人負責 |
| 材料本身是轉換產物         | 上一段的漂移被當成原文、漂移逐段累積 |

## 強度作為設計變數：適用邊界

量級升格本身是中性的寫作工具、對錯由文字的**責任對象**決定：

| 情境                                             | 責任對象 | 量級的地位                                                         |
| ------------------------------------------------ | -------- | ------------------------------------------------------------------ |
| 保真轉換（翻譯、轉述、摘要、引用）               | 原文     | 鎖定原文量級、升格與降格都是缺陷、本卡檢查適用                     |
| 宣告過的再創作（trans-creation、在地化行銷標語） | 訴求效果 | 設計變數、可升格；成品要標示為再創作、回頭引用時取原文而非再創作版 |
| 原創文案（標語、行銷、產品命名、無 source）      | 訴求效果 | 純設計變數、由受眾、文體、品牌語氣決定                             |

同一個「奇蹟」、在中譯一句日文標語時是超譯、在替自家產品寫中文標語時是誇飾修辭的正當運用。分辨能力比禁令有用：把三列混在一起、會在保真情境放行超譯、也會在創作情境誤殺有效的標語。未宣告目的的轉換、預設以保真為判準。

## 檢查流程

| 檢查         | 問題                                                   | 失效訊號                             |
| ------------ | ------------------------------------------------------ | ------------------------------------ |
| 強度詞定位   | claim 裡承載強度的詞是哪些（形容詞量級、模態、頻率）？ | 找不到對應詞、強度是成品自己長出來的 |
| 量級對位     | 成品的強度詞跟原文同級嗎？                             | 成品讀起來比原文更有力、更像口號     |
| 鄰詞存在測試 | 原文語言有更強的專詞、原文選用了嗎？                   | 成品用了原文迴避的那個量級           |
| 目的宣告     | 這次轉換是翻譯還是再創作？                             | 升格存在、但沒有任何地方宣告過再創作 |
| 回源驗證     | 材料本身是轉換產物嗎？                                 | 拿譯文當原文比對、漂移被當成原意     |

命中是候選、判定在語意層：明示的意譯、宣告過的文案再創作、目標語言慣例要求的語氣調整（敬語、邀請式收尾）都合規。判定問題是「量級改變有沒有被選擇過、有沒有被宣告過」。鏈式轉換（翻譯的翻譯）漂移逐段累積、查證要回最上游的語言版本比對；原文不可得時（付費牆、口述來源、已下架）判定為「未驗證轉述」——可保留但要標示、不得作為 claim 的支撐再被引用。鄰詞存在測試的成立前提是兩語言在該語意場都有可對位的量級階梯：原文語言用一個詞涵蓋目標語言分成兩級的區間時（significant 對「顯著」與「相當程度」）、測試沒有輸出——回上下文推定量級意圖、選跨度最近的詞並標示不確定。文學翻譯（詩、雙關）因音節、韻與意象密度必須調整量級、在本卡邊界之外。

## 跟鄰近原則的分工

- **概念角色**（[translation-must-preserve-concept-role](translation-must-preserve-concept-role.md)）：那卡管類型軸（方法被翻成測試）、本卡管量級軸（「奇蹟」跟「很棒」同為讚美、類型沒換、量級被拉高）。兩軸正交、一個譯名可以只錯一軸。
- **原文錨點**（[terminology-keeps-original-anchor](terminology-keeps-original-anchor.md)）：雙錨點是量級漂移的偵測基礎、保留原文才有對照量級的材料；鄰詞存在測試以能回到原文為前提。
- **摘要模態**：同語言的摘要壓縮可以丟細節、不可以改模態（條件允許壓成禁止）；本卡是同一族在跨語言、跨作者轉換場景的對應、兩者共享「成品比原文更有力就是失真訊號」這條判定。
- **位置合法性**（[hyperbole-legitimacy-by-position-function](hyperbole-legitimacy-by-position-function.md)）：本卡管生產端——轉換他人材料時鎖定原文量級；那卡管接收端——審查任何內容時用段落位置的功能（文體契約 × 行動耦合）判定強度合法性、含支撐存在測試與反比操縱訊號兩個接收端判準。

## 自查清單

- [ ] 成品的每個高強度詞在原文找得到同級對應
- [ ] 鄰詞存在測試通過：原文迴避的更強專詞、成品也沒用
- [ ] hedge 詞（可能、有時、在某些情境）在轉換後仍在
- [ ] 這次轉換的目的明確：保真翻譯鎖定量級、再創作有宣告
- [ ] 材料本身是轉換產物時、已回最上游版本比對

**核心**：原文停在的量級、就是讀者該拿到的 claim。轉換者無從分辨原文的量級是刻意還是隨手、而改動的收益歸轉換者、風險歸原作者——所以預設保真、要改就宣告。

本卡自外部原則庫同步而來、slug `rewrite-preserves-claim-intensity` 供同步工具對位（非內容依賴）；無同步流程的專案可刪本行。
