# 關鍵詞清單換一個體裁就失準，而健康的命中數會蓋住這件事

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被字句層的 keyword bank（一組用來曝光候選違規的 grep pattern）的位置與集合指涉段與收尾段引用。
>
> **何時讀**：既有的 pattern 要套到一批新體裁的內容上時；或掃描回報的命中數看起來正常、而人工讀起來覺得這一類還有別的形態時。

## 核心原則

**一份 keyword 清單是從某個體裁的實例歸納出來的，而違規形態隨體裁換一整組。** 位置指涉這一類在論述型內容裡的主流形態是「前者 / 後者」，因為論述文的結構單位是命題與對比；在清單型內容（書單、工具比較、選型表）裡是「前一本 / 下一本 / 本篇第三本」，因為那裡的結構單位是一篇裡的一組並列成員。兩組詞沒有交集，而它們違反的是同一條原則。

**非零命中會被讀成涵蓋。** 這是缺口躲過審查的機制：一條回傳大量命中的 pattern 讀起來像「這一類有在管」，於是「這個體裁的這一類還有沒有別的形態」這個問題不會被問。命中數越健康，關掉那個問題的力道越強——零命中至少還會讓人懷疑 pattern 寫錯了。

判斷標準因此不能是「grep 有沒有命中」，換成兩步：**先在這個體裁上人工列出這一類的實際形態，再回頭問 pattern 涵蓋幾種。** 第一步的成本是讀三到五篇並把違規逐處記下來，而那正是既有 pattern 讓人跳過的動作。

## 實測

一批清單型內容跑完整的字句層 bank，位置與集合指涉這一類回傳 86 個命中，數量在全部類別裡排第二。一位審查者逐處驗過那 86 處的計數，判定全部合規——判定沒有錯，錯的是集合。同一批內容由一個結構審查逐篇讀完之後列出約三十處違規，全部是序數形態（前一本、下一本、本篇第三本、上述兩本、前面幾本），pattern 一個都沒有抓到；其中十二個章節冷讀落地時讀不出這本書跟同篇其他成員的關係。

最直接的證據來自修完之後的量測：三十處具名改寫走完，同一條 grep 的命中數從 86 動到 85。**修法與量測完全脫節，而量測那一側看不出任何異常。**

## 反模式

**拿命中數當這一類的健康度。** 命中數量的是 pattern 與內容的交集，不是內容裡這一類的總量。兩者在同體裁上大致同向，換體裁之後可以完全脫鉤。

**修完之後不回頭看量測。** 修了幾十處而指標不動時，最直接的解釋是修的那一批與量的那一批沒有交集。這個對照免費（改動前後各跑一次），而它是這個缺陷最早、最明確的訊號。

**用同一批內容驗證從它歸納出來的 pattern。** pattern 從論述型內容抽出來、而內容集合裡多數也是論述型時，它在日常掃描裡會一直表現良好。表現良好不是涵蓋完整的證據，只是它與歸納它的那個體裁還在同一個分佈上。

## 修法

**新體裁進來時，對每一個高風險類別做一次形態盤點。** 挑三到五篇逐處記下該類的違規並抄下原文，再把出現過的詞面與 pattern 比對。差集要嘛補進 pattern（形態穩定時），要嘛在使用點留下一句「這個體裁的這一類另有 X 形態，grep 抓不到」。

**盤點的單位是形態不是詞。** 「前一本」與「下一本」是同一個形態（用排列位置指涉同篇的成員）的兩個詞面，補 pattern 時收一組；「本篇第三本」是另一個形態（用序數指涉），要另外收。照詞面一個一個補，下一批換個說法就又漏了。

**在使用點寫下這份 pattern 是從哪個體裁抽的。** 作用不是提醒，是讓後續的人知道要不要重做盤點——一份沒有標明來源體裁的清單，讀起來對所有內容都成立。

**體裁的判別看結構單位。** 論述文的單位是命題、教學模組的單位是步驟與判斷標準、清單型內容的單位是一組並列的成員、事件紀錄的單位是時序。指涉的形態跟著單位走，所以單位換了就要重做盤點，不必等到「這看起來是新的文體」這種感覺出現。

## 什麼時候不成立

pattern 抓的是封閉集合時不成立——裝飾符號、字形轉寫、特定的單詞對照表，這些的成員由外部規則決定，不隨內容的體裁變動。

內容集合只有單一體裁時不成立：那裡沒有轉移，pattern 與內容始終在同一個分佈上，涵蓋範圍的問題退回 [keyword-list-needs-dominant-violating-sense](keyword-list-needs-dominant-violating-sense.md) 的入選標準。

這一類的違規本身沒有穩定外形時不成立。對讀者喊話、自評誇飾、必然性框架這幾類的真防線本來就是異源冷讀而非 grep，換體裁不改變那個結論，補盤點的收益落在有外形可寫的那幾類上。

## 跟其他原則的關係

- [keyword-list-needs-dominant-violating-sense](keyword-list-needs-dominant-violating-sense.md) 給的是入選標準（違規義項佔它全部用法多少、形態寫不寫得成 pattern），本卡限定它的適用邊界：**那個佔比是在某個體裁上算的**。「前一本」在論述文裡幾乎不出現、永遠不會被抽中；在清單型內容裡它是主流違規形態。那張卡說清單是判斷標準的一次抽樣，本卡補的是抽樣的母體。
- [regional-idioms-evade-keyword-bank](regional-idioms-evade-keyword-bank.md) 講的是同一份清單在同一個體裁內持續長出新個案，處置是靠目標地區讀者冷讀。本卡的方向不同：形態不是慢慢長出來的，是換一批內容就整組換掉，所以它有一個明確的觸發時點（新體裁進來的那一次），也因此排得進行程。
- **命中是候選不是判決**管的是命中之後的語意判定，本卡管的是命中之前的涵蓋範圍。兩者的失敗方向相反而且互不覆蓋：那條處理「抓到了而判錯」，本卡處理「根本沒抓到」。實例裡兩者同時成立而只有前者被看見——86 個命中逐處驗過、判定全部正確，而該體裁的主流違規形態一處都不在那 86 個裡面。
- [decodable-from-text-already-read](decodable-from-text-already-read.md) 是這一類違規本身的判斷標準，本卡處理的是偵測它的工具在換體裁時的失準。
