# 翻譯探針：中文可以不決定的，英文強制決定，多份譯本的分歧就是歧義的位置

> **角色**：本卡是 `compositional-writing` 的支撐型原則（principle）、被字句層 keyword bank 的收尾段引用，作為 grep 抓不到那幾類的補位偵測。
>
> **何時讀**：中文稿件已通過理解探針與多輪審查，而個別詞句仍被指「說不清楚」時；或要判斷一個詞是不是譬喻、一句話有沒有實際內容時。

---

## 核心原則

**中文允許不決定的語法項，英文強制決定。**主詞、單複數、時態、定冠詞、所有格的方向、並列的轄域、修飾語的作用範圍、一個詞是字面義還是譬喻義——中文句子可以把這些全部留在未定狀態而仍然通順，英文的語法要求譯者每一項都選一個答案。翻譯因此是**強制消歧**：譯者無法把原文的模糊態原樣搬過去。

判斷標準跟理解探針（派多份低階模型用逐字相同的指令讀同一篇、只問理解不問評價）相同——**看份與份之間的分歧**，不看任何一份譯文的品質。低階模型的翻譯本身會出錯，單份譯得好不好不進判定；份與份在同一個位置選了不同答案、都在同一個位置寫「原文沒有給出判斷依據」、或任何一份在註記裡主動標明那個位置需要自己決定，都指向同一件事：那個位置有歧義。第三種只要一份就成立，因為註記是譯者**自覺**的決定，能寫出來就表示原文沒有替他決定。

## 它抓的是詞與語法層

理解探針問「你讀到什麼」，而回答的形式是摘要——**摘要允許模糊**：模型可以在不決定「這個所有格指誰」的情況下，寫出一段正確的摘要。翻譯繞不過去，每個詞都要落地成另一個語言的具體形式。

| 軸       | 理解探針                               | 翻譯探針                                   |
| -------- | -------------------------------------- | ------------------------------------------ |
| 解析度   | 命題與脈絡層                           | 詞與語法層                                 |
| 問題形式 | 你讀到什麼、指涉詞指什麼、下一步做什麼 | 把它翻成英文、列出你必須自己決定的東西     |
| 能繞過嗎 | 可以——摘要允許保持模糊                 | 不行——語法強制填空                         |
| 抓得到   | 讀者帶走的命題、脈絡缺口、形狀斷裂     | 所有格方向、轄域、集合邊界、譬喻、零資訊句 |

兩者互補而不互相取代：翻譯探針對「這一節在整篇的什麼位置」這類問題沒有意見，理解探針對「這個『的』的方向」沒有意見。

## 三類獨有的發現

**一、語法項的分歧。**所有格的方向在本次量測中出現過：中文的 `X 的 Y` 不標記 X 是施事者還是被描述的對象，英文必須在 of / for / by 之間選。實測中一個「某人那本的定位」有一份譯成 `positioning for that book`（那個人是定位的施事者），另兩份譯成 `the positioning of that book`（那本書被定位）。同類還有並列的轄域（`A 和 B 的 C`）、修飾語的作用範圍、集合名詞的邊界。

**二、譬喻在翻譯時會現形。**譯者必須決定一個詞是字面義還是譬喻義，因為兩者對應到不同的英文詞。**同一段文字裡的內部對照是最乾淨的證據**：一次補測把同一段派給三份翻譯，其中「判斷標準」（有現成術語）三份全部收斂到 criteria，而同段的「量尺」（譬喻）三份給出不同的英文詞，兩份還主動在註記裡標明它是 metaphor 並列出其他候選。收斂與分歧出現在同一段、同一批譯者身上，差別只在那個概念有沒有現成術語。一個概念如果有現成術語，多份譯文會收斂到那個術語；如果作者用的是譬喻，譯文會分歧（yardstick / criteria / standard）或譯者會在註記裡明說「這是譬喻、原文沒有指明要哪一種框架」。這一項給 [coherence-by-advancing-not-recapping](coherence-by-advancing-not-recapping.md) 的譬喻判斷標準提供可量測的驗收方式：收斂到術語是合格，分歧成多個英文詞就是那個位置還在用譬喻。

**三、零資訊的句子現形（機制推導、尚無觀察到的實例）。**中文的四字節奏與對仗會讓一句什麼都沒說的話讀起來像在做事，英文沒有那個節奏支撐，回收式過場翻過去之後就是一句空話。這一類的偵測不需要譯者知道那條規則——回收式過場（把剛讀完的內容摘一次再出發的句子）與同型的零資訊句會自己譯成明顯無內容的英文。其餘幾類廢字（姿態描述、文章自指、迂迴指代）翻成英文照樣通順，這個管道抓不到，仍要靠 grep 與逐句判定。

## 內部詞彙的跨頁綁定會被抓出來

實測中三份譯文都無法確定一個內容集合內部的分類詞指什麼，各自譯成不同的英文而且都在註記裡標明沒有判斷依據。那個詞的定義住在另一個頁面，本篇首次出現時沒有給連結——原語言的讀者掃過去不會停，翻譯者必須決定它的意思，於是缺的那條綁定現形。

## 操作

指令要求三件事，缺第二件這個 frame 就退化成一般翻譯：

1. 逐句翻譯，不摘要、不省略、不改寫結構——結構改寫會把歧義一起改掉。
2. 翻完之後單獨列出「翻譯時我必須自己決定、而原文沒有明確給出的東西（例如某個名詞的單複數、某個句子的主詞是誰、某個並列結構的範圍到哪、某個詞是字面義還是比喻義）」，寫出選了哪一個、原文還有哪些可能的解讀。**這一欄才是產出**，譯文本身是它的副產品。括號裡的例子要留在指令中——拿掉之後模型回報的多半是譯詞選擇，而不是語法項的決定。
3. 決定不了的寫「原文沒有給出判斷依據」，禁止推測填補。

譯文與註記都要看：註記是譯者**自覺**的決定，而不自覺的決定只有把三份譯文並排逐句對照才看得到。實測中作用域不明的那個詞（三份無一正確譯出）沒有出現在任何一份的註記裡——三份都以為自己讀懂了。它落在「全部一致選錯」那一格，而歸因的下一步是查原文有沒有給出足以排除那個讀法的材料：查證後判定原文的修飾範圍本身不明，因此處置是重寫那一句，不是結案。

專有名詞與技術術語要求保留原文，它們是對照時的錨點、不參與判定。

## 判斷標準

進到這個 frame 的稿件應該已經通過理解探針——**兩者的順序不可顛倒**：翻譯探針的產出密集在詞與語法層，命題層還沒收斂的稿件跑它會被大量低層 finding 淹沒，而那些 finding 多數會在命題層修完之後自動消失。

處置沿用一份讀錯就是判決：份與份選了不同答案是歧義（修），全部都寫「沒有判斷依據」是缺定義或缺綁定（補），全部一致選錯而原文材料足以排除那個讀法才是模型的問題（結案）。

## 什麼時候不成立

- **命題層還沒收斂的稿件**：先跑理解探針。順序顛倒會被低層 finding 淹沒。
- **判定術語翻譯的正確性**：低階模型的術語翻譯不可信，那要專業對照或既有譯名表；本 frame 判的是份與份之間的分歧，不是譯得對不對。
- **以原語言的語感本身為主題的內容**（雙關、詩詞、成語的字面與引申並用）：那些位置的模糊是內容而非缺陷，翻譯會把它們全部報成歧義。
