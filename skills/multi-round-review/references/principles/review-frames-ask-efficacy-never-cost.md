# 審查的 frame 全部在問規則的效力，沒有一個問它的代價

> **角色**：本卡是 `multi-round-review` 的支撐型原則（principle）、被「這一批要跑哪些 frame」與「Round N 規劃判讀」引用。
>
> **何時讀**：規劃一批 frame 時；以及一輪結案、finding 數量可觀而準備判斷停不停時。

## 核心原則

**frame 集合會朝同一個方向長：問規則的效力，不問規則的代價。** 效力那一側問「判準漏了什麼、這一類還有哪些位置、涵蓋範圍夠不夠」；代價那一側問「判準會把哪些合規的個案判成違規、規則的成本由誰承擔、值不值得」。

**成因可以指認，而且兩端同向。** 找到一處漏抓是**產出**——多一則 finding；找到一處誤報是**否定產出**——少一則 finding，而且要撤回別人已經寫下的東西。規劃 frame 的人在找「還有什麼沒被檢查」，執行 frame 的人的價值由 finding 數量體現。

**零 finding 與零 frame 在報告上同形。** 代價那一側交白卷，讀起來像「那一側沒有問題」，而那一側從來沒有人問過。判準若真的不誤傷，誤報那一側該有 frame 跑過並回報零；直接缺席與回報零，在結案報告上是同一片空白。

## 偵測：給每則 finding 標一個方向欄

沿用「finding 的分佈本身是訊號」，而軸換掉——[斷言支撐那一張](review-needs-claim-support-frame.md)看層級（全部落在表面層代表深層無人在看），本卡看方向。

結案前把所有 finding 逐則標一個方向，只有兩個值：這一則說規則**漏掉了**什麼，還是說規則**多抓了**什麼。一欄全滿、另一欄全空時，缺的是 frame 而不是缺陷。

## 修法：frame 清單成對排

| 效力側               | 代價側                                 |
| -------------------- | -------------------------------------- |
| 判準漏了哪些情境     | 判準會把哪些合規的個案判成違規         |
| 這一類還有哪些位置   | 這一類的命中有哪幾處其實合規           |
| 規則的涵蓋範圍夠不夠 | 規則的成本由誰承擔、在什麼規模下不划算 |

**「找誤報會減少產出」這個成本估計本身是錯的。** 一次實測裡有兩次撤回，兩次撤回之後的替代 finding 都比原本那一則強——一次把「有人可能誤用這個設定」換成「本庫唯一的該類項目已經誤用了」。撤回減少的是錯的 finding，換來的是更準的那一則。

**所以這個偏斜是一個沒被算過的假設，而不是一個算過之後的成本選擇。** 這一點劃出它與[代理比本體便宜](proxy-is-cheaper-than-the-thing-it-stands-for.md)的邊界：那張卡的差價是真的（打開一個檔確實要花時間），所以拿代理是理性的；本卡的「代價側產出少」沒有經過量測，而一量就翻轉。**套用「這是理性的成本選擇」之前，要先驗那個成本差是不是真的存在。**

## 限制

單一批次、單一審查對象（一份判準集合），約一百五十則 finding 方向完全一致。「換一種被審對象是否同樣偏斜」沒有量測，成因分析是推導。

## 判讀徵兆

- 結案報告的 finding 全部可以改寫成「這裡漏了 X」。
- frame 清單裡沒有任何一個的產出會是「刪掉一條規則」或「放寬一個判準」。
- 有人問「這條規則會不會太嚴」時，答案來自設計者的印象而不是一輪跑過的 frame。
- 代價那一側交白卷，而結案敘述把它讀成沒有問題。

## 跟相鄰原則的關係

- [審查要有斷言支撐 frame](review-needs-claim-support-frame.md)：同一個偵測法用在另一個維度（層級對方向），共用同一句推論——一整片空白代表那個維度沒有人負責。
- [同一個 session 派出的 reviewer 共用它的盲區](review-scale-does-not-buy-independent-origin.md)：鄰居而軸不同。那張講來源，本卡講提問方向——來源就算換了，只要每個 frame 都在問同一個方向，換來的仍是同一側的 finding。
- [要求揭露只擋得住省略](disclosure-yields-one-bucket-classification-yields-layers.md)：本卡的方向欄是那張卡的分類義務用在 finding 上。
