# 多次局部正確的修法會合成缺陷，而合成的缺陷對每一次修法的 frame 都不可見

> **角色**：本卡是 `multi-round-review` 的支撐型原則（principle）、被「Round N 規劃判讀」與「整合 finding 跟 fix 工作流」引用。
>
> **何時讀**：同一份內容已經跑過三輪以上、每輪的 finding 都修完，要判斷還缺什麼的時候；或是要決定停止判讀的時候。

## 核心原則

**兩次修法各自在自己的 frame 內正確時，它們的合成仍然可能有缺陷，而那個缺陷對兩個 frame 都不可見。**

不可見是結構性的：第一個 frame 的視野裡沒有第二次修法（它還沒發生），第二個 frame 的視野裡有第一次修法的產物但沒有它的動機（frame 只問自己那一軸），於是「這兩件事放在一起會怎樣」不落在任何一方的職責裡。

推論直接影響停止判讀：所有 frame 都跑過、所有 finding 都修完，不等於這份內容現在是好的。**修法本身改變了被審查的對象**，而改變之後沒有人以整體為對象重看過一次。

## 與「修法引入同類變體」的分界

修法產生的問題有兩類，處置不同：

|          | 同類變體                               | 合成缺陷                                       |
| -------- | -------------------------------------- | ---------------------------------------------- |
| 成因     | 兩處同一個（修的人盯著表面、放過成因） | 兩次不同、各自正確                             |
| 誰抓得到 | 下一輪同 frame 或近 frame              | 沒有任何單一 frame，要第三個以整體為對象的視角 |
| 處置     | 把判斷標準從表面移到成因                   | 每輪收尾加一次通讀                             |

「review 的 scope 要涵蓋修法後的產物」這條規則對前者有效、對後者無效——**逐條看修法產物仍然看不見合成缺陷**，因為缺陷在那些條目之間。

## 實測的四種形狀

一組教學章節連續跑八輪審查之後回看，四處缺陷同一個成因：

1. **補進入動機的修法讓同一則故事出現兩次。** 某輪指出章節缺進入動機，修法是把該章微案例的內容前置成開場鉤子——於是同一則故事在相隔一百多行處出現兩次、細節一字不差。
2. **換判斷標準的修法讓一段不該存在的內容變得更完整。** 某輪指出某段的判斷標準用錯，修法換上正確的判斷標準；下一輪指出那整段本來就不該在正文裡（它是寫給審稿人的編輯決策）。
3. **對齊待辦的修法把內部狀態帶進正文。** 某輪要求正文的判定與待辦清單對齊，修法是在正文寫出對齊後的狀態——而那句話把「已列入待辦」這種只有維護者用得上的資訊帶給了讀者。
4. **入口頁被三輪各插一句而讀起來不成句。** 每一句插入單獨看都正確（補一條新分支、補一個分流、修一個過時的指涉），第三句落在句子中間，讀者讀到「這一類讀者可以直接從某章起步」之後又接到「再讀某章」。

## 第二種形態：共用產物被每一輪修改而不被任何一輪審查

多輪審查的對象通常是內容本身——章節、卡片、文章。而每一輪的修法除了改內容，還會動到幾份共用產物：**入口頁（路線敘述）、待辦清單、索引**。這些產物被每一輪修改，卻不在任何一輪的審查範圍裡，因為每一輪的 frame 都是對著內容設計的。

入口頁的後果最直接：它是所有讀者路線的起點，而它累積了 N 輪的插入。沒有人發現，是因為 reviewer 讀的是內容，而作者每次只看自己要插入的那個位置。

**登記與除籍的不對稱**是同一形態在待辦清單上的表現。登記便宜、動機明確（剛發現一個缺口），所以會做。除籍由「以為自己做完的人」執行，而他在檢查自己的工作——於是刪掉的那一列裡可能有一半還沒完成，而刪掉它等於讓那個缺口不再被系統性發現。

## 操作

**每輪修完之後重讀一次全文，而不是重讀被改動的那幾段。** 判斷標準是問「這份內容現在讀起來像一個人一次寫完的嗎」——合成缺陷的表徵幾乎都是「像好幾個人各自加了一段」：同一件事講兩次、前後兩句立場不同、某一段的存在只有作者知道為什麼。

**共用產物要進審查範圍，而且排在最後一輪。** 入口頁看「這幾條路線現在還通嗎」，待辦清單看「這幾列的內容真的都還沒做嗎、做完的真的都刪了嗎」。排最後是因為它們累積的是全部輪次的改動。

**除籍要說出理由。** 刪掉一列待辦時寫出它是被哪一次改動完成的——寫不出來的那些多半只做了一半。

**修法落在別人的段落上時，讀完那一段再改。** 合成缺陷高頻發生在「我為了修 A 而動了 B 段落」的情形，而動的人只讀了要插入的那個位置。

## 判讀徵兆

- 同一份內容經過三輪以上的修法，而沒有任何一輪的收尾動作是通讀全文。
- 某一段讀起來像好幾個人各自加了一句。
- 修法的理由是「回應某一輪的某個 finding」，而那個 finding 的提出者沒有讀過這一段的其餘部分。
- 入口頁、待辦清單或索引在這一批被改過三次以上，而它們從來沒有進過任何一輪的審查目標清單。
- 待辦清單有列被刪掉，而刪的人說不出它是被哪一次改動完成的。
- 一輪修法讓某段變得更完整，而下一輪指出那段本來就不該存在。
