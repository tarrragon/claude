# 定位決定體例，而共用的規範會把一個定位的體例搬到另一個上

> **角色**：本卡是 `multi-round-review` 的支撐型原則（principle）、被「派發之前先定這一批的定位」、Round 2-D 與 2-B⁷ 引用。
>
> **何時讀**：規劃一批審查、決定要跑哪些 frame 之前；或稿件通過了所有規則檢查而讀的人說「內容是對的，但不會這樣寫」時。

## 核心原則

動筆與派發之前先確定這份稿件的定位——**誰讀、讀完要做什麼**——因為語氣、文法與格式都由定位決定。

規範裡的每一條規則都誕生自某一個定位。共用一套規範之後，那些規則累積成一個池子，而池子不記得自己的來歷。**套規則之前沒有先過定位這一關的話，一條為 A 定位設計的規則會把 A 的體例搬到 B 上，而且每一步都合規。**

判別定位的軸不是「內容裡有沒有可執行的東西」，而是**那個動作落在哪裡：在世界上動手，還是在腦中重新歸類**。

## 三種定位

| 定位             | 讀者               | 體例                                                                       |
| ---------------- | ------------------ | -------------------------------------------------------------------------- |
| Agent 指令、規範 | 照著執行的執行者   | 操作手冊：步驟編號是執行的位置，判錯代價要寫，因為執行者需要知道哪一步不能錯 |
| 人類教材         | 來理解一件事的人   | 引導與脈絡：講清楚為什麼是這個順序，順序自己就出來；讀者要的是判讀的依據     |
| 程式碼註解       | 正在讀那段程式的人 | 只解釋商業邏輯，不解釋原理也不冗長，因為原理讀程式碼就有                     |

同一個內容集合底下可能兩種定位並存：一個分類裡的文章是教材，而它的目錄頁是那個分類的操作手冊（成員表、路由、待辦）。整個子集合也可能兩邊都不是——一份歸納問題與解法的記錄，讀者不是來理解一個主題的，而可執行的那一半住在另一個位置。定位按稿件要讀者做什麼判、不按它放在哪裡判，掃體例時要把這些位置排除。

## 量得到的是裝置，不是語氣

一次五份獨立探針的量測交出七種會讓稿件被讀成手冊的裝置：

- **表徵對映清單**：「症狀：成因」，冒號兩邊讓讀者拿成品去對號
- **檢查順序的指示**：規定先看什麼再看什麼
- **配比與參數數字**
- **順序關鍵加上顛倒的後果**：「顛倒過來的話……就散」
- **可執行的操作判準**：不必量測就能判斷的視覺或觸覺訊號
- **具體器具與工具作法**
- **序列連接詞**：先、之後、最後

最後一項最容易漏。把步驟編號換成序列連接詞只改掉一半——同一次量測裡，「會不會放在手邊隨時翻」翻到了教材那一側，而「預期讀者會照著做」仍在手冊那一側，五份全部引了那三個連接詞。**序列連接詞自己就攜帶程序讀法，編號只是它比較顯眼的形態。**

判別的軸不看內容有沒有可執行的東西：同一次量測裡的教材控制項也給了辨識訊號與可以改的東西，而五份仍全部答讀一次就好——它要讀者做的是用一個框架重新詮釋已經發生的事。

## 為什麼既有的 frame 抓不到

**審查的問題形狀是「這一條遵守了嗎」，而定位失配的稿件每一條都遵守了。**

frame 的觸發條件也幫不上忙，因為它們多半按內容形狀判定而不按定位判定。要求補微案例的那一條觸發於「判讀 / 選型型內容」——而一篇讓人理解某個現象的文章確實給了判斷標準，形狀對上了，於是照常要求手冊才需要的裝置。

還有一層：同一條規則自己帶的判斷標準會被跳過。那條規則明寫了要挑後果最不直觀的、直觀的補了是冗餘。**定位沒先定下來的時候，規則的觸發條件會先於它自己的判斷標準生效。**

## 修法

**派發之前寫下一句定位**，並用它重新過一次 frame 的觸發條件。定位是人類教材時，微案例要求、可執行走查、下游任務這幾個 frame 的預設都來自 agent 指令或工程決策內容，要重判。

**規則寫進共用規範時標注它的定位。** 沒有標注的規則看起來一律通用。

**處置不是刪掉資訊。** 材料與手法該留就留，改的是框架：把「照著做的步驟」改寫成「這件事為什麼是這樣」，把「顛倒的後果」改寫成「順序在這裡有什麼物理意義」。

## 判讀徵兆

- 教材裡出現步驟編號，或用先、之後、最後承接的序列——兩者等價。
- 一段判讀之後另起一段演示判錯的後果，而那個後果讀者從前文已經知道。
- 稿件通過了所有規則檢查，而讀的人說「內容是對的，但不會這樣寫」。
- 套某條規則時說得出它的觸發條件，說不出它為哪一種讀者設計。
- 問「讀者讀完之後那個動作落在哪裡」，答案是在世界上動手，而這份稿件的定位是讓人理解一件事。

## 跟相鄰原則的關係

- **要求補微案例的那條規則**（判讀類內容要給「出事會長什麼樣」的短敘事）：本卡界定它的前置條件。那條規則的適用範圍寫成內容形狀（判讀 / 選型類），而真正的前提是後果不直觀且代價可觀，由定位決定。順序是先定位、再判斷它適不適用。
- [規模買不到異源視角](review-scale-does-not-buy-independent-origin.md)：定位判定由作者做的時候有結構上限，因為作者知道自己想寫的是什麼。類型探針把判定移到多份獨立的理解上，正是那張卡說的異源。
