# 替補結構的豁免來自它修掉的清單，重問殺死前任的問題驗不到它

> **角色**：本卡是 `multi-round-review` 的支撐型原則（principle）、被「整合 finding 跟 fix 工作流」與「Round 3-B steelman」引用。
>
> **何時讀**：某一輪的 reviewer 提出一個替代結構、理由是它一次修掉前面記錄的 N 項問題，而你正要採納它的時候。

## 核心原則

一個替補結構若是為了修掉 N 個已記錄的問題而生，**那份清單就是它的豁免證明**。修掉的問題越多，說服力越強，被檢驗的機率越低。

這跟「替補說法從自己推翻的過程裡浮現」那種豁免不同，而且更難擋，因為它的說服力有實據：清單上的每一項都真的被解決了，逐項可核對。要質疑它，等於要質疑一個剛剛證明過自己有效的東西。

**替補結構失敗的後果比它取代的做法嚴重一階。** 逐處補路徑失敗時，讀者看到的是一個沒有路徑的位置，他知道自己拿不到東西；一張地址表失敗時，讀者看到的是一張叫他去查的表，他照著查、查不到，而中間他一直相信自己走在正確的路徑上。**假的完整比公開的殘缺貴**，所以替補結構的驗證門檻要高於它取代的那個做法，而不是因為它「一次解掉很多項」而低於它。

一次實測給出這個差距的形狀：某張取代逐處補路徑的地址表，宣稱涵蓋十五個受管詞而表上實有八列，且其中一列的地址指向框架的源檔，而實際要編輯的是專案裡的副本——照字面查表的讀者會去改框架資產。

外部來源讓豁免更完整。自己想出來的替補帶著「已經被想過」的錯覺；由 reviewer 提出的多帶一層「**別人**想過」——而審查意見的預設地位是「值得採納」，於是採納這個動作本身就吸收掉了本該用在驗證上的注意力。

## 為什麼重問上一輪的問題驗不到它

常見的自我檢查是「用殺死前任的那句話當場測一次」，成本只有一個問句。這個檢查在本卡的情形下會通過而漏抓，原因是結構性的：**殺死前任的問題，正是替補結構被設計來回答的那個問題**。前任死於 N 項具體缺陷，替補結構被提出的理由就是它一次解掉那 N 項；重問一次，它逐項答得出來，而且答得比前任好。檢驗結果是「通過」，而通過是正確的。

漏掉的是替補結構**自己帶進來的新性質**，那些性質沒有被任何一項清單條目觸及。實測形態是四類：新結構的維度彼此不正交、它宣稱的判斷標準無法實際執行、它要求的輸入取得不到、以及它對反例免疫（反例出現時被重新分類成別的東西）。這四項與前任的缺陷清單零交集。

推論：**替補結構與前任處於同一個抽象層時，同層的問題驗不到它。** 檢驗必須來自它自己沒有預期的方向。

## 有效的偵測是換 frame，不是加輪

實測攔下它的是三個彼此獨立的角度，沒有一個是「重問上一輪的問題」：

- **拿具體個案把新結構實際走一遍**（instance 軸）。抽象層讀不出來的東西，走一次就停住——實測的仲裁規則要求比較三個不同量綱的數字，而那件事讀「這段話對不對」看不出來。
- **對抗姿態的反證**，預設新結構是錯的、要求它證明自己，並逐條枚舉候選反例（沒找到反例的也要列出查過什麼）。
- **把整批內容的前提句抽出來並排**，找同一個判斷被多處當前提而無人承接的情形。

三個角度從不同路徑收斂到同一處，而**收斂本身是證據強度**——任何單一角度的結論都可能是那個角度的產物，三個互相看不見的角度指向同一點才排除得掉這個可能。

反過來，同源的逐篇審查再加多少輪都會放行，因為新結構的每一段話都是對的。缺陷在段與段之間、在維度與維度之間，不在任何一個句子裡。

## 修法

**採納外部提出的替代結構時，把它當成自己剛想出來的東西驗。** 三個問句，都針對新結構自己而非它修掉的清單：

1. 新結構的維度兩兩正交嗎（其中一個維度的成本，是不是另一個維度的變數的函數）
2. 它宣稱的判斷標準能不能實際執行一次（拿一個具體個案走完，走得到行動嗎）
3. 它要求的輸入取得到嗎（誰去取、用什麼取、稿件有沒有把這件事寫成一個選擇）

**清單上的每一項都被解決，只證明前任的缺陷消失了，不證明新結構成立。** 這兩件事要分開寫下來：修掉了什麼、以及支持新結構自己成立的證據是什麼。第二欄空白時，新結構還是待驗項。

**在替補結構有自己的驗證之前，不擴散到下游。** 骨架、路由描述、共用元件的鏡像同步都先停住。傳播的成本與推翻的機率相乘，才是採納這個動作的真實代價。

## 判讀徵兆

- 一個替代結構被提出的理由是「它一次解掉前面那 N 個問題」，而 N 大於三。
- 替代結構來自 reviewer，而採納的決定在同一輪內做完。
- 說得出替代結構修掉了什麼，說不出支持它自己成立的證據是什麼。
- 替代結構已經開始擴散（骨架重寫、路由改寫、鏡像同步），而它還沒被任何一個新角度檢驗過。
- 用上一輪的問題重問替代結構，它答得又快又好。

## 與鄰近原則的關係

- [多次局部正確的修法會合成缺陷](sequential-fixes-compose-into-defects.md)：兩者都描述連續動作在交界處產生缺陷。那張卡的兩次動作各自正確、缺陷在合成上；本卡的替補結構整體正確地修掉了清單，缺陷在它自己帶進來的新維度上。共同處置都是在序列的收尾加一個以整體為對象的步驟。
- [multi-pass frame 顆粒度盲點](multi-pass-frame-granularity.md)：本卡是它的一個具體後果。同 frame 多輪 catch 高度重複這件事，在替補結構的情形下惡化——不只是重複，而是同層的所有 frame 都會通過，因為新結構在那一層是對的。
- [多輪審查至少三輪是硬底線](minimum-three-rounds.md)：本卡給它一個新的理由。原本的理由是第三輪的 frame 覆蓋前兩輪的結構性盲區；本卡補的是——審查過程本身會產生要被審查的東西，而第二輪採納的結構要到第三輪才有機會被獨立檢驗。
- [規範化跟自審是兩種認知任務](rule-codification-self-audit.md)：本卡的來源事件是它的實例。相關規則在事發前已存在且被記錄過仍然沒有生效，因為那條規則的觸發條件寫的是「推翻之後」，而採納 reviewer 的建議在當下不被感知為「推翻」，是被感知為「修正」。
