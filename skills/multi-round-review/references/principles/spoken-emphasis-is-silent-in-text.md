# 口語的語氣強調寫進文章後變成讀者的解碼成本

口語裡用語氣強調來傳遞程度——「遠端一個字都沒有執行」比「指令沒有被送到遠端執行」多了「一個字都沒有」這個強調，聽的人從語氣就知道重點在「完全沒執行」。搬到文字上之後語氣消失了，讀者拿到的是一個多了修飾成分的句子，他要先拆掉強調結構、還原成事實，再繼續讀。

## 為什麼審查抓不到

這種句式在中文裡完全合語法，而且讀起來更生動。審查時讀到它的反應是「讀得懂」然後跳過——它確實讀得懂，而問題從來不在讀不讀得懂，在讀者要多花一步還原。一篇文章裡有一處，成本可以忽略；散布在每一段，累積起來讀者的工作記憶被語氣結構佔滿，留給技術內容的空間變少。

它跟教室形態（[#355](teaching-is-not-lecturing.md)）的差別在於：#355 的形態搬的是教室的結構（情境開場、提問引導、省略主詞），這一條搬的是口語的語氣。兩者的來源不同：教室結構來自「教學」這個詞的誤讀，語氣強調來自中文口語與書面語之間的邊界模糊——同一句話講出來與寫下來都通順，而書面語不需要語氣來傳遞程度。

## 判讀方式

判斷標準是**受詞是不是動詞在這個領域裡能作用的對象**。

| 槽位           | 遠端沒有執行任何指令 | 遠端一個字都沒有執行 |
| -------------- | -------------------- | -------------------- |
| 動作者         | 遠端                 | 遠端                 |
| 動詞           | 執行                 | 執行                 |
| 受詞           | 指令                 | 字                   |
| 量詞計數的單位 | 指令（零個）         | 字（零個）           |

「執行」在 adb 的領域裡作用的對象是指令、程式、命令。「字」不是執行的單位——沒有任何系統逐字執行東西。「一個 X 都沒有 Y」這個句式在口語裡成立的前提是 X 是 Y 的計數單位：「一個字都沒說」成立，因為字是說話的單位。搬到「執行」上，前提不成立，句式照樣通順——中文語法不檢查受詞跟動詞在領域裡合不合。

讀者要做的還原是四步：認出這是慣用語 → 把「字」對回「指令」 → 把「一個都沒有」對回「零個」 → 重組成「沒有執行任何指令」。而「遠端沒有執行任何指令」直接就是終點，它是一個明確的判斷結果；「一個字都沒有執行」要查看前後文才能理解。兩句的差距在資訊量，與品味無關。

同一個判準套到其他強調句式：

| 改前                     | 受詞或量詞的單位                       | 改後                                                 |
| ------------------------ | -------------------------------------- | ---------------------------------------------------- |
| 遠端一個字都沒有執行     | 字：不是執行的單位                     | 遠端沒有執行任何指令                                 |
| 根本沒走到 shell 的解析  | 走到：解析是一個步驟，步驟被執行或跳過 | adb 在裝置解析那一步失敗，shell 的選項解析沒有被執行 |
| 徵兆與行尾被改寫完全一樣 | 完全：全稱量詞，範圍未在句內具名；文章下一節給了分辨方法（`xxd`），「完全」與內容矛盾 | `file` 與 stderr 分不出兩種壞檔；分得出的是檔案開頭的位元組 |

第三列是量詞槽位的第二種失效：「一個字」的單位具名但在領域外，「完全一樣」的範圍沒有具名——在全部什麼面向上相同？句內沒說。括號裡列的兩項是判定者替句子補的範圍，句子自己說的是「全部」。信了「完全」的讀者會停止找分辨方法，而文章在下一節給了一個。量詞槽位的判準因此是**範圍在句內具名**：「遠端沒有執行任何指令」的「任何」範圍是指令、具名；「兩個 md5 完全相同」的範圍是那兩個 md5、具名；「徵兆完全一樣」沒有。

**判定者不代填槽位。** 這一列先前被判成合規，理由是「完全計數的是逐項相同的徵兆」——那個單位是判定者從上下文推出來填進去的，句子沒寫。判定者做了規格要擋讀者做的事。判準要寫成是非題「單位有沒有寫在句子裡」；寫成「判定者推不推得出單位」，它永遠通過。

這個判準是生成端的：寫每一句操作描述之前先填四個槽位，槽位填不出領域內的名詞就不成句。它取代先前的「拿掉強調結構事實變不變」——那一條要有人先拿掉才知道，是後驗的；本條寫的當下逐句可判。

## 適用範圍

這條標準獨立於文章的定位。教學文章、操作指引、report 卡、規範文件——口語強調句式在任何一種文體裡都是讀者的解碼成本。它跟教室形態（[#355](teaching-is-not-lecturing.md)）的來源不同：#355 來自 LLM 對「教學」的理解，本卡來自中文口語與書面語之間的邊界模糊——同一句話講出來與寫下來都通順，而技術書面語不需要語氣來傳遞程度。

## 跟其他原則的關係

`colloquial-rhetoric-erodes-technical-precision`（住在 `compositional-writing`）管的是口語詞彙（「其實」「碰巧」「搞」），本卡管的是口語句式。兩者的 grep 策略不同：詞彙有固定的關鍵詞可以掃，句式的關鍵詞是語法結構（「一個⋯⋯都」「根本」「完全」），命中範圍很大而多數是合規的技術描述（「完全相同」在描述 md5 比對時是精確的事實陳述），判定要逐處做。

[#358](command-fragment-as-subject-hides-the-actor.md) 管的是另一種句子層的文法標準——主詞、受詞、操作關係的完整性。兩張卡共用同一個失效機制：「讀得懂」作為審查標準，對這兩種形態都有結構性盲區，因為中文的文法允許讀者自動補完和拆解。

候選 grep：`rg "一個.*都沒|根本沒|完全一樣|完全相同"`，假陽性率高——「完全相同」在比對 hash 值時是精確事實。判定用上面那個問句：拿掉強調，事實變不變。
