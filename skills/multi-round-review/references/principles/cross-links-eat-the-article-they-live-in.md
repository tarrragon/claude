# 串連佔掉的是本篇的篇幅，順序要先自足再往外開門

> **角色**：本卡是 `multi-round-review` 的支撐型原則（principle）、被 Round 2-B′ 冷讀 frame 引用。
>
> **何時讀**：一個內容集合裡各篇互相引用，而單篇讀起來薄、說不出自己要交付什麼時；或者規劃冷讀 frame 要問哪幾題時。

## 核心

一篇文章的篇幅是固定的，**寫進去的每一段跟鄰居的關係，都佔掉了本來要用來講自己的位置**。

相互引用的集合會讓串連看起來像義務：這一項要跟那一項分清楚、這一篇要接回上一篇的框架。每一條引用單獨看都成立，而它們累加起來把本篇的主題擠到只剩定義。

順序要反過來——**先讓這一篇說完自己的事，再決定要不要往外開門，開了門也由讀者決定走不走**。

## 症狀：讀得懂，而說不出它要交付什麼

一篇二十六行的短文有四個內容段，其中兩段在講別篇。冷讀的人把每一段的內容都答對了，最後一題卻寫「看不出來」，並自己列了三種互斥的可能。同一批裡幾乎整篇講自己的那篇，最後一題答得又長又準。

**讀得懂與有內容是兩件事，而多數冷讀只問前者。** 要問「這一篇讓你具備什麼能力」才分得開。

## 驗收

**這套判準測的是以論證為交付的單篇。** 個案實跑撞到四種落在射程外的頁面：術語卡的交付本來就是定義（遮掉連結後剩下定義是正常的）、目錄頁的交付是路由（遮掉連結等於拆掉它的功能）、歸納層的交付是問題與解法、孤立單篇跑它是空轉。**判準之前先過定位這一關。**

**把所有往外的連結當成不存在，重讀一次。** 剩下的東西該長什麼樣依這一篇的定位而定；以論證為交付的單篇剩下定義加屬性清單的話，篇幅被鄰居佔走了。

**驗收的門檻是「本篇有沒有任何一段在講自己」。** 這比「剩下的是定義加屬性清單」明確——量測裡答不出交付什麼的那幾篇，共同點是內容段全部在講鄰居、一段都沒剩，而答得出來的那些至少留了一段。判定因此不看比例、看有沒有。**而這條門檻只夠用來判不合格，不夠用來判合格**——它的證據是十一篇裡的兩個陽性，編碼還是知道結果之後做的。「至少留了一段」不是達標線，是下限。

**動筆的順序是先寫完本篇再開門。** 顛倒過來的話串連會邊寫邊插進來，而每一處插入單獨看都有理由。**補承諾時從行內連結與術語卡連結先補**——收尾的路由段通常已經有人在照顧，缺的是散在正文裡那些。缺的那一段要寫進來——寫本篇論證需要的那個長度，不是把目的地整段搬過來。

**遮住連結之後，第一個要查的是那個貫穿全篇的詞。** 承重的術語在自己的主場最容易沒有定義：越承重的詞，作者寫得越多、陌生感消失得越早，所以停下來定義它的那一刻從來不會到。

**多個高頻詞的時候，承重的是那個「換掉它整篇就垮」的。** 判別是把它從標題與核心段落裡拿掉，看那幾句還成不成立；剩下的多半是題材常用詞，沒被定義也不影響論證。

**產生候選可以機械化，判定不行。** 把正文的高頻詞排序、濾掉功能詞與這一批的行文習慣用語，每篇取前三個；四十四篇跑出來一百二十九個候選，逐個回原文看首次出現處有沒有一句話說明。**這個工具的精確度沒有量過**——實際做的是從裡面挑四個回查、三個是真缺口，而那四個是人挑的。射程限制三項：只掃連續的漢字（英文術語看不到）、單字要在詞邊界上反覆出現才進候選（否則被複合詞碎片淹沒）、比對要取重疊窗（非重疊會讓頻率變成字元相位的函數）。

濾詞表要隨文體調整——**新體例會製造自己的高頻詞**，而那些詞對這個掃描是雜訊。

## 串連怎麼寫

**替換型的關係寫成條件分支。**「換掉哪一項會變成什麼」讓串連變成本篇的內容——它說明了那個條件為什麼是關鍵的那一個。形態長這樣：

> **把某一項換成另一種作法**：換掉之後這個機制會怎麼變、成品因此差在哪，那是[另一個對象]。

相較之下「跟某某的分野在某某與某某」是純粹的比對，抽掉之後本篇不會少任何東西。

**而替換只是五種關係裡的一種。** 一次個案實跑逐條檢查二十二個連結，只有一個能寫成替換分支：

| 關係 | 形態 |
| ---- | ---- |
| 替換 | 換掉哪一項會變成什麼 |
| 組成 | 兩者在同一條流程上，一個是另一個的輸入 |
| 展開 | 目的地把本篇這一句推導到什麼程度 |
| 反查 | 從成品的哪個特徵認得出這一類 |
| 類比 | 兩者共用的那個抽象是什麼（參數空間不同，沒有可換的項） |

**「組成」有方向。** 它容易被寫成「本篇的哪一步用到它」，那只是其中一個方向。第二次個案實跑的十八條路由裡有兩條方向相反——目的地拿本篇的產物去用（本篇講怎麼把一批資料算出來，目的地講算出來的指標怎麼定義）。硬歸進組成會讓承諾寫反，變成「它給本篇這一步需要的東西」。兩個方向各有自己的承諾形態：取用的那一側寫「它給本篇這一步需要的什麼」，被取用的那一側寫「本篇算出來的東西在那裡被拿去做什麼」。

**這個清單換題材仍然涵蓋。** 第二批十八條裡替換零條——第一批的主導形態完全沒出現，而其餘四種各自都用上了（展開九、組成三、類比二、反查二）。

**把條件分支寫成通用解會逼出硬塞**——一次改寫裡有兩篇被套進它而關係型別根本不對，改回各自的形態才通。

**分支不會順便交代目的地，這兩件事要分別做。** 一次重測顯示，四條寫成條件分支的路由全部被回報成「沒有說去了拿到什麼」——分支交付的是本篇的內容（差異在哪），目的地的內容（那一篇會給你什麼）仍然要另外寫。

**判斷標準是內容測試：遮住目的地，讀者能不能從這一句預測出那一篇會給什麼。** 預測得出來就算，寫成什麼句型都可以。

**「預測得出來」有可驗收的形式**：讀者要能寫出一句關於目的地的話，而那句話能被拿去目的地檢查對錯。主題詞不算（「那一篇會講某某」對錯無從檢查），能比對的敘述才算，而驗收就是真的拿去比對。對得上是承諾成立；**對不上要當成一項 finding 記下來並指定修法**——改承諾的措辭、或者改目的地讓它承接，停在「這是承諾寫錯」這個分類上不算處理完。

**這個測試作者自己跑不了。** 作者知道目的地寫了什麼，讀那一句時永遠預測得出來——預測的材料來自記憶而不是那一句。它按構造需要一個不知道目的地的讀者，而「我預測不出來」這個回報要先歸因：是那一句沒給材料，還是這個讀者缺背景。

句型只影響命中率，不是判定條件。「某某付給了誰，決定了這個市場是零和還是負和，見[連結]」交出了結論的形狀；「某某與某某的互動**在**[連結]」只給了主題。但把這個差別寫成「要有謂語」的句法規則會產生假陰性——「這一類的完整成員與兩地要求差在哪，在[連結]」照句法規則判成沒承諾，而它已經說了目的地交付的兩件事。

**這一維的可機械化程度低於它看起來的樣子**：用「見」與「在」比對前綴會把兩種形式都算成有承諾，改成比對句法角色又會漏掉上面那種假陰性。要量它就用冷讀，逐條問「這一句讓你預期那一篇會給什麼」。

**這一條被改過三次，三次都是同一種失效**——初稿寫「條件分支同時是往外的門」、改成「連結前面掛一個名詞」、再改成「寫成謂語」，每次都是**把一個形式當成判準**。形式是高命中率的寫法，判準要問內容。這個形態本身比這一條規則有用。

## 每一條判定都要附它的輸入

上面每一條規則的最省力遵循方式都一樣：在腦中判一次，在報告寫一句通過。而**那個判定認真做過與完全沒做，產物完全相同**——這一組規則的所有判定又都由知道答案的作者執行，所以「我判過了」不構成證據。

判定本身不是產物，**判定用的材料才是**：

| 判定 | 要附上的輸入 |
| ---- | ---- |
| 這一篇自足 | 遮掉連結之後剩下的段標清單，逐條標「講自己／講鄰居」 |
| 這個概念不是主線、可以換成連結 | 遮掉它之後仍然成立的那一句原文 |
| 這一篇沒有承重術語沒被定義 | 三個候選各一句「拿掉它之後那幾句還成不成立」，不只寫中選的那個 |
| 這條路由有承諾 | 冷讀者預測出來的那句原話，以及拿去目的地比對的結果 |
| 這一批不必調濾詞表 | 「本批新增濾詞：無」這一行 |

**「不適用」「不需要」「份量不夠」這三個結論最省力，因為它們不產出任何東西可供檢查**——判成它們的時候尤其要附輸入。同樣的道理套在數量上：取前三個候選是上限而不是配額，實際查了幾個、還剩幾個沒查，要寫出來。

## 為什麼審查抓不到

**交叉引用在多數審查 frame 裡是加分項。** 路由完整度查有沒有連過去，雙向性稽核查反向補了沒有，目的地承接查那一頁對不對——三者都在確認連結該有而沒有，**沒有一個在問連結佔掉了多少篇幅**。

逐句讀也讀不出來，因為每一句都在講一件對的事。

## 判讀徵兆

- 一篇的小節標題裡，帶著別篇名字的佔了一半以上。
- 問一份冷讀「這篇讓你具備什麼能力」，答案是「看不出來」，或者列出兩種以上互斥的可能。
- 把所有往外的連結遮起來之後，這一篇剩下的是定義加屬性清單。
- 文章列出某一項跟另一項的三處差異，而另一項是什麼，本篇沒說。
- 遮住連結的目的地之後，讀者從那一句預測不出那一篇會給什麼。
- 一篇裡出現頻率最高的那個實詞，在全文裡找不到一句話說明它是什麼。
- 同一個集合裡，短的那幾篇比長的那幾篇更難說出自己在教什麼。
