# 教學定位被讀成教室講課，產出的是經營注意力的障礙而非有序的說明

## 三個形態

**情境故事開場**：文章的讀者由搜尋或路由帶來，自帶問題，不需要一段故事替他建構情境。範圍交代用一句話。判別：刪掉這一段之後讀者還知不知道這篇在講什麼——標題與 description 已經告訴他了。

**省略主詞受詞**：教室裡師生共享脈絡所以主詞可以省，文章的讀者從任意位置落進來，手上沒有作者腦中的地圖。每個指令與每段說明的操作主體寫完整。

**模擬教室互動**：「該問誰」「容易搞錯」「前面提到的四種」「先確認 A 再做 B」。操作指引直接把正確做法寫清楚。如果某個輸出容易被讀反，一開始就引導讀者看對的欄位，而不是寫完之後告訴他「剛剛那段容易搞錯」。

## 根因

「教學」在生成端被讀成一種產出形式（教室講課），而教室的預設是講者在場、學生坐在面前、注意力需要經營。搬到文章上之後，經營注意力的手段全部變成資訊障礙。LLM 訓練資料裡「教學」最高頻的範例是教室場景——線上課程講稿、教科書導入段、教學影片旁白。

## 判讀徵兆

- 開場超過一句話的情境敘事
- 正文裡的「該問誰」「要懷疑的對象」「下一個要問的」
- 「容易搞錯」「容易讀反」「讀者會停下來」
- 「前面提到的 N 個」（位置回指兼教室回顧）
- 直接寫給讀者的提醒句：「先確認 A 再做 B」「注意這裡」「這一步不能省」

## 形態四：判定標準包裝成自問自答

「問自己一個問題：回退時間是⋯⋯」——判定標準的消費方式是讀者帶著個案來查，他要的是條件與通過標準，把判定包裝成問句多了兩步還原。改法是直接給條件映射。

## 形態五：「問得出/問不出」替代指標

「問得出走官方 SDK 的呼叫佔多少比例」——中文口語讀得通，但它把指標名稱與通過標準藏在隱喻裡。改法是寫出指標名稱、量測方式、通過標準。

## 與相鄰原則的差別

`write-for-readers-not-audiences`（住在 `compositional-writing`）管的是刻意的懸念手法；本卡管的是不自覺帶進來的教室姿態。`audience-is-professional-not-layperson`（同一支 skill）管的是宣導語氣（預設讀者無能）；本卡的省略主詞看起來是相反的問題（預設讀者已知脈絡），實際上根因是同一個教室預設的兩端。
