# DOC-GPD-001: 規範並列兩個判準，只有一個綁定可執行動作，未綁定者形同不存在

---

## 分類資訊

| 項目 | 值 |
|------|------|
| 編號 | DOC-GPD-001 |
| 類別 | documentation |
| 嚴重度 | 中 |
| 發現日期 | 2026-09-04 |

### 症狀

規範文件在同一處並列兩個判準，其中一個是本體、另一個是它的代理指標，但緊接其後的
可執行條文（Action、檢查清單項、hook 判定式）只綁定其中一個。**實際生效的永遠是被綁定
的那個**，另一個雖然寫在文件裡，卻沒有任何時刻會被援引。

典型訊號：

- 判準寫成「A（B）」的形式，B 在括號內作為 A 的便利換算，而 Action 只提 B
- 檢查清單的機械檢查項複製了 Action 的措辭，於是同一個遺漏在兩處重複
- 存量檔案普遍通過檢查，但以本體判準重算後大量超標

實例：一份 skill 設計規範的載入預算表列「< 5k tokens（< 500 行）」，其 Action 寫
「超過 500 行就外移」，Body 檢查清單寫「SKILL.md body < 500 行」。以行數量測時全庫通過，
以 token 量測時 58 份有 29 份超標，中位數恰卡在門檻上。最大者為門檻的 7.12 倍。

### 根因

**行為模式**：撰寫規範時，本體判準（token、語意條件）不便當場量測，於是補一個好量的
代理指標放進括號；寫 Action 時自然選擇可執行的那個，本體判準遂退化為註解。

三層原因：

1. **可執行性偏差**：Action 必須落到一個能被執行的動作上。兩個判準中只有一個可執行時，
   Action 必然綁它——這不是疏忽，是撰寫過程的必然傾向。
2. **代理指標的出處未標**：括號內的換算值常是撰寫者的估算，未標明來源與適用條件。
   後續讀者無從判斷它是權威值還是便利值，於是當作等價替代。
3. **代理指標的失效區未標**：代理關係只在某個分布內成立。行數與 token 的比例
   取決於每行字元數，而繁中散文的每行字元數沒有上界——長行處兩者脫鉤，
   代理指標仍通過而本體已大幅超標。

### 影響範圍

| 影響 | 說明 |
|------|------|
| 規範靜默失效 | 本體判準從未被援引，且因無人違反「有 Action 的那條」而不產生任何告警 |
| 存量累積 | 失效期間所有新增內容都以寬鬆代理指標驗收，發現時已是全庫規模 |
| 發現需外部觸發 | 只有在有人恰好以本體判準重算時才會暴露，日常流程不會撞到 |
| 誤判為判準過嚴 | 修正代理指標後大量檔案轉為不合規，容易被反過來理解成「新門檻太嚴」而回退 |

### 解決方案

| 步驟 | 動作 | 驗證方式 |
|------|------|---------|
| 1 | 查本體判準的出處，確認它是權威值還是本地假設 | 讀規範所引的上游文件；出處缺席即為第二個問題 |
| 2 | 查代理指標的出處，多數情況會發現它是本地自創且未標來源 | 上游文件搜尋該指標；查無即為本地新增 |
| 3 | 若已有經校準的換算係數，沿用之，不自創公式 | 搜尋既有實作中的係數常數與其校準註解 |
| 4 | Action 改綁本體判準，附可直接執行的量測指令 | Action 內含一行可複製的命令 |
| 5 | 同步所有鏡像位置（檢查清單、hook、其他文件的複述） | 全文搜尋舊代理指標的數值與措辭 |
| 6 | 以新判準重算存量，量測結果本身即分流依據 | 超標比例與倍數分布；分布極不均時分層處置而非一律 |

修正後仍須分辨兩件事：**判準是否正確**與**存量是否合規**。大量存量不合規不構成
判準過嚴的證據——除非本體判準本身查無出處。

### 預防措施

| 措施 | 說明 |
|------|------|
| 判準與 Action 一對一 | 一個判準配一個 Action。並列兩個判準時，未被 Action 綁定的那個應刪除或明標為「僅供參考換算，非判定依據」 |
| 代理指標標明失效條件 | 保留代理指標時，同處寫出它在什麼條件下與本體脫鉤（如「每行字元數超過 N 時不適用」） |
| 換算值標出處 | 括號內的換算值註明來源：官方規格、實測校準、或本地估算。標為本地估算者不得進入 Action |
| 量測而非推斷 | 修訂判準後立即以新判準重算存量，把結果寫進變更紀錄。不重算則無從知道修訂是否只是換了個沒人違反的門檻 |
| 檢查是否有執法層 | 判準所在的層級若無 hook 或 CI 覆蓋，在條文中明載此事實，使讀者知道它依賴自查 |

### 相關

- 同源機制：估算係數未經實測校準即上線（本框架另有一則實作類 error-pattern 記錄
  同一檔案的係數曾以未實測的保守值上線並低估 2.3 倍），與本則的差別在於
  前者是「值錯」、本則是「值對但沒有任何動作會用到它」
- 代理指標脫鉤與可執行性偏差不限文件：測試斷言以易量測的代理值取代待驗語意、
  監控以易採集的指標取代服務品質，皆為同一形態
