# TEST-GPD-1007: 以固定行號抽取實驗素材，漏掉段落邊界外的一行，使理解題的答案不在素材內

## 基本資訊

| 項目 | 值 |
|------|-----|
| 分類 | test |
| 來源版本 | 0.5.0 |
| 風險等級 | 低 |
| 首次觀察 | 2026-10-30 |

## 症狀

一次讀者理解實驗比較兩種寫法。出題者先從票面以固定行號範圍（例如第 359～373 行）抽出事實表，再依票面原文出理解題與答案鍵。兩組撰寫者依事實表寫回報，讀者依回報作答。

開跑後，某一題的讀者全部答「文中未提」，兩組各 3 名都一樣。回查發現：這題的答案在第 374 行，落在抽取範圍外一行。事實表從一開始就沒有這項事實，兩組都不可能答對。

## 根因

**出題的來源與素材的來源不是同一份文字**。出題者看著完整的票面出題，素材卻是另外以行號切出來的片段。兩者的範圍沒有核對，題目就可能指向素材以外的內容。

**行號範圍是在看過標題後估出來的**。段落最後一行常是補記（例如「推送待辦」），緊接下一個二級標題。估範圍時容易停在倒數第二行，而下一個標題就在下一行，看起來像已經取完。

## 解決方案

- 依停止條件不改答案鍵。結果以兩種口徑並列：照答案鍵計分，以及把該題當無效題剔除。另外記錄這屬於出題者的錯誤，以及它對兩組的影響是否相同。
- 兩組受到相同影響時，組間比較仍然有效，只有絕對值失真。

## 預防措施

- 抽取素材時，以標題錨點取到下一個同級或更高級標題為止，不用手寫的行號範圍。
- 出完題後、派讀者前，逐題在**素材檔**（不是原始票面）中 grep 答案鍵的關鍵詞。每一題都要命中，命中數為 0 的題目先修正素材或題目。這一步也是 PC-168「開跑前登記」的一部分：登記內容要對素材本身驗過，不是只對來源驗過。
- 讀者全部答「文中未提」的題目，先查素材，再判讀讀者或寫法的問題。
