# PC-BAL-042: 跨 session 訊息引用的對話脈絡已隨 /clear 蒸發，接收方誤接續並產生無載體承諾

## 基本資訊

| 項目 | 內容 |
|------|------|
| 風險等級 | 高 |
| 發現時機 | 平行 PM session 對話跨越 /clear 邊界，接收方對已脫離的脈絡做出回報承諾 |
| 發現日期 | 2026-08-18 |
| 觀測次數 | 一次完整事件鏈（發送側缺訊號 + 接收側誤接續兩環同時成立） |

## 症狀

- session 甲向 session 乙提供建議後 /clear 轉入新任務，未向乙發任何訊號
- 乙依「對話延續中」的心智模型回傳處置進度，訊息本身完全合理
- 甲的新 context 收到訊息後直接接續，並做出「結論出來後回傳給我」類承諾——對一個自己已無記憶、用戶已視為結束的脈絡重新開啟迴圈
- 失效無錯誤訊息：訊息送達成功、回覆語氣自然，所有可觀測訊號都與「正常協作」一致
- 承諾只存在 session 記憶，下次 /clear 再度蒸發，peer 側迴圈永不關閉

## 根因

三層，由深至淺：

1. **地址穩定性與脈絡穩定性脫鉤**：跨 session 訊息以 session 為地址（socket 跨 /clear 存續），但 context 不存續。發送方看到同一個可達地址，無從得知對方已脫離脈絡；接收方看到一則指名道姓的訊息，直覺以為那是「自己的對話」。
2. **接收側預設行為是接續**：訊息 wrapper 與工具說明均引導「act on it」，沒有「先判讀本 session 是否仍持有該脈絡」的前置步驟。預設路徑即錯誤路徑。
3. **承諾載體錯誤**：對話中的承諾未落 ticket。框架核心原則是資訊經 ticket 系統傳遞，跨 session 對話繞過了這條——承諾與後續路由只存在於雙方 session 記憶的交集，而這個交集在任一側 /clear 時歸零。

與 PC-BAL-038 同屬「唯一可觀測訊號最易被誤讀」家族：038 的 idle 通知被誤讀為交付完成；同儕沉默（接管判準所防）被誤讀為未工作或工作中；本模式的來訊被誤讀為「本 session 的在途對話」。三例同形狀，誤讀方向不同。

## 解決方案

**接收側（發現當下即可自保，不依賴 peer 配合）**：收到跨 session 訊息時先問「本 session context 是否含該對話脈絡」。引用無記憶脈絡的訊息，先以世界平面（ticket / worklog）查證脈絡歸屬與狀態，再分流：已完結 → 回覆關閉訊號不做承諾；需本側用戶決策 → 轉 ticket 並告知經票面追蹤；與現任務相關 → 明示接續依據（ticket ID）後繼續。禁止預設接續。

**發送側**：/clear 前清點有在途對話的 peer，逐一發關閉訊號——已完結告知脈絡結束；未完結告知後續經 ticket 接手。

**承諾規範**：跨 session 對話不做無 ticket 對應的回報承諾，改以「結論見票面」加票號表達。

## 預防措施

| 時機 | 檢查 |
|------|------|
| 收到跨 session 訊息 | 問「這個脈絡在我的 context 裡嗎」，不在則先查世界平面再決定接續／關閉／轉 ticket |
| 回覆 peer 前 | 掃描回覆中的承諾語（「之後告訴我」「我會回報」），每一條都須有 ticket 對應，否則改寫為票面指向 |
| /clear 前 | 清點在途 peer 對話，逐一發關閉訊號 |
| 設計跨 session 協作流程 | 任何需跨 session 存續的資訊（承諾、待決項、路由）以 ticket 為載體，對話僅作即時協調 |

## 案例

一次雙 PM session 協作：甲 session 向乙 session 轉達用戶對接管判準章節的改進建議後 /clear；乙不知情，依對話延續模型回傳三視角審查的處置方式；甲的新 session 收訊後直接接續並承諾「審查結論出來後告訴我、我會帶回用戶決定」。用戶指出甲側已脫離該脈絡、不再需要同步。撤回成本：一則更正訊息（撤回承諾、改由票面路由）+ 一張 ANA 票（2026-08-18 建於接收方專案 worklog v0.2.1 W3 tickets，標題含「跨 session peer 對話的 thread 生命週期缺漏」，規則落地設計見該票 Solution）。

## 與既有模式的分界

| 模式 | 誤讀對象 | 誤讀方向 |
|------|---------|---------|
| PC-BAL-038 | 背景 agent 的 idle 通知 | 以為產出已交付 |
| 跨 session 接管判準（parallel-dispatch.md 沉默方向） | 同儕的沉默 | 以為未工作（搶做）或以為工作中（空等） |
| 本模式 | 同儕的來訊 | 以為對話脈絡仍屬本 session（誤接續） |
