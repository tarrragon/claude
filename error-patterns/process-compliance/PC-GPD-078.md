# PC-GPD-078：「沒有指示就照做」不會自己開始

## 基本資訊

| 項目 | 內容 |
|------|------|
| Pattern ID | PC-GPD-078 |
| 分類 | process-compliance（多 session 協調的回合推進） |
| 風險等級 | 中（線閒置，沒有任何訊號） |
| 來源版本 | 0.6.0 |
| 首次觀測 | 2026-11-03 |
| 關聯 | [[PC-GPD-072]]（同屬「沉默的線不產生事件」，本則的成因在雙方的回合結構） |

## 摘要

**一個 session 送出回報後結束回合，就要等到有新的輸入才會繼續。** 回報裡寫「沒有其他指示的話，我就先做 X」，並不會讓它在一段時間後自己開始做 X。如果主控把這種回報判定為「不用回覆」，而這條線背景也沒有在跑的代理人可以喚醒它，這條線就會一直閒置，直到有人問起。

## 症狀

- 線回報完成一張票，結尾寫「下一張是 X，沒有其他指示的話，我先盤點 X 再派發」。
- 主控記錄回報，判斷不用回覆。
- 約 30 分鐘後，line_status 顯示這條線沒有等用戶、沒有 worktree，ctx 也沒有新的量測。主控傳訊詢問後，線才回覆「我在等你回覆」，然後開始動工。

## 根因

- 寫回報的一方把「沒有其他指示就照做」當成自動繼續，實際上回合已經結束。
- 主控判斷要不要回覆，看的是「有沒有需要裁定的事」，沒有看「對方送出這則回報後，還有沒有東西會喚醒它」。
- 有背景代理人在跑的線，代理人完成時會喚醒它，所以平常看不出這個問題；只有背景沒有在跑東西的線會停住。

## 防護

| 情境 | 做法 |
|------|------|
| 線的回報寫了「沒有其他指示就做 X」，而且背景沒有在跑的代理人 | 主控一律回一句「照做 X」，不判定為不需回覆 |
| 線要宣告預設的下一步 | 不寫成「沒有指示就做」，直接在同一個回合開始做 X，回報寫「已開始 X」 |
| 主控每輪讀 line_status | 某條線的 ctx 量測停在一段時間以前、沒有 worktree、也沒有等用戶，就傳訊詢問，並加 `notify_when_idle` |

## 檢查問句

決定不回覆某則回報之前問：對方送出這則訊息後，還有什麼會讓它再動起來？如果答不出來，就回一句。
