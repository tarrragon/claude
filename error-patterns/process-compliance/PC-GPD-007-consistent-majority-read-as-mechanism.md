# PC-GPD-007: 樣本中一致的部分被讀成機制，對不上的那一格被當成雜訊

## 症狀

比對一組樣本後宣告一個機制，而該機制解釋不了樣本裡的某一格。那一格通常已經出現在自己列出的表格或清單裡，被歸類為補充證據、例外或雜訊，沒有被當成問題。

外觀特徵：結論的措辭是「A 等於 B」「A 一律 C」，而支撐它的資料是「N 項相同、1 項不同」。不同的那一項在同一份產出裡看得到。

## 根因

| 層級 | 機制 |
|------|------|
| L1 一致性的說服力與樣本數同向 | 相同的項數越多，讀者對結論的信心越高，而信心來自數量不來自機制。七項相同不比一項相同更能證明因果，它只是更難被偶然產生 |
| L2 例外被歸類而非被解釋 | 不一致的那一格出現時，最省力的處置是給它一個標籤（補充證據、反向情形、環境差異），標籤讓它從待解問題變成已處理項目，於是不再被追問 |
| L3 正確的機制通常同時解釋兩者 | 真機制若成立，例外不會存在——存在的是機制的邊界。誤把邊界讀成雜訊時，得到的模型在邊界外會無聲失效 |

## 盲區：本 pattern 的訊號抓不到相消的成對錯誤

本 pattern 的偵測依賴「看得到一格對不上」。兩個方向相反的錯誤同時存在時，聚合值完全吻合，零不一致可見，本 pattern 的訊號失效。

該形態不在此另立條目——`PC-BAL-023` 已完整涵蓋，其根因段逐字寫「`|A| = |B|` 不蘊含 `A = B`。計數是集合的一個投影，投影相等不足以推導原像相等」，並稱一漏一多相抵為「偽全量最難察覺的形態」。判準與補救一律以該檔為準。

本專案補一個新的觸發情境：**兩種解析器對同一目標各自出錯**。既有實證是搜尋範圍與待處理集合的分母錯配，本情境是兩個實作讀同一批檔案、一個漏抓一個多抓（案例其二）。兩者的共同點是相抵發生在聚合之前，聚合值本身無異常。

兩條訊號的關係見防護節末段。

## 案例

**其一，七格相同一格不同（主形態）**：比對本地、上游正本、發佈庫三方的元件版本，八個元件中七個的正本版本與本地相同、一個比本地舊兩版。據七格宣告「正本在該維度是本地的舊快照、不承載更新」，並把第八格列為「反向也漏」的補充證據。

該結論會導向一個代價很高的下一步：既然這條通道不承載此類資產，合理的作法是設計第三條通道。實際的機制是「正本凍結在上次全樹推送的時點」——它承載該類資產，只是快照較舊；八格用這個機制全部解釋得通，包含那個對不上的第八格（該次快照裡它就是舊版）。錯誤的模型會讓人去解決一個不存在的問題。

**其二，計數吻合而成員不同（變體）**：以兩種量法統計同一批檔案的欄位超標數，兩者皆得 22。實際成員相差兩項——一種量法漏抓使用折疊純量的檔案（只讀到分隔符，長度算成 1），同時多抓另一項。若交叉核對比對的是數量，此處得到完美吻合。

**其三，三則一致推出形態（主形態，他方）**：一個並行執行者以「同一日的三次自我更正屬同一形態」推論出一條通則，經逐項核對，其中兩次不成立——一次是它引述他人的自陳而非該執行者的更正，一次從未發生。以三實例支撐的形態實際只有一個實例。

## 防護

**Why**：一致的樣本能排除偶然，不能指認因果。指認因果的是「這個機制能不能解釋每一格」，而每一格包含對不上的那一格。

**Consequence**：依錯誤機制建立的模型在其邊界外無聲失效——不會報錯，只會在某次條件變化時給出錯的判斷。其中代價最高的一類是「這條路走不通」型的錯誤結論，它會引導出建設性的補救動作（新建通道、新增機制），而補救的對象並不存在。

**Action**：

| 步驟 | 做法 |
|------|------|
| 宣告機制前 | 清點自己列出的資料，找出機制解釋不了的格。有這樣的格就先問為什麼，不給它標籤 |
| 對不上的那一格 | 預設它是機制的邊界而非雜訊。試著找一個能同時解釋一致格與例外格的機制，找到的那個通常才對 |
| 措辭 | 「N 項相同」與「A 等於 B」是兩種強度的宣稱。資料只支撐前者時就寫前者，不要升級 |
| 交叉核對 | 比對集合而非其基數，判準見 `PC-BAL-023`。只比對數量無法偵測相消的成對錯誤 |
| 引用他人的多實例歸納 | 逐項核對每個實例是否成立，特別是實例來自對方對你的行為的描述時。歸納者常把他引述的內容記成當事人的行為 |
| 跨 session 協作時歸納行為 | 以執行體而非專案名索引。同專案的多個 session 是不同行動者，以專案名索引會把數個執行體的紀錄併成一份，製造不存在的重複實例（案例其三的成因） |

**兩條訊號的分工**：可數的不一致（N 項一致而 1 項例外）偵測本 pattern；集合比對偵測相消的成對錯誤（`PC-BAL-023`）。前者抓看得見的不一致，後者抓被抵銷掉的不一致。只用前者會漏掉整個後者類別。
