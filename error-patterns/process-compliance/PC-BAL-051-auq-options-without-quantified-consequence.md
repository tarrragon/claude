# PC-BAL-051: AskUserQuestion 選項措辭正確但未附量化後果，用戶在資訊不完整下裁示不可逆操作

## 基本資訊

| 項目 | 內容 |
|------|------|
| 風險等級 | 高 |
| 首次發現 | 2026-08-21 |
| 來源版本 | 0.2.1 |
| 適用範圍 | 任何以 AskUserQuestion 向用戶徵求不可逆或有量化效果之操作授權的場景：刪除檔案或資料、清理快取、縮減保留期、關閉防護、變更預設值。選項字面合理但效果需量測才知者為高發區 |
| 關聯 | `PC-BAL-050`（同屬「數字未呈現即被措辭取代」家族；該模式在分析報告端，本模式在向用戶提問端）、`PC-BAL-022`（證據形態看似充分實則不對應問題） |

## 摘要

PM 以 AskUserQuestion 請用戶授權一次性刪除 68 萬個 hook 日誌檔（2.7 GB）。選項之一為「保留最近 7 天，其餘刪除」——字面合理、聽起來保守。用戶選了它。同儕 session 隨後量測：680,399 檔中僅 12,795 檔（1.9%）超過 7 天，該選項實際效果是**幾乎不刪任何東西**，問題完全沒解決。PM 作廢授權，附上量化事實重新呈現四選項，用戶改選「全部刪除」。

失真機制：選項本身沒有錯、AskUserQuestion 機制運作正常、用戶認真作答——錯的是**每個選項的量化後果沒有被呈現**。這種不完整不會表現為任何錯誤訊號：沒有 exception、沒有 WARNING、沒有測試紅燈，只會在有人獨立量測並對照時被發現。若無同儕攔截，執行結果是「做了一次授權流程，刪了 1.9%，2.7 GB 原封不動」，且事後稽核看到的是一次合規的用戶授權。

**代價**：不可逆操作在資訊不完整下被授權。本例方向是「刪太少」，代價是問題未解；同一機制也可能反向——選項「清理快取」未附「會連同 X 一起刪」，用戶授權後才發現刪了不該刪的。後者不可回復。

## 症狀

| 症狀 | 觀察點 |
|------|--------|
| AUQ 選項描述只有動作（「保留 N 天」「清理 X」），沒有該動作的量化效果 | 選項 description 欄無數字 |
| 選項間的效果差距極大但措辭相近 | 「全部刪除」與「保留 7 天」讀起來像程度差異，實際差 50 倍 |
| 用戶選了最「保守」的選項 | 在缺乏後果資訊時，保守措辭天然吸引選擇 |
| 事後由第三方量測才發現選項效果不符直覺 | 提問者自己不會發現 |

## 根因

1. **提問者把「選項正確」當成「提問完整」**：選項列舉窮盡且每個都可執行，提問者即認為盡責；但用戶做決定依據的是後果，不是動作。
2. **量化後果需要額外量測，提問時省略了這一步**：「保留 7 天會刪多少」需要 `find -mtime +7 | wc -l` 一次量測；提問者沒量，用常識填補（「7 天應該會清掉大部分」），而常識在本例是錯的（98% 檔案是最近 4 天產生）。
3. **機制層無任何訊號**：AskUserQuestion 不知道選項背後的效果，無法警告；權力不對等規則（ai-communication 規則 5）要求避免替用戶選擇，但未要求每個選項附後果。

## 解決方案

重新提問時的做法（本例實際執行）：

1. 先量測：總數、各候選閾值下會刪多少、佔比。
2. 問題敘述開頭先放事實：「現有 680,399 檔，其中僅 12,795（1.9%）超過 7 天，98% 為最近 4 天產生」。
3. 每個選項 description 附該選項的量化效果與不可回復面：「全部刪除——釋放 2.7 GB / 68 萬 inode；今日以前日誌不可追溯」「保留 7 天——只刪 1.9%，實質不釋放空間」。
4. 把前次授權標為作廢並記錄原因於 ticket，避免下游把第一次裁示當定案。
5. 不可逆操作的**執行方**再獨立向用戶確認一次（本例由同儕 session 執行，它以自己的量測數字重問）——這不是不信任轉述者，是 permission laundering 的邊界：執行方沒看到原始提問就不該執行。

## 預防措施

- **選項附後果（強制）**：涉及刪除、清理、縮減、關閉防護、變更預設的 AUQ，每個選項 description 必須含該選項的量化效果（影響幾個／多少／誰）與不可回復面；無法量化時明寫「效果未量測」。
- **提問前量測一次**：閾值型選項（N 天、N 筆、N%）在提問前用一行命令算出各閾值的實際效果，數字進 description。
- **第三方可攔截的結構**：不可逆操作的授權與執行分屬不同執行體時，執行方以自身量測重新確認；同一執行體時，提問前後各量測一次並比對。
- **Hook 層候選**：`askuserquestion-*` 類 hook 可對 options 中含「刪除／清理／保留 N 天／rm」字樣而 description 無數字者發 WARNING（非阻擋），提示補量化後果。

## 關聯
