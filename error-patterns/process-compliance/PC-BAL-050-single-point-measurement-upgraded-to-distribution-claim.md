# PC-BAL-050: 參數敏感決策以單點量測作主論據，數值再被措辭升級為分佈宣稱

## 基本資訊

| 項目 | 內容 |
|------|------|
| 風險等級 | 高 |
| 首次發現 | 2026-08-21 |
| 適用範圍 | 任何代價隨參數變動的決策分析：排程與並行度、快取與批次大小、逾時與重試次數、取樣率、資源配額。分析報告已自承某參數未測、推薦段仍以其推定值作論據時為高發區 |
| 關聯 | `PC-168`（同屬取樣不足家族，處理的是量測不穩定；本模式的量測在給定參數下穩定，問題在參數未變動）、`PC-BAL-022`（同屬證據形態看似充分實則不對應問題） |

## 摘要

當決策的代價隨某個參數變動，而量測只在該參數的單一取值上進行時，得到的數字可重現，但**代表性未經檢驗**。此數字若在代表性檢驗之前就成為決策主論據，並在敘述中被形容詞升格為分佈性質（「代價極小」「可忽略」「幾乎不受影響」），該升格會隨衍生票的 why 欄位逐字複製到下游，使實作者拿到的是無條件結論而非有條件量測。

標題的兩段可分別發生：單點量測但措辭嚴謹、或多點量測但措辭仍誇大，各自都不構成本模式。本模式指的是兩者接續出現時的放大效應——單點量測限縮了證據，措辭升級抹除了限縮的痕跡。

**代價**：實作者依無條件結論選型，若參數的最差端會翻轉方案選擇，該實作是白做的。而錯誤結論此時已隨 why 欄位固化在票面上，回溯成本高於原始分析——要撤回的不只是一份報告，還有已據以建立的衍生票、已寫入的驗收條件、以及讀過票面的後續執行者的認知。

### 與 PC-168 的分野

概念差異：`PC-168` 處理 flaky 環境下少量 sample 的幸運連勝，問題出在量測本身不穩定；本模式的量測在給定參數下穩定且可逐項重現，問題出在**參數未被變動**。前者的解方是提高同一條件下的重複次數（N >= 5），後者的解方是變動參數做敏感度掃描。在參數被固定的重跑中，重複次數再高也不會暴露本模式；若參數是隨環境漂移的實況值，跨時段重跑可能偶然撞見變異，但那是運氣而非方法。

現場判別（同一條件、同一參數值，重跑兩次）：

| 重跑結果 | 判定 | 處方 |
|---------|------|------|
| 兩次結果不同 | `PC-168` | 提高 N 至 5 以上並記錄分佈 |
| 兩次結果相同，且該量測有可變參數 | 本模式 | 掃描參數範圍做敏感度分析 |
| 兩次結果相同，且無可變參數 | 兩者皆不適用 | — |

## 症狀

| 症狀 | 觀察點 |
|------|--------|
| 分析報告的成本論據只有一個數字，且該數字有明確的產生條件（某參數等於某值） | Solution / 實驗結果章 |
| 該參數的實際取值範圍未被查證，或以「通常不超過 N」的推定值代替 | 「仍未驗證的假設」章常自承但推薦段照用 |
| 數字在報告前段是條件式陳述、在推薦段變成無條件形容詞 | 同一文件前後對照 |
| 衍生票的 why 逐字沿用該形容詞，未攜帶原文的 caveat | 衍生票 frontmatter |
| 取樣點事後被發現落在最有利的一端 | 敏感度重跑 |

## 根因

三層共振：

1. **參數的存在未被辨識為變數**。量測者取當下環境的實況值（W3-791 案例：量測當下恰有 2 個並行任務），未意識到該值是分佈的一次抽樣，因此不會想到要變動它。
2. **可重現性被誤讀為代表性**。數字經他人重跑逐項命中，強化了「這個數字是對的」的信心；但重現驗證的是計算正確，不是取樣充分。
3. **形容詞沒有量測義務**。具體百分比必須有出處，「代價極小」不必——語言層允許在不新增任何量測的情況下把單點升格為性質，而下游只會複製後者。

## 偵測方式

分析報告產出後、衍生票建立前，對每個作為決策依據的數字問：

1. 這個數字是某個參數在特定取值下的結果嗎？該參數是什麼？
2. 該參數的實際取值範圍是多少？**用歷史資料量，不用推定值。**
3. 在範圍的兩端重測，數字的變動幅度是多少？
4. 把報告中修飾這個數字的形容詞，就地替換成最差端的實測數字，重讀該句與其推薦結論——推薦的方案還是同一個嗎？

第 4 問答否即命中本模式。此問以方案選擇作答，不以形容詞語感作答；第 3 問未完成時本問無輸入，不可跳答，逕依處置表末列處理。

## 處置

| 情境 | 動作 |
|------|------|
| 分析尚未結案 | 補敏感度掃描，結論改為區間陳述並載明單點值的成立條件 |
| 已衍生實作票 | 回寫衍生票 why，補上原文 caveat；若最差端會翻轉方案選擇，退回重裁 |
| 形容詞無法以資料支撐 | 刪除形容詞改數字直述，把評價留給讀者 |
| 參數範圍取不到歷史資料 | 明確寫「未量測，屬推定」，不得以推定值否決敏感度分析 |

## 預防措施

- 多視角審查（`/parallel-evaluation` 情境 F）至少一個視角應被要求重跑關鍵數字並變動其參數，而非只查證數字是否可重現。查證可重現只會確認計算無誤。
- 分析報告的「仍未驗證的假設」章若列出某參數未測，推薦段不得以該參數的推定值作論據——兩章互相矛盾時以未驗證章為準。
- 建立衍生票時，PM 應檢查 why 是否攜帶了原文的成立條件。W3-791 的擴散即循此路徑：衍生票 why 逐字沿用形容詞，caveat 未被攜帶。
